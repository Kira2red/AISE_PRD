## 启动

```bash

```

浏览器打开 http://localhost:8090 （登录页点击角色卡即登录）

## 大模型（真实调用，与 Hermes 同款）

- 配置读取：环境变量 `GLM_API_KEY`，缺省自动读 `~/.hermes/.env`
- 文本模型 `glm-5.3-flash`（预审判分 / 画像分析 / 问答），图片作品走 `glm-4.5v` 视觉模型
- 端点 `GLM_BASE` 默认 `https://open.bigmodel.cn/api/coding/paas/v4`，可用环境变量覆盖
- 未配置 key 时预审置「预审失败」，人工可直接终审（PRD 的降级口径），问答会报错提示

## 演示链路

1. 学员端上传作品（代码/图片/PDF，类型自动识别，≤10MB）→ 状态「审核中」
2. 后台异步真实调用大模型预审：准入结论 + 理由 + 能力标签（强制清洗：剔除格式词/作品名，≤4 个）+ 100 分制得分 + 评语 + 理解摘要
3. 教研员端审核工作台：预审队列 → 作品原文预览 → 确认通过 / 修改后通过 / 驳回（必填原因），全部留痕
4. 通过后人才卡特长标签动态更新；画像分析报告（学员端点「生成/重新生成」）综合 AISE 测评记录、逐题作答、知识点掌握与入库作品评价生成
5. 问答助手：学员只答本人数据；教研员可问全库。越界请求（写作文/出卷/闲聊）、隐私打探、学员互查一律拦截，话术以「该问题超出人才库服务范围。」开头
