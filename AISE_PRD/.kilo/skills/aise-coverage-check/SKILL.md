# AISE 需求覆盖率检查

逐条对照原始需求，标记实现状态，输出精确的遗漏清单。

## 工作流

```
1. 读取原始需求文档（用户指定路径）
2. 逐条拆解为可核验的原子需求项
3. 读取所有相关 HTML demo 和 PRD 内容
4. 逐项标记 [x] 已完成 或 [ ] 未覆盖
5. 输出覆盖率报告
```

## 拆解规则

将原始需求中的每句话拆解为原子需求项：

| 原子需求项 | 来源 | 验证方式 | 状态 | 备注 |
|-----------|------|---------|------|------|
| 证书模板增删改查 | 原始需求 L12-15 | 检查 `26_证书模板管理.html` | [x] | Demo 已覆盖 |

### 拆解粒度

- 一条功能需求一个检查项（如"模板列表支持搜索"是一个检查项）
- 一个交互细节一个检查项（如"拖入字段即时创建占位元素"是一个检查项）
- 一个异常场景一个检查项（如"签发失败需支持重签"是一个检查项）
- 不做需求文档行号的全量映射，聚焦功能性需求

### 验证方式

| 产出物类型 | 验证方法 |
|-----------|---------|
| HTML demo | 读文件检查 DOM 是否包含对应的元素/按钮/列/状态 |
| PRD 章节 | 读文件检查 3.x 章节是否覆盖该功能点 |
| 两者都需覆盖 | 同时验证 HTML 交互 + PRD 描述 |

## 输出格式

```
## AISE 需求覆盖率报告

原始需求：{文档路径}
已实现产物：HTML demo {数量} 个，PRD 章节 {数量} 个
覆盖日期：{日期}

### 覆盖率
| 分类 | 总数 | 已覆盖 | 未覆盖 | 覆盖率 |
|------|------|--------|--------|--------|

### 已覆盖项
| # | 需求项 | 对应页面/PRD章节 | 验证 |
|---|--------|-----------------|------|
| 1 | ... | 26_证书模板管理 / PRD 3.1 | [x] |

### 遗漏项
| # | 需求项 | 严重程度 | 建议 |
|---|--------|---------|------|
| 1 | ... | 高/中/低 | ... |

### 已识别但暂不适用的项
| # | 需求项 | 不适用原因 |
|---|--------|-----------|
```

### 遗漏项严重程度判定

| 级别 | 定义 |
|------|------|
| 高 | 缺失会导致功能不可用或流程中断 |
| 中 | 缺失影响体验完整性（如缺少错误态、边界值） |
| 低 | 可后补的辅助功能（如导出、批量操作） |

## 约束

- 检查范围包括 HTML demo 和 PRD 文档，两者同时覆盖才算完成。
- 如果 PRD 缺失后续章节（如 3.x 只写到一半），标记对应的需求项为"未覆盖"并在建议中指明需补充的 PRD 章节编号。
- 已实现但 PRD 未描述的功能，标记为"PRD 滞后"而非"未覆盖"。
- 原始需求中暂不做的项，单独列入"暂不适用的项"并说明原因。
- 检查结果应可直接用于补充剩余 HTML demo 和 PRD 章节。
