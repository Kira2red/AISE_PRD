## 1. 背景与收益

9 月 12 日测评结束后，考务组整理出后台 8 个模块共 31 条需求（含 bug 修复与体验优化），本 PRD 一次性覆盖。

预期收益：
- 活动与测评的复制能力补齐，搭建同构活动不再重复配置
- 报名管理升级，批量导入一次成功率和审核效率提升，人工核对成本下降
- 证书筛选与导出追踪完善，纸质证书发放核对有据可查
- 学员账号治理与考中快速登录，缩短考中问题排查时间
- 修复订单查询、证书导出白屏等阻断性 bug

## 3. 详细功能说明

### 3.1 测评管理——复制测评项目 / 复制活动（序号 2）

| 项 | 说明 |
|---|---|
| 位置 | admin/33 活动详情页，测评行「…」菜单；admin/32 活动管理列表（复制活动入口） |
| 目标 | 搭建同构测评/活动时一键复制既有配置，减少重复设置 |

功能规则：
- 复制测评项目：复制该测评的试卷、时间设置、监考设置等全部配置
- 模拟卷与正式卷一并复制，两者各自的试卷与设置完全保留
- 复制活动：复制该活动下全部分组结构、测评清单及各测评的全部配置
- 复制生成的测评/活动处于「未发布/草稿」状态，名称自动加「副本」后缀，可编辑后发布
- 复制测评后其渠道关联默认不复制，由运营在渠道关联矩阵重新配置（避免费用与人数配置被误带）

补充说明 #1：demo 现状（admin/32、33）已有「复制测评」按钮，本需求将复制范围从「单测评」扩展到「整个活动」，并明确复制内容的完整边界（试卷/时间/监考/模拟考全保留）。demo 相应增加「复制活动」入口。

### 3.3 报名管理——批量导入重构（序号 5、7、17）

| 项 | 说明 |
|---|---|
| 位置 | admin/10 批量导入 |
| 目标 | 一张表格完成多渠道、多活动的批量报名导入，校验自动匹配，失败明细可核对 |
| 现状 PRD | [20260110 批量导入](<../20260110 批量导入/20260110 批量导入.md>) 三步流程保留，校验逻辑按本节重构 |

#### 3.3.1 导入表格字段

表格必填字段（序号 5、17）：

| 字段 | 校验规则 |
|---|---|
| 姓名 | 与系统数据匹配 |
| 身份证号 | 与系统数据匹配 |
| 联系电话 | 与系统数据匹配 |
| 活动 | 与系统活动名称精确匹配，不匹配报错拦截 |
| 渠道 | 与系统渠道名称精确匹配 |
| 渠道识别码 | 通过渠道码关联考场信息 |
| 分组 | 与系统分组数据匹配 |
| 测评名称 | 与该活动下测评精确匹配 |
| 支付状态 | 取值：已支付/未支付，导入后后台支付状态以表格为准（序号 17） |
| 省/市/区 | 新增字段，按行政区划匹配（序号 17） |

#### 3.3.2 导入流程与校验

- 取消前置考场选择：导入前不再要求先选定考场，考场由表格内渠道识别码自动关联
- 多渠道多活动同表：一张表格可混合多渠道、多活动的报名数据（序号 5）
- 逐行校验：字段与系统数据不匹配的行报错拦截，不阻断其他行
- 结果明细：导入完成后输出成功/失败明细，失败原因注明具体行号及不匹配的字段项

#### 3.3.3 老学员匹配（序号 7）

- 学员已注册时，导入数据自动归入该学员名下，不新增用户信息
- 匹配规则：导入表格中的渠道码与系统中该学员已有渠道匹配，匹配成功则不新增
- 新增用户时，学员渠道以表格渠道码为准

## 5. 待讨论事项

### 5.1 考中快速登录（序号 21，原表红字标注「强需求，需要讨论」）

| 项 | 内容 |
|---|---|
| 背景 | 考中阶段需要快速登录学员账号，排查问题是系统问题还是学员自身问题 |
| 需求 | 学员默认登录信息为注册手机号+手机号后 6 位；讨论增加身份证后 6 位也可登录的方案 |
| 约束 | 学员修改密码后，默认密码不再可用（刘玮备注：修改后就是新密码，保留默认密码有安全风险） |
| 现状 | 此前 bug（默认了预备测手机号后 6 位）已修复，现以正式测手机号后 6 位为准 |

待拍板：
- 方案 A：登录页支持「手机号+身份证后 6 位」作为备用登录方式，仅在测评进行中的时段生效——满足考中排查，风险窗口小
- 方案 B：后台「考中排查」专用入口，管理员经权限审批后可临时查看/登录学员账号，全程留痕
- 建议：方案 B 权限更可控；若考务强调速度，可 A/B 结合（后台入口为主，登录页备用方式兜底）

### 5.2 删除/合并学员 ID（序号 22）

| 项 | 内容 |
|---|---|
| 背景 | 学员重复注册导致无法报名，需以 ID 为线索合并账号 |
| 需求 | 后台管理员可删除空白账号（配套恢复功能），合并重复学员 ID |

待拍板：
- 删除范围：仅「空白账号」（无报名记录、无证书、无成绩）可删，含恢复期（如 30 天内可恢复）
- 合并规则：被合并账号的报名记录、成绩、证书归入保留账号，合并操作留痕且不可逆
- 权限：仅 AISE 后台管理员可见入口
- 建议：先上「删除空白账号+恢复」，合并功能涉及成绩/证书归属迁移，作为二期单独评审
