# AISE 渠道分组与报名活动卡片 PRD

> 需求文件夹：20260826 渠道分组 ｜ 方案依据：[方案概要.md](方案概要.md) ｜ 相关需求：[测评多考场 PRD](<../20260708 多考场/测评多考场_PRD.md>)、[爱测评考试自动创建 PRD](<../20260825 爱测评考试自动创建/爱测评考试自动创建 PRD.md>)、[渠道选择 PRD](<../20260729 渠道选择/PRD.md>)

术语口径：本文「活动」指渠道下关联的测评活动；「分组」指渠道内对活动做的自定义分组；「默认」分组指系统内置分组，收纳未指定分组的活动。

---

## 1. 背景与收益

多考场需求（20260708）试图在一个测评活动内嵌套多个考场（时间段、容量、标签独立配置），对测评活动模型与爱测评考试创建链路改动过大，已放弃。本需求改为在渠道维度做轻量分组：运营在渠道管理里给活动分组，用户报名时按「渠道 → 分组 → 活动卡片」选择活动，用「一个渠道下的多个活动 + 分组」替代「一个活动 + 多个考场」，实现同样的多时间段报名效果，但完全不改动测评活动模型。

业务诉求：合作渠道一场考级常需安排多个时间段或科目，原报名页「机构 + 测评项目」两级下拉在活动较多时难以浏览。分组让报名页有结构，活动卡片让关键信息（名称、考试起止时间、报名费、报名状态）直接可见。预期收益：运营侧分组配置全程在渠道管理一个弹窗内完成；用户侧选择路径清晰、步骤不增加，不可报名的活动明确置灰，减少误报。

---

## 2. 业务流程

### 2.1 运营配置流程

1. 运营进入渠道管理，打开某渠道的「关联活动管理」弹窗。
2. 点击「分组管理」，在弹窗内新建、重命名、删除、上下移排序分组。
3. 「关联新测评」时指定所属分组；不指定则归入「默认」分组。
4. 已关联活动可随时在「编辑活动配置」里改分组。
5. 保存即生效，用户端报名页按后台配置顺序展示分组。

### 2.2 用户报名流程

1. 用户进入报名，选择机构（渠道）。
2. 该渠道设置了分组 → 出现「活动分组」下拉，选择分组后展示该分组下活动卡片；该渠道未设置分组 → 直接展示该渠道全部活动卡片。
3. 用户点选活动卡片（已结束的置灰不可选），卡片区下方出现「已选择」信息条。
4. 下一步进入确认信息页（展示所选活动与分组），随后支付。
5. 报名流程保持 4 步不变（报名须知 → 填写信息 → 确认信息 → 支付）。

## 3. 详细功能说明

### 3.1 渠道管理端：活动分组管理

**位置**：渠道管理页（admin/02）→ 渠道行「关联活动」→ 关联活动管理弹窗。

#### 3.1.1 分组管理弹窗

- 入口：关联活动管理弹窗头部「分组管理」按钮，弹出分组管理弹窗；弹窗顶部标注当前渠道名称。
- 分组列表：每行展示分组名称与组内活动数；行内操作：上移、下移（调整排序）、重命名、删除。
- 新建分组：弹窗顶部输入名称，点击「新建分组」立即加入列表末尾。
- 命名规则：名称必填、渠道内不重名，重名时提示「分组名称已存在」。
- 删除规则：组内有活动的分组禁止删除（删除按钮置灰），提示「该分组内有 N 个活动，请先将活动移至其他分组」；空分组删除需二次确认。
- 「默认」分组：系统分组，恒存在；未指定分组的活动自动归入；不可重命名、不可删除、不可排序，固定展示在分组列表末尾（置灰样式并标注「系统分组」）。
- 分组顺序即用户端「活动分组」下拉的展示顺序（后台配置顺序，运营可调）。

#### 3.1.2 关联活动列表的分组展示

- 关联活动表格新增「分组」列，展示每个活动所属分组；未分组的活动展示「默认」。
- 表格上方新增「活动分组」筛选下拉：选项为「全部分组」+ 渠道各分组 + 「默认」（渠道存在未分组活动时出现）；切换筛选即时过滤列表，并展示当前筛选下的活动数量。
- 表格内「取消关联」操作生效后，列表与分组筛选项同步刷新。

#### 3.1.3 关联新测评 / 编辑活动配置

- 「关联新测评」弹窗新增「所属分组」下拉：选项为渠道当前分组，默认选中「默认分组（不指定）」；不指定时活动归入「默认」分组。
- 「编辑活动配置」弹窗同样可修改所属分组。
- 一个活动只能属于一个分组。

### 3.2 用户报名端：渠道分组与活动卡片

**位置**：考试报名主页（user/08）第二步「填写信息」。

#### 3.2.1 渠道与分组两级下拉

- 「所属机构/学校」（渠道）下拉保持不变。
- 渠道设置过分组 → 机构下拉旁出现「活动分组」下拉（必选）：选项为渠道各分组（按后台配置顺序）+「默认」（该渠道存在未分组活动时出现）。
- 渠道未设置分组 → 不显示分组下拉，直接展示该渠道全部活动卡片。
- 渠道识别码逻辑不变：扫码/链接进入锁定机构后，照常联动分组下拉。
- 切换机构 → 分组下拉、卡片列表、已选活动全部重置。

#### 3.2.2 活动卡片

- 原「报名测评项目」下拉框移除，替换为卡片列表。
- 卡片字段：活动名称（加粗）、考试起止时间（同日显示「YYYY-MM-DD HH:MM-HH:MM」，跨日显示「YYYY-MM-DD HH:MM 至 YYYY-MM-DD HH:MM」）、报名费（该渠道配置价，格式「报名费：¥ XXX.XX」）、报名状态标签。
- 状态与可点性：
  - 报名中：卡片可点击；选中后蓝框浅蓝底，右上角标签变为「已选」；
  - 已结束（考试时间已过）：卡片置灰，右上角标签「已结束」，不可点击；
  - 是否出现：沿用关联活动弹窗「前端展示时间」既有规则（未到/已过展示时间的活动不展示）。
- 排序：分组内活动按考试开始时间升序排列。
- 空态：分组下无可展示活动时，卡片区显示「该分组暂无可报名活动」；未选择分组/机构时分别提示「请选择分组」「请先选择机构」。
- 选中活动后，卡片区下方显示信息条「已选择：{活动名称}（{考试日期}）」。

#### 3.2.3 后续步骤联动

- 确认信息页：测评项目行展示所选活动名称；渠道有分组时新增「活动分组」行展示所选分组。
- 支付费用：支付步骤的金额取所选活动在该渠道的报名费，随所选活动联动更新。
- 报名流程步骤数不变（4 步）。

### 3.3 范围与替代关系

- 本需求为多考场方案（20260708）的替代方案：测评活动保持单考场形态，活动仍按「关联爱测评试卷、保存自动创建爱测评考试」规则运作（见爱测评考试自动创建 PRD）；报名端不再有「选择考场」步骤，多考场相关页面能力已回退。
- 定制报名流程（元创S营等）不涉及本需求。
- 渠道选择 PRD（登录渠道检测）与本需求相互独立，本次无改动。
