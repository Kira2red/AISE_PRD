# 20260511 5 月需求

## 功能一：渠道前端展示隐藏控制

### 1. 项目背景
- **需求简介**：在 AISE 运营后台「渠道管理」页面，为主渠道及关联活动（子渠道）新增「前端展示」隐藏/展示控制开关，并在列表中增加对应的状态字段。
- **业务诉求**：软协对外发布报名通知后，多个客户会使用各自的专属渠道报名。为避免前端同时展示收费与免费渠道导致用户困惑、以及个人用户误报到专属渠道的问题，运营方需能够灵活控制各渠道及子渠道在前端报名页的可见性。

### 2. 业务流程简述
运营人员进入渠道管理列表 -> 查看各渠道/子渠道的「前端展示」状态 -> 通过编辑弹窗切换隐藏/展示 -> 保存后实时生效于前端报名页。

### 3. 详细功能说明

#### 3.1 主渠道「前端展示」列表字段
- **位置**：渠道管理列表页 -> 表格列，介于「组织后台状态」与「操作」之间。
- **可用值**：
  - **展示中**：绿色圆点 + 绿色底 Badge（`bg-green-50 text-green-700 border-green-100`），该渠道在前端报名页可见。
  - **已隐藏**：灰色圆点 + 灰色底 Badge（`bg-slate-100 text-slate-500 border-slate-200`），该渠道在前端报名页不可见。
- **默认值**：新建渠道默认为「展示中」。

#### 3.2 主渠道编辑弹窗新增展示开关
- **位置**：渠道管理 -> 点击「渠道」编辑按钮 -> 编辑弹窗内，位于「渠道名称」输入框下方。
- **交互组件**：采用 Tailwind Toggle Switch（滑块开关），与页面现有「组织后台状态」开关风格一致。
- **状态联动**：
  - 开关开启时，右侧文字显示「展示中」（绿色）。
  - 开关关闭时，右侧文字显示「已隐藏」（灰色）。
- **创建/编辑模式**：新建渠道和编辑已有渠道模式下，开关均默认开启（展示中）。

#### 3.3 子渠道（关联活动）「前端展示」列表字段
- **位置**：渠道管理 -> 点击「关联活动」进入关联活动管理弹窗 -> 表格列，介于「已报名」与「操作」之间。
- **可用值与样式**：与主渠道列表规则完全一致（展示中🟢 / 已隐藏⬜）。
- **默认值**：新关联活动默认为「展示中」。

#### 3.4 子渠道（关联活动）编辑弹窗新增展示开关
- **位置**：关联活动管理弹窗 -> 点击编辑配置按钮 -> 编辑活动配置弹窗内，位于「报名费」下方、「前端展示时间」上方。
- **交互组件**：Tailwind Toggle Switch，与主渠道编辑弹窗风格一致。
- **状态联动**：开关文字状态联动逻辑与主渠道编辑弹窗一致。
- **新增/编辑模式**：
  - 新关联活动时，开关默认开启（展示中）。
  - 编辑已有活动时，打开弹窗根据当前活动的实际展示状态初始化开关位置。

### 4. 涉及页面文件
- `admin/02_渠道管理.html`：渠道列表、编辑弹窗、关联活动弹窗的统一变更。
