# 服务号消息类目模板配置对照表

依据：《20260816 服务号消息通知 PRD.md》§3.1（9 类消息定义）、§6.3（模板申请核对清单）；服务类目已选定 **工具 > 预约/报名**。

## 1. 通道划分（PRD §3.1 通道选择原则）

| 通道 | 消息 | 发送前提 |
|------|------|---------|
| 模板消息（5 条） | 报名成功、环境检测、照片不合格、电子证书可查、证书邮寄 | 用户已关注服务号 + 已绑定账号 |
| 订阅通知（4 条） | 测评前提醒、测评开始提醒、成绩公示、测评变更 | 用户对该模板有未消耗的订阅授权（报名成功页/绑定页订阅入口） |

## 2. 模板消息配置对照（5 条）

配置路径：公众平台 → 广告与服务 → 模板消息 → 类目模板库（工具 > 预约/报名 类目下）→ 搜索模板标题 → 详情页选关键词、排顺序 → 填场景说明 → 添加，取模板 ID 交研发对接。

### 2.1 报名成功

| 项 | 内容 |
|----|------|
| 触发点 | 支付回调确认成功（微信支付回调 / 支付宝回调 / 后台直接开通保存） |
| PRD 必填字段 | 测评名称、考生姓名、准考证号、测评时间（+温馨提示） |
| 模板库搜索词 | 报名成功通知 / 预约成功通知 |
| 关键词映射建议 | 活动名称→测评名称；预约人→考生姓名；预约编号→准考证号；预约时间→测评时间；备注→温馨提示 |
| 槽位需求 | 4-5 个 |

### 2.2 环境检测通知

| 项 | 内容 |
|----|------|
| 触发点 | 用户提交环境检测、结果生成时（通过/不通过都发） |
| PRD 必填字段 | 测评名称、检测结果、说明/指引（不通过时说明=不合格项、指引=重新检测） |
| 模板库搜索词 | 审核结果通知 / 检测结果通知 / 进度通知 |
| 关键词映射建议 | 项目名称→测评名称；审核/检测结果→检测结果；备注→说明或指引 |
| 槽位需求 | 3 个 |

### 2.3 照片不合格通知

| 项 | 内容 |
|----|------|
| 触发点 | 审核员在用户信息审核页判定「不合格」并保存时 |
| PRD 必填字段 | 测评名称、考生姓名、不合格原因、补交截止时间、补交方式（审核页无截止字段时改为「请尽快重新上传」） |
| 模板库搜索词 | 审核结果通知 / 审核失败通知 / 资料审核通知 |
| 关键词映射建议 | 项目名称→测评名称；提交人→考生姓名；审核结果→不合格；未通过原因→不合格原因；备注→补交截止+补交方式 |
| 槽位需求 | 4-5 个 |

### 2.4 电子证书可查通知

| 项 | 内容 |
|----|------|
| 触发点 | 电子证书签发完成、开放下载时 |
| PRD 必填字段 | 证书名称、获取方式 |
| 模板库搜索词 | 证书通知 / 发放通知 / 领取通知 |
| 关键词映射建议 | 证书/物品名称→证书名称；领取方式或备注→获取方式（点击查看并下载） |
| 槽位需求 | 2 个 |

### 2.5 证书邮寄通知

| 项 | 内容 |
|----|------|
| 触发点 | 管理端证书寄送录入物流单号时（物流平台无预计到达数据时改「已发货，请注意查收」） |
| PRD 必填字段 | 证书名称、快递公司、快递单号、预计到达时间（+温馨提示） |
| 模板库搜索词 | 发货通知 / 快递寄出通知 / 物流通知 |
| 关键词映射建议 | 商品/物品名称→证书名称；快递公司→快递公司；快递单号→快递单号；备注→预计到达+温馨提示 |
| 槽位需求 | 3-4 个 |

## 3. 订阅通知配置对照（4 条）

配置路径与模板消息**不同**：公众平台 → 订阅通知 → 模板库（同样按工具 > 预约/报名 类目）选用模板；且需在网页（报名成功页、绑定页，JS 安全域名下）挂订阅组件，用户点订阅授权后才可发送。

### 3.1 测评前提醒

| 项 | 内容 |
|----|------|
| 触发点 | 测评开始前 1 天 09:00（北京时间，定时任务扫描） |
| PRD 必填字段 | 测评名称、测评时间、注意事项 |
| 模板库搜索词 | 活动提醒 / 预约提醒 / 开考提醒 |
| 关键词映射建议 | 活动名称→测评名称；活动时间→测评时间；温馨提示→注意事项（提前 30 分钟进入候考页面） |

### 3.2 测评开始提醒

| 项 | 内容 |
|----|------|
| 触发点 | 测评开始前 30 分钟（定时任务扫描） |
| PRD 必填字段 | 测评名称、开始时间、进入方式 |
| 模板库搜索词 | 活动开始提醒 / 即将开始通知 |
| 关键词映射建议 | 活动名称→测评名称；开始时间→开始时间；备注→进入方式（点击详情进入候考页面） |

### 3.3 成绩公示提醒

| 项 | 内容 |
|----|------|
| 触发点 | 管理端开启成绩公示时，公示期内扫描下发 |
| PRD 必填字段 | 测评名称、公示开始时间、查询方式 |
| 模板库搜索词 | 结果公布通知 / 成绩发布提醒 / 公示通知 |
| 关键词映射建议 | 项目名称→测评名称；公布时间→公示开始时间；备注→查询方式（点击查看成绩） |

### 3.4 测评变更通知

| 项 | 内容 |
|----|------|
| 触发点 | 管理端修改测评时间或取消测评并保存时（取消时变更后信息=「本次测评已取消」，说明=退费指引） |
| PRD 必填字段 | 测评名称、变更类型（改期/取消）、变更后信息、说明 |
| 模板库搜索词 | 变更通知 / 改期通知 / 时间调整通知 |
| 关键词映射建议 | 活动名称→测评名称；变更内容→变更类型+变更后信息；备注→说明 |

## 4. 配置执行注意事项

1. **逐条核对**：上表搜索词是检索入口，实际模板标题、槽位数、每槽字段类型与长度以类目模板库搜索结果为准（PRD §6.3 要求核对结果记录：模板存在与否、模板编号、槽位数、每槽上限、模板类目）。
2. **无匹配模板时**：按运营规范提交新模板申请——标题以「通知/提醒」结尾、不带品牌、内容不超过 200 字符、中部 2-5 个关键词。
3. **关键词排序**：详情页内可自由挪动关键词顺序，按上表映射排，左侧预览确认。
4. **场景说明**：每个模板添加时必填，写实际用途（如「用于推送考试报名成功通知」）。
5. **模板数量**：账号同时可用 25 个模板，本方案 9 条，余量充足；改/删服务类目会连带删除该类目下已选模板，类目选定后不再动。
6. **发送前统一校验**（研发对接口径）：报名记录有效（已支付、未退款、未取消）+ 微信已绑定账号；模板消息额外要求仍关注服务号；订阅通知额外要求有未消耗订阅授权；按「消息类型+报名记录+触发批次」幂等去重；失败静默记日志不重试。
