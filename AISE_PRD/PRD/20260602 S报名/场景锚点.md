# 场景锚点：元创S营定制报名流程

> **产品定位**：元创S营是AISE与企业合作体系的线下训练营，需要在AISE官网搭建一套定制化报名流程。该流程具有通用性基础，后续其他合作方可能复用相似模式。

---

## 1. 目标场景

元创S营的招生报名全流程在AISE平台完成，包括：

- **前端报名**：三个通道（常规申报/人才库/专家推荐），用户选择通道后完成报名信息提交
- **后台审核**：运营团队审核报名信息，决定通过/不通过
- **笔试衔接**：审核通过后，用户进入指定考场参加笔试
- **结果反馈**：审核和笔试结果通过消息通知用户

## 2. 核心约束

| 约束 | 说明 |
|------|------|
| 费用 | 免费（无报名费） |
| 账号 | 用户需先注册AISE账号（或报名同时注册） |
| 审核 | 异步审核——提交后不即时反馈，显示"等待审核" |
| 笔试 | 同一考场（多个课题但一场考试） |
| 通用性 | 该流程框架可供后续其他合作方复用 |

## 3. 用户旅程

### 3.1 三个通道

```
独立入口页
├── 常规申报通道（核心）
│   → 选考生身份（本人/代报名）
│   → 填写报名表单
│   → 提交 → 等待审核
│   → 审核通过 → 进入笔试考场
│   → 审核不通过 → 收到通知
├── 人才库通道
│   → 输入证书编号（=身份证号）
│   → 校验
│   ├── 有数据 → 跳转常规通道（可预填部分信息）
│   └── 无数据 → 提示去常规通道
└── 专家推荐通道
    → 弹窗提示发送材料到官方邮箱
    → 审核结果邮件通知
```

### 3.2 与现有AISE报名流程的差异

| 维度 | 现有测评报名 | 元创S营报名 |
|------|------------|------------|
| 入口 | 活动详情页"立即报名" | 独立入口页，三个通道选择 |
| 费用 | 有报名费 | 免费 |
| 支付 | 需要支付流程 | 无支付 |
| 审核 | 支付成功即报名完成 | 异步审核，审核后分配考场 |
| 后台入口 | 11_报名管理 | 11_报名管理（加报名类型筛选） |

## 4. 关键设计原则

1. **独立页模式** — 三个通道的选择页面作为独立入口，通过首页导航配置访问
2. **优先复用** — 尽量复用现有AISE报名流程的结构（选考生身份、表单提交），减少定制开发
3. **MVP优先** — 表单字段先硬编码固定字段，后续迭代为可配置
4. **后台最小改动** — 在现有 `11_报名管理` 中扩展「报名类型」筛选，不新建独立页面

## 5. 涉及范围

| 端 | 涉及内容 |
|----|---------|
| **user 端（新增页面）** | 独立入口页（三通道选择）+ 常规申报流程适配（免支付+审核状态） |
| **admin 端（修改页面）** | `11_报名管理` 增加报名类型筛选 + 审核操作列 |
| **user 端（修改页面）** | 首页导航配置入口链接 |
| **user 端（复用页面）** | `10_选择考生身份`、`09_填写信息`（部分适配） |
