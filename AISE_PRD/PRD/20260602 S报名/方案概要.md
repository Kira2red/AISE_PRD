# 方案概要：元创S营定制报名流程

> 版本：v1.0 | 日期：2026-06-02 | 状态：概要确认

---

## 1. 概述

### 1.1 项目背景与目标

元创S营是AISE与企业合作体系下的线下训练营项目，本次项目目标是在AISE官网搭建一套定制化报名流程，实现前端三通道报名、后台异步审核、审核通过后分配笔试考场的能力，同时保持流程的通用性框架，便于后续其他合作方复用。

### 1.2 三通道用户旅程概述

**常规申报通道**是核心流程。用户从独立入口页点击「常规申报」卡片后，先选择考生身份（本人报名或代他人报名），然后填写报名表单，提交后系统显示「等待审核」状态。运营人员在后台审核报名信息，审核通过的用户可参加统一笔试考场，审核不通过的用户收到包含驳回原因的通知，并可修改信息后重新提交。

**人才库通道**是为已进入人才库的考生提供的快捷通道。用户在独立入口页点击「人才库」卡片后，弹窗提示输入证书编号（证书编号即身份证号）。系统校验该编号是否存在于人才库中：若存在，则跳转至常规申报通道，并将已有信息预填入报名表单，用户补充剩余信息后提交；若不存在，则提示用户人才库中无此记录，请转至常规申报通道报名。

**专家推荐通道**是为通过专家推荐方式参与的考生提供的特别通道。用户在独立入口页点击「专家推荐」卡片后，弹窗提示用户将推荐材料发送至官方邮箱 csiaetc@csia.org.cn，并在邮件主题中注明"元创S营专家推荐+姓名"。审核结果将通过邮件通知用户，系统端无需进一步操作。

## 2. 前端页面方案（user端）

### 2.1 独立入口页（新页面：24_元创S营报名）

该页面为AISE官网新增的独立页面，页面路径通过首页导航配置入口链接访问。

页面上展示大标题，标题文案为「元创S营报名」或运营可配置的名称。标题下方有一段引导文案，简要说明元创S营是什么以及用户可以选择哪种方式报名。

页面主体区域展示三个选择卡片，每个卡片包含：
- 卡片标题（如「常规申报」「人才库」「专家推荐」）
- 卡片摘要说明文字，简要介绍该通道的适用场景
- 可点击区域，点击触发对应通道的交互

页面底部可配置温馨提示或注意事项文案。

#### 三个卡片的交互逻辑

**卡片一：常规申报**
- 用户点击后直接进入常规申报流程，跳转至「选择考生身份」页面（10_选择考生身份）
- 该卡片上标注「最常用」或「推荐」标识引导用户优先选择

**卡片二：人才库**
- 用户点击后弹出居中弹窗，弹窗内提示「请输入您的证书编号」，下方提供一个文本输入框
- 输入框下方有「确认」和「取消」两个按钮
- 用户输入证书编号后点击确认，系统进行校验
- 若校验通过，关闭弹窗并跳转至常规申报表单页面，自动填入姓名、身份证号等已有信息，用户补充剩余字段后提交
- 若校验不通过，弹窗内显示提示文案「您提供的证书编号在人才库中未查询到记录，请返回选择常规申报通道报名」，并提供「返回」按钮让用户关闭弹窗回到入口页

**卡片三：专家推荐**
- 用户点击后弹出居中弹窗，弹窗内显示引导文案：「请您将推荐材料发送至官方邮箱 csiaetc@csia.org.cn，邮件主题请注明"元创S营专家推荐+您的姓名"，审核结果我们将通过邮件通知您。感谢您的参与！」
- 弹窗底部仅提供一个「我知道了」或「关闭」按钮，点击后关闭弹窗，用户回到入口页

### 2.2 常规申报流程

#### 前置：未登录用户处理

用户点击「常规申报」卡片后，系统首先检测当前用户是否已登录：
- 已登录：直接进入选考生身份页面
- 未登录：跳转至登录/注册页面（01_登录注册），用户完成登录或注册后，自动回跳至选考生身份页面继续报名流程

#### 步骤一：选择考生身份（复用现有 10_选择考生身份）

从独立入口页点击「常规申报」后，进入现有页面 `10_选择考生身份`，该页面展示当前账号关联的考生列表。

- 如果账号下只有一个考生，系统跳过选择步骤，直接进入填写表单页面
- 如果账号下有多个考生（如张三、李四等家庭考生），页面以卡片列表形式展示所有关联考生，由用户选择本次报名针对的考生
- 如果账号下尚无关联考生，提供「关联新考生」的操作入口

该页面完全复用现有能力，无需改动。

#### 步骤二：填写报名表单

选择考生身份后，进入报名表单页面。本期 MVP 阶段表单字段为固定硬编码，具体字段清单待运营老师确认后补充。

表单底部包含「证件照上传」组件，复用现有 12_照片选择器 的能力，用户点击上传按钮从本地选择照片，上传后展示缩略图，支持重新上传和删除。该组件为非必填项，用户可选择不上传。

表单底部有「提交」按钮。用户填写完整并点击提交后，系统执行表单必填项校验和格式校验，校验通过则提交报名数据。

#### 步骤三：提交后的等待审核页面

用户成功提交报名信息后，系统跳转至一个新的结果页，页面展示以下内容：

- 成功提示图标或视觉标识
- 文案：「报名信息已提交，请耐心等待审核。审核结果将通过消息通知您。」
- 页面可提供「返回首页」或「查看我的报名」的操作入口

#### 后续：审核状态查看

用户提交报名后，可以在「我的活动」或「我的考试」相关页面中查看该报名的审核状态。状态标签分为三种：
- 待审核：显示「审核中」状态
- 审核通过：显示「审核通过」，并展示考场名称、考试时间等信息
- 审核驳回：显示「审核未通过」，并提供查看驳回原因和「重新提交」的操作入口

审核不通过的用户点击「重新提交」后，可进入报名表单页面修改已有信息，修改后重新提交。重新提交后审核状态恢复为「待审核」。

### 2.3 人才库通道交互

参照 2.1 节中「卡片二：人才库」的描述，人才库通道的完整交互流程如下：

用户在入口页点击「人才库」卡片 → 弹出证书编号输入弹窗 → 用户输入证书编号（身份证号）并确认 → 系统向后端发起校验请求 → 分两种结果：

- 结果一（校验通过/存在记录）：弹窗关闭，系统自动跳转至常规申报流程的「填写报名表单」页面，表单中预填以下信息：姓名、身份证号、性别等人才库中已有的字段。用户补充剩余必填字段（如年级、手机号、监护人信息等）后，点击提交按钮完成报名。
- 结果二（校验不通过/无记录）：弹窗内提示「您提供的证书编号在人才库中未查询到记录，请返回选择常规申报通道报名」，弹窗底部显示「返回」按钮。用户点击「返回」后弹窗关闭，页面停留于独立入口页。

### 2.4 专家推荐通道交互

参照 2.1 节中「卡片三：专家推荐」的描述，专家推荐通道的完整交互流程如下：

用户在入口页点击「专家推荐」卡片 → 弹出信息提示弹窗 → 弹窗内展示以下完整文案：

「专家推荐通道说明：请您将推荐材料（包括但不限于专家推荐信、个人简历、相关证明材料等）发送至官方邮箱 csiaetc@csia.org.cn。邮件主题请注明：元创S营专家推荐+您的姓名。审核结果我们将通过邮件回复通知您。如有疑问，可联系客服咨询。感谢您的参与！」

弹窗底部仅提供「我知道了」按钮，用户点击后弹窗关闭，页面停留于独立入口页。后续所有交互通过邮件进行，系统端不再处理该通道的报名数据。

## 3. 后台管理方案（admin端）

### 3.1 报名管理页改造（11_报名管理）

现有后台页面 11_报名管理 进行改造，原有测评报名相关功能保持不变，在其基础上扩展定制报名相关的管理能力。

#### 新增「报名类型」筛选

页面顶部筛选条件区域增加一个「报名类型」下拉筛选框，选项为：
- 「全部」（默认值）
- 「测评报名」
- 「定制报名」（对应元创S营报名数据）

选择「全部」时，页面同时展示测评报名和定制报名两类数据；选择「测评报名」或「定制报名」时，仅展示对应类型的数据。

筛选条件切换后，表格列表内容根据筛选结果刷新展示。

#### 定制报名表格列

当用户选择「定制报名」或「全部」且数据中包含定制报名记录时，表格中展示以下列信息：
- 报名编号：系统生成的唯一编号
- 姓名：报名表单中的考生姓名
- 身份证号：报名表单中的考生身份证号
- 联系方式：报名表单中的手机号
- 报名通道：显示该报名来自哪个通道，展示为「常规申报」「人才库」或「专家推荐」
- 提交时间：用户提交报名的时间
- 审核状态：展示状态标签，分为「待审核」「通过」「驳回」三种
- 操作：每行记录末尾提供操作按钮，包括「查看详情」「通过」「驳回」

#### 审核操作流程

**审核通过操作**：运营人员在操作列点击「通过」按钮，系统弹出确认弹窗，提示「确认通过该报名申请？」。运营点击确认后，系统执行以下动作：
- 将该条报名记录的审核状态更新为「通过」
- 系统向用户发送审核通过通知，通知内容包含通过信息及分配的笔试考场详情
- 用户端对应报名记录状态同步更新为「审核通过，已分配考场」
- 状态变更日志记录操作人、操作时间和操作内容

**审核驳回操作**：运营人员在操作列点击「驳回」按钮，系统弹出带文本输入框的弹窗，要求运营填写驳回原因。驳回原因必填，需输入不少于5个字符的说明文字。运营填写原因后点击确认，系统执行以下动作：
- 将该条报名记录的审核状态更新为「驳回」
- 系统向用户发送审核不通过通知，通知内容包含驳回原因说明
- 用户端对应报名记录状态同步更新为「审核未通过」，并可查看驳回原因
- 状态变更日志记录操作人、操作时间和操作内容

#### 审核详情查看

运营人员在操作列点击「查看详情」按钮，系统以弹窗或侧边抽屉形式展示该条报名记录的完整信息，包括：
- 报名编号、报名通道、提交时间
- 考生基本信息：姓名、身份证号、性别、年级、手机号
- 监护人信息：监护人姓名、监护人手机号
- 证件照（如有上传则展示缩略图，可点击查看大图）
- 审核状态及历史审核记录（操作人、操作时间、审核结果、驳回原因）

### 3.2 通知机制

审核结果通过用户端消息通知推送。AISE 现有 admin 端消息中心（19_消息中心）支持系统通知，用户端个人中心已有审核结果通知的展示区域（证件照审核场景），可复用同一通知体系。

通知逻辑如下：

- **审核通过通知**：发送时机在运营点击「通过」确认后。通知标题为「元创S营报名审核通过」，通知正文包含：用户姓名、审核通过提示、笔试考场名称和考试时间、进入考场的入口指引。用户在通知中可点击链接直接进入考场。
- **审核驳回通知**：发送时机在运营点击「驳回」确认后。通知标题为「元创S营报名审核未通过」，通知正文包含：用户姓名、审核未通过提示、驳回原因、重新提交入口链接、如有疑问可联系客服的提示。

## 4. 考场方案

本期仅一个统一笔试考场，所有审核通过的考生自动报名至该考场。具体规则如下：

- 该考场在AISE系统中属于元创S营对应的测评下的考场资源，不区分课题/方向，所有考生在同一时间地点参加笔试。
- 考场信息包含考场名称、考试日期、考试时间、考试地点等，在审核通过通知和用户端状态中展示。
- 不存在考场分配或自选逻辑——审核通过即代表已报名该考场，用户在「我的考试」中可直接看到考场入口。
- 若后续需要支持多个考场，需单独迭代。

## 5. 不做范围（本期排除）

以下功能不在本期 MVP 范围内，明确排除：

- **表单字段可配置**：本期报名表单字段为硬编码固定（待运营老师确认字段清单后补充），不支持后台动态配置。后续迭代中评估是否支持可配置。
- **多个训练营管理**：本期仅元创S营一个训练营项目，后台不处理同时管理多个训练营的场景。后续其他合作方接入时再扩展。
- **支付相关**：本期报名免费，不涉及任何支付流程。
- **多个考场自选**：本期仅一个统一考场，不提供考场选择和切换逻辑。
- **专家推荐的后台管理**：专家推荐通道的报名数据不进入系统后台报名管理列表，该通道的审核和沟通通过邮件进行，系统端不处理。
- **短信/邮件通知通道**：本期通知仅通过AISE站内消息推送，不接入短信或邮件发送通道（专家推荐除外，其审核结果邮件通知由运营手动处理）。

## 6. 验收标准

方案交付时满足以下条件视为验收通过：

| 编号 | 验收项 | 预期结果 |
|------|--------|---------|
| 1 | 独立入口页展示三个通道卡片 | 页面正常展示「常规申报」「人才库」「专家推荐」三个卡片，点击各自触发对应交互 |
| 2 | 未登录用户引导 | 未登录用户点击报名后跳转至登录/注册，完成后回跳至报名流程 |
| 3 | 常规申报全流程 | 选身份→填表单→提交→等待审核页面，流程完整闭环 |
| 4 | 人才库校验分流 | 输入存在的人才库编号→跳转预填表单；输入不存在的编号→提示返回 |
| 5 | 专家推荐弹窗 | 点击卡片弹出包含邮箱信息和引导文案的弹窗，关闭后回入口页 |
| 6 | 后台「报名类型」筛选 | 11_报名管理页面可下拉筛选「全部/测评报名/定制报名」，筛选正常工作 |
| 7 | 后台审核通过 | 审核通过后用户收到通知，状态变更为「通过」，考场信息正确展示 |
| 8 | 后台审核驳回 | 审核驳回后用户收到通知和驳回原因，状态变更为「驳回」，可点击「重新提交」 |
| 9 | 审核不通过重新提交 | 驳回状态的报名，用户可修改信息后重新提交，状态恢复为「待审核」 |
| 10 | 考场展示 | 审核通过后，用户在「我的考试」中可看到考场名称、考试时间等信息 |
| 11 | 免支付 | 提交报名无需支付，无支付页面出现 |
| 12 | 首页导航入口 | 首页导航可配置进入独立入口页的链接 |
