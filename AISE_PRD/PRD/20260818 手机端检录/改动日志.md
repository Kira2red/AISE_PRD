# 改动日志 — 手机端检录（20260818）

## 模块

AISE 手机监考通道新增「手机端检录」：云端开检录功能 + 考生扫码用手机监考时，进手机监考直播页之前先插入「手机检录页」（前置自拍正面照 + 检录视频），检录三态沿用线上（强制 / 非强制 / 不开启）。

## 涉及文件

- 新增 PRD：`AISE_手机端检录_PRD.md`（§0-§9 结构，功能型）
- 新增方案稿（产品大师中间产物）：`S1_方案V1/V2/V3.md`、`S2_方案V1/V2/V3.md`
- 新增审查记录：`S1_审查结果_第1/2轮.md`、`S2_审查结果_第1/2轮.md`
- 索引更新：`Functional_Specs/AISE&爱测评平台能力梳理.md`（能力概述 + 页面树 + 功能明细 + 附录统计 user 28→29、合计 93→94）

## 关键决策（用户拍板）

1. 页面顺序方案 A：扫码 → 检录页 → 引导页 → 直播页
2. 检录配置沿用线上三态（强制 / 非强制 / 不开启），非强制有「跳过」
3. 双重检录不去重：扫码即进检录页，不查电脑摄像头状态
4. 拍照即上传（照片）；视频录制完成即上传
5. 检录前置自拍 / 直播后置推流
6. 检录记录追加保留（带来源通道），生效取最后一次
7. 去向：检录完成/跳过 → 引导页（不经候考流程）
8. 仅实时拍摄、禁用相册/滤镜

## 遗留事项（待确认 10 项，详见 PRD §9.3）

1. 线上检录照片/视频规格 + 上传接口/存储/鉴权 + 视频是否含音频
2. 检录结果存储改造（来源通道字段 + 追加保留 + 半完成态查询）
3. 电脑端「进入测评」对手机检录结果的消费逻辑
4. 检录三态配置读取接口与实时性
5. 强制档兜底/豁免（含开考后）
6. 双重检录记录监考端展示规则
7. 视频录制兼容性（iOS 14.5 以下老机型）
8. 取景框比例差异（原型 3:4 vs 方案 4:3）+ 视频步骤补齐
9. 跳过按钮位置/文案 + 权限「去设置」引导
10. 「开始录制检录视频」步骤是否简化
