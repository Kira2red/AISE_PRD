## 一、模型口径先对齐（关键变化）

**用户现状口径（2026-09-12）**：活动 → N 个分组 → N 场考试 → 每场考试含正式考 +（可选）模拟考；正式考与模拟考的**试卷、监考配置可能不同**。

| 层级 | 本方案口径 | 与存量的差异 |
|---|---|---|
| 活动 | 组织主体（名称+起止时间） | 不变 |
| **分组** | **挂在活动下**（活动内分区组织考试） | 🔴 变化：存量分组挂渠道下（20260826 口径）。分组成为活动的内部层级，渠道关联只到考试粒度 |
| 考试 | 分组下的一场考试，含正式考+模拟考 | 分组来源从渠道改为活动 |
| 渠道 | 考试×渠道的报名侧关联（矩阵列） | 渠道下不再有分组 |

> ⚠️ 待拍板 0：分组从「渠道下」移到「活动下」是模型级变化，影响报名页展示（用户选分组→考试）与 20260826 渠道分组 PRD。**请确认这个理解正确后再开工。**

「一个活动下有哪些分组、哪些考试」即由本批量创建流程产出：**建分组 → 分组内批量建考试**，全部配置动作都在活动详情页完成。

## 二、存量批量创建（20260908 3.4）的问题清单

| # | 问题 | 明细 |
|---|---|---|
| 1 | **没有「分组」维度** | 考试行直接平铺，用户现状「活动→分组→考试」的分组归属无处配置 |
| 2 | **模拟考字段大量缺失** | 只有：模拟卷、模拟考交卷时间限制（批量弹窗里连模拟考起止时间/次数都没有；demo 33 里有但表单没有）。缺：**模拟考起止时间、次数限制、模拟考自己的监考配置（10 项监考里模拟考可独立配置）** |
| 3 | **模拟考与正式考只能同配置** | 公共配置里一份监考配到底；用户明确「正式考和模拟考的试卷、监考配置可能都不一样」 |
| 4 | **不需要的字段混入** | 批量创建里放「成绩/分数/读题开关、检录视频引导文案、检录视频示意图、证书落款」等低频细节——这些是单条编辑的精度，批量场景徒增表单长度（评委说「乱」的来源之一） |
| 5 | **渠道关联与考试创建耦合在一步** | 第 3 段渠道×分组勾选嵌套复杂；分组改挂活动后，渠道关联回归矩阵页（前一方案 4.1），批量创建不再承担 |

## 三、新批量创建设计

### 3.1 入口与层级

活动详情页 →「批量创建」→ 弹窗（全屏抽屉式）。**四步向导**：

```
第1步 选分组 → 第2步 考试清单 → 第3步 正式考配置 → 第4步 模拟考配置 → 提交
```

### 3.2 第 1 步：选择/新建分组

- 展示活动下已有分组（勾选，可多选）：本次创建的考试归入所选各分组
- 「新建分组」内联输入（名称必填、活动内不重名）
- 可同时勾选多个分组 = 同一批考试复制到多个分组（每分组各生成一套考试）

### 3.3 第 2 步：考试清单（本次建哪几场）

每行一场考试，字段收紧为 4 个：

| 字段 | 必填 | 说明 |
|---|---|---|
| 考试名称 | ✓ | 支持「名称+序号」批量生成（如「Python一级」× 3 场 → 自动 -第1场/-第2场/-第3场） |
| 开始时间 | ✓ | |
| 结束时间 | ✓ | 校验晚于开始 |
| 关联试卷 | 可空 | 行内可选专属试卷；留空则用第 3 步的公共试卷 |

支持添加行 / 删除行 / 复制行（名称时间顺延）/ 时间自动顺延（勾选后按间隔生成）。

### 3.4 第 3 步：正式考配置（公共 + 覆盖）

**高频公共项**（放表单主体，填一次全体生效）：

| 字段 | 必填 | 缺失修复 |
|---|---|---|
| 关联试卷 | 行内全空时必填 | 不变 |
| 时长 / 交卷限制 | ✓ | 不变 |
| 标签 | 可空 | 改为**下拉多选**（会议决议：标签必须下拉） |
| 摄像头 / 录屏 / 检录照片 | ✓（默认强制开启） | 三档下拉，一行三项紧凑排 |
| 候考时长 | 可空 | 默认不开启 |

**收进「更多设置」折叠区**（批量场景低频，单条编辑可再精调）：手机监考、成绩/分数/读题开关、检录视频引导文案、检录视频示意图、测评描述、证书落款时间。

### 3.5 第 4 步：模拟考配置（修复重点）

| 字段 | 必填 | 说明 |
|---|---|---|
| 开启模拟考 | — | 总开关；不开启则跳过本步 |
| 模拟卷 | 开启时✓ | 可与正式卷不同 |
| **模拟考起止时间** | 开启时✓ | 🔴 存量表单缺失 |
| **次数限制** | 开启时✓ | N 次 / 无限次；🔴 存量表单缺失 |
| 模拟考交卷时限 | 可空 | 分钟，空=不限 |
| **监考口径** | 开启时✓ | 单选：**跟随正式考 / 自定义**（🔴 存量表单缺失）。自定义时展开与第 3 步同构的监考表单（摄像头/录屏/检录照片/候考/手机监考/成绩/分数/读题）——依据监考配置迁移方案「模拟考监考默认读正式考、可改、可一键恢复」 |

### 3.6 提交与结果

- 提交前汇总预览：「将为【分组 A、B】创建 N 场考试（含模拟考 M 场），并按第 5 步矩阵关联渠道」
- 创建 = 分组归属落位 + 考试生成 + 自动创建爱测评考试（正式考 + 模拟考各自创建）；失败行存「未关联」可补建，不回滚整批
- 异步执行，消息中心通知 + 成功/失败明细下载
- **渠道关联不在本表单**：创建完成后回矩阵页，用「勾选行 + 添加渠道」完成（职责分离，表单瘦身）
