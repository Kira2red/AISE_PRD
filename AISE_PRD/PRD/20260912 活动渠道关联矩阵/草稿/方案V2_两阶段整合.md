## 一、总体流程图（用户视角）

```
第 1 步  建活动            「2026年9月常规考」（名称 + 起止）
           │
第 2 步  建分组（可选）     3月批 / 6月批 …（不建分组 = 全部考试在「未分组」）
           │
第 3 步  建考试            每场考试：正式考全套 + 模拟考（可选，独立配置）
           │                ← 阶段一结束：考试模型就绪，尚无任何渠道可报名
           ▼
第 4 步  关联渠道          矩阵二维图：批量添加 / 批量修改 / 批量删除
                            每个格子：报名费、展示开关、展示时间、报名可见性
```

阶段一完成时状态明确提示：「考试模型已就绪，尚未关联渠道，前端不可见」——给运营一个明确的「准备好了吗」检查点，之后才进入阶段二。

## 二、阶段一：考试模型（3 步向导）

### 第 1 步：创建活动

- 输入：活动名称、开始日期、结束日期
- 极简两字段，创建即进入活动详情

### 第 2 步：添加分组（非必须）

- 分组管理面板（活动详情页侧栏或顶部 Tab）：新建 / 重命名 / 排序 / 删除（有考试的分组不可删）
- **分组可选**：不建分组时所有考试归入「未分组」（系统默认区，置灰不可改名）
- 分组在活动内唯一；**所有渠道看到的分组一致**（决策 #2）
- 分组顺序 = 矩阵行分区顺序 + 用户端展示顺序

### 第 3 步：批量创建考试（核心交互，分两小步）

**入口**：某分组分区的「+ 批量创建考试」；或顶部按钮后先勾选目标分组。

**3a. 考试清单**（建哪几场）

- 每行一场考试：考试名称、开始时间、结束时间（3 字段）
- 批量生成器：输入名称 + 场数 + 起始时间 + 场间隔 → 自动展开 N 行（名称自动 -第1场/-第2场，时间自动顺延）——**多场同构考试是主场景，生成器前置**
- 行内可改任意字段；可再加空行
- 勾选目标分组（本批考试落位哪些分组；多选 = 每组各生成一套）

**3b. 考试配置**（这批考试长什么样，正式考 + 模拟考两次配置）

- **正式考**：
  - 基础：关联试卷（必填，可被行内覆盖）、时长、交卷限制、标签（下拉多选）
  - 监考（8 项）：摄像头/录屏/检录照片（三档）、候考时长、手机监考、成绩/分数/读题开关
  - 低频折叠：检录引导文案、检录示意图、测评描述、证书落款
- **模拟考**（总开关）：
  - 开启后：模拟卷（可与正式卷不同）、起止时间、次数限制（N 次/无限次）、交卷时限
  - 监考口径：**跟随正式考 / 自定义**（自定义展开与正式考同构的 8 项）
- 布局：左右分步或上下分节，**严禁全平铺**；每节完成打勾

**提交后**：生成考试（含爱测评自动创建，失败行「未关联」可补建）→ 考试模型就绪提示

## 三、阶段二：渠道关联矩阵（活动详情主体页）

### 3.1 矩阵形态

```
              │ 猿编程        │ 核桃编程      │ 编程猫        │ [+ 添加渠道]
──────────────┼───────────────┼───────────────┼───────────────┤
【3月批】      │               │               │               │
 Python一级   │ ✓ ¥300        │ ✓ ¥300 🔒隐   │ ○             │
 图形化一级   │ ✓ ¥280        │ ○             │ ✓ ¥280        │
【6月批】      │               │               │               │
 Python二级   │ ✓ ¥320        │ ○             │ ○             │
```

- **行** = 分组分区 × 考试（行头：勾选框、考试名称+ID、标签、考试时间、报名量、爱测评状态、行尾「…」菜单）
- **列** = 渠道（表头：渠道名+号、列勾选框；列宽适中、横向滚动）
- **单元格**三态：
  - 已关联：**报名费为主信息**（如「¥300」）；隐藏报名行右上角「隐」角标（决策 #6：隐藏时展示开关/展示时间不参与控制，格子不出现「展示中/隐藏中」字样，避免误导）
  - 未关联：浅灰空格 + 悬浮「关联」
  - 创建失败：红色角标 + 悬浮原因
- **格子点击** = 单条关联配置弹窗（见 3.4）

### 3.2 批量添加渠道（专门设计的弹窗，非简单确认）

**入口**：勾选行/整组/全选 → 工具条「+ 添加渠道」

弹窗分两步（步骤条）：

**Step 1 选渠道**
- 渠道列表多选（卡片式，含渠道名/码/已关联考试数）
- 已与全部勾选行存在关联的渠道置灰标「已全部关联」

**Step 2 配置报名**（本步是复杂配置区，不是确认页）
- 每个所选渠道一张配置卡，卡片内：
  - **报名费**（必填，默认带出该渠道上次使用价；支持「应用到全部渠道」）
  - **前端展示**：开关 + 展示时间（起止/永久有效）——可勾「默认开启不设时间」
  - **报名可见性**：默认「正常报名」且**不可在此切隐藏**（隐藏报名涉及链接生成与失效，只允许单格操作——防误伤）
- 卡片顶部汇总条：「将为 12 场考试 × 2 个渠道生成 24 条关联」
- 提交 → 已存在的关联跳过不覆盖 → 结果「新增 20 条，跳过 4 条（已存在）」

### 3.3 批量修改渠道配置

**入口**：勾选行 →「修改渠道配置」→ 先选一个渠道（单选）→ 弹窗配置（同 3.2 Step 2，但带出当前值）

- 只改所选行在该渠道上的：报名费、展示开关、展示时间
- 汇总条：「将修改 12 条关联的报名费」；锁定行（已有报名的报名费锁不锁由线上现状，默认可改价不溯及已报名订单）跳过并计数提示

### 3.4 批量删除渠道关联（含隐藏报名保护）

**入口**：勾选行 →「解除渠道关联」→ 选渠道（多选）→ **确认页列出影响清单**：

- 将删除 N 条关联（按渠道分组计数）
- ⚠️ 其中 M 条已有报名：默认跳过（可勾选「连同报名记录处理」由研发评估，默认不可）
- ⚠️ 其中 K 条为隐藏报名：删除后定向链接永久失效，已发出的链接将无法报名（用户已确认可接受，仍需明示）
- 输入确认或二次点击后执行

### 3.5 单格点击：单条关联配置弹窗

- 报名费、前端展示开关 + 展示时间、报名可见性（正常/隐藏）
- 切「隐藏报名」→ 展示开关/展示时间区块**收起消失**（决策 #6），出现定向链接区块（只读+复制+二维码）
- 底部显示该关联的报名量；已有报名时报名费修改弹提示「不溯及已有订单」

### 3.6 行「…」菜单（考试级操作）

详情（跨渠道全配置抽屉）/ 复制考试 / 编辑考试（阶段一配置的整体编辑，正式考+模拟考）/ 解除全部渠道关联（危险，二次确认）

## 四、权限与状态小结

| 配置 | 阶段 | 粒度 |
|---|---|---|
| 名称/时间/试卷/监考/模拟考/标签 | 一（批量创建/编辑考试） | 考试 |
| 分组 | 一（分组管理+创建时落位） | 活动 |
| 报名费/展示开关/展示时间 | 二（矩阵格子/批量弹窗） | **考试×渠道** |
| 报名可见性（隐藏报名）+定向链接 | 二（**仅单格**） | **考试×渠道** |

## 五、用户端影响（待研发评估，不在本 PRD 展开）

分组改挂活动下后，报名页「机构→分组→考试」两级下拉的分组数据源变化。产品口径：**选机构后，按分组分节展示考试卡片（分组顺序=阶段一配置顺序，各渠道一致）**，分组不再作为必选下拉。具体交互在报名端改版 PRD 细化。

## 七、按钮位置（已拍板）

「+ 添加渠道」按钮**不占矩阵列**：单独放在矩阵上方的工具条（筛选器同行右侧）。矩阵本身不放占位列——很多老师屏幕小，横向空间留给渠道列。

**补充「发现性」兜底**：当活动下还没有任何渠道关联时（空矩阵），矩阵中央显示引导空态「尚未关联渠道，点击右上角『+ 添加渠道』开始」，解决新活动用户找不到入口的问题。
