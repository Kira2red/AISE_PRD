# AISE 活动管理与渠道关联矩阵 PRD

> 需求文件夹：20260912 活动渠道关联矩阵 ｜ 2026-09-13 定稿（同日多轮迭代，V1.1）
> 权威依据：[活动渠道关联矩阵_方案定稿V3.md](<./活动渠道关联矩阵_方案定稿V3.md>)（16 条拍板闭环）
> 原型：[32_活动管理.html](<../../html/admin/32_活动管理.html>) · [35_渠道关联矩阵.html](<../../html/admin/35_渠道关联矩阵.html>)（本需求后续修改直接基于此正式库文件）

## 1. 背景与收益

本次改版把业务流程拆为「先建测评模型、再关联渠道」两个阶段：

- 矩阵只承载渠道关联覆盖一个信息，配置全部收进弹窗。
- 运营建活动的路径从「一张大表里找列」变为「按流程两步走」。
- 渠道侧配置按测评×渠道粒度精确到格，隐藏报名等危险开关与批量操作隔离。

## 2. 业务流程

```
第 1 步  建活动            名称 + 起止日期
   │
第 2 步  建分组（可选）     不建分组 = 全部测评归「未分组」
   │
第 3 步  批量创建测评       测评清单 → 正式考配置 → 模拟考配置
   │                       ← 阶段一结束：测评模型就绪，尚无渠道可报名
   ▼
第 4 步  关联渠道           矩阵二维图：批量添加 / 批量修改 / 批量删除
                           每格子：报名费、展示开关、展示时间、报名可见性
```

阶段一完成时提示「测评模型已就绪，尚未关联渠道，前端不可见」，作为运营检查点。

## 3. 详细功能说明

### 3.1 活动管理（admin/32）与活动详情（admin/33）

页面框架与线上后台同构：左侧 `w-64` 菜单（测评管理／活动管理／标签配置｜运营中心｜考务与用户），顶栏 `h-16`，主区浅灰底。

- 32 为活动列表页，点击行进入 33 活动详情独立页。
- 渠道关联是活动管理的子功能：侧栏无独立菜单项，入口为 33 详情页顶栏「渠道关联」按钮。

#### 3.1.1 活动列表

| 元素 | 说明 |
|---|---|
| 筛选区 | 活动名称搜索、状态筛选 |
| 列表列 | 活动名称、起止日期、分组数、测评数、状态、操作 |
| 操作 | 点击行或「进入」按钮跳转 33 活动详情独立页（URL 带 act 参数） |

#### 3.1.2 新建活动

输入活动名称、开始日期、结束日期，提交后留在列表页并提示「点击行进入详情」。

#### 3.1.3 活动详情（admin/33，树状表格）

分组与测评合并为层级树状表格，替代旧的独立分组区块：

| 行类型 | 展示                                                                                                                                                                                                       | 交互                  |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- |
| 分组行 | 勾选框 + 分组名 + 场次数，顶格加粗                                                                                                                                                                                     | 点击改名；悬浮出现排序、添加测评、删除 |
| 测评行 | 6 列结构，整体缩进体现层级（明细见下） | 勾选后顶栏浮现「批量修改 (N)」 |

测评行列结构明细：

- 勾选框 + 测评名称（含编号）+ 测评时间。
- **正式考配置**格：
  - 试卷标签（绿底；待关联=琥珀底）。
  - 监考四项：摄像 / 录屏 / 检录 / 手机。
  - 候考时长。
- **模拟考配置**格（三行）：
  - 第一行：模拟卷标签（蓝底；未关联试卷时标「模拟卷未关联」）。
  - 第二行：起止时间 + 次数限制。
  - 第三行：模拟考监考四项开关（摄像 / 录屏 / 检录 / 手机）。
  - 未开启时仅灰字「未开启」。
- **渠道操作**列：
  - 渠道数。
  - 「编辑」直入按钮。
  - 「…」菜单（复制 / 补关联试卷 / 删除）。|

- 删除分组：仅允许删除无测评的分组；有测评的分组删除按钮置灰并提示。
- 未分组：不建分组时所有测评归「未分组」系统默认区，置灰不可改名。
- 分组顺序即矩阵行分区顺序，也是用户端展示顺序；所有渠道看到的分组一致。
- 批量修改（diff 式）：
  - 弹窗 860px，各设置项默认「保持原值」，修改了才生效；无复选框。
  - 底部实时计数「将修改 N 个设置项」，0 改动时应用按钮置灰。
  - 分区顺序：试卷与标签（正式）→ 测评时间与要素（正式）→ 正式考监考 → 模拟考（整段殿后）。
  - 模拟考段含独立的模拟卷、起止时间、次数限制与监考 8 项。

#### 3.1.4 批量创建测评（两步向导）

入口：分组分区「+ 添加测评」或顶栏按钮（先勾选目标分组）。

**第一步 测评清单**（建哪几场）：

| 项 | 规则 |
|---|---|
| 测评行字段 | 测评名称 + 正式考开始/结束 + 模拟考开始/结束，共 5 字段（模拟考时间在本步逐场配置，第二步不再重复配置） |
| 批量生成器 | 名称 + 场数 + 起始时间 → 自动展开 N 行（名称-第1场/-第2场…，正式考时间固定 30 分钟顺延，模拟考时间同步顺延） |
| 行操作 | 行内改任意字段、加空行、复制行 |
| 目标分组 | 下拉多选（token 样式），多选 = 每组各生成一套 |
| 试卷 | 留空可创建，状态「待关联试卷」，创建后可补 |

**第二步 测评配置**（正式考在前、模拟考整段殿后）：

| 分区 | 字段 |
|---|---|
| 正式考·基础 | 关联试卷（可搜索下拉，选中即替换、可清空；清空提示「待关联试卷」）、测评时长、交卷限制、标签（下拉多选，选完不收起） |
| 正式考·监考 | 摄像头 / 录屏 / 检录照片（三档）、候考时长、手机监考、成绩开关、分数开关、读题开关，共 8 项 |
| 正式考·更多设置（折叠） | 检录视频引导文案、检录视频示意图（文件上传）、测评描述（多行可拉伸）、证书落款 |
| 模拟考（总开关） | 开启后展开：模拟卷（可搜索下拉）、次数限制（N 次 / 无限次）、交卷时限、监考 8 项（默认带出正式考值 + 「重置为正式考配置」链接）。模拟考起止时间已在第一步逐场配置，此处不重复出现 |

提交后生成测评（含爱测评自动创建；失败行标红「未关联」，可补建不回滚）。

弹窗内控件规范：定高 36px；label 单行，长说明改灰色小字后缀（如「关联试卷 *选中即替换，不选不变*」）；多选下拉选完保持展开，单选选中即收起。

### 3.2 渠道关联矩阵（admin/35）

入口：33 活动详情页顶栏「渠道关联」按钮。页面面包屑「活动管理 › 活动详情 › 渠道关联」，侧栏高亮「活动管理」。

#### 3.2.1 矩阵形态

横轴 = 渠道，纵轴 = 分组分区 × 测评。

| 区域 | 展示与规则 |
|---|---|
| 表头 | 5 列统一两行结构、等高：第一行列名（「测评 × 渠道」/ 渠道名），第二行灰色小字（首列=操作说明「勾选行后可批量操作」；渠道列=N 场已关联） |
| 分组行 | 单行：勾选框（一键选本组全部）+ 【分组名】+ N 场测评，顶格 |
| 测评行首列 | 三行结构，整体缩进 + 左侧竖线体现层级（明细见下） |

首列三行明细：

- 第一行：勾选框 + 测评名称 + 试卷标签（绿色=已关联 / 琥珀=待关联试卷）。
- 第二行：测评时间 + 「含模拟考」。
- 第三行：行内文字链接「解除全部关联」（无浮出菜单）。
- 首列固定宽 320–360px，测评名称不换行（超长省略号）。|
| 单元格 | 固定 150px 宽、两行布局：第一行 报名费（加大）+ 报名人数；第二行 小字「编辑 · 展示 · 隐藏」。已关联=蓝底；未关联=灰虚线「＋ 关联」 |
| 隐藏报名格 | 整格琥珀色（浅橙底+深棕字），与蓝格一眼区分；不使用图标角标 |
| 创建失败格 | 红色「失败」标 |
| 工具条 | 全选/取消全选、分组筛选、名称搜索、「关联整个活动」（一键全选全部测评行进入批量添加）、批量操作按钮、「+ 添加渠道」（不占矩阵列） |
| 空矩阵 | 中央引导「尚未关联渠道，点击『+ 添加渠道』开始」 |
| 图例 | 表格下方完整说明：蓝格=正常关联；琥珀格=隐藏报名（前端展示开关与展示时间不参与控制）；灰虚线=未关联；红标=创建失败 |

#### 3.2.2 批量添加渠道（两步弹窗）

入口：勾选测评行 / 勾分组框整组选 / 全选 → 「+ 添加渠道」；或直接点「关联整个活动」（自动全选全部测评行后进入同一弹窗）。

| 步骤 | 内容 |
|---|---|
| 第一步 选渠道 | 三列网格卡片 + 顶部搜索框（按渠道名实时过滤；渠道量大时一搜即达），限高滚动。每卡：勾选圈 + 渠道名 + 已关联场次数；已与全部勾选行关联的置灰标「已全部关联」不可选 |
| 第二步 配置报名 | 每渠道一张配置卡，字段与单格弹窗对齐（明细见下） |

配置卡字段：

- 报名费：必填，带出该渠道上次价，允许 0=免费。
- 前端展示开关：默认关。
- 展示开始 / 展示结束：选填，默认「不展示」；含「永久展示」勾选——勾选后起止输入置灰禁用。
- 报名可见性：正常报名 / 隐藏报名。|

卡内联动（切「隐藏报名」时）：

- 该卡前端展示开关与展示开始/结束整体收起。
- 显示警示条：仅定向链接可报名、链接生成与失效规则。
- 切回「正常报名」→ 展示配置恢复。
- 各渠道卡独立联动，互不影响。

- 隐藏报名可在批量添加中配置：按测评×渠道逐一生成独立定向链接；卡内明示「切换或删除关联会使链接失效」。删除关联场景的失效提醒保留在批量解除确认页。
- 第二步顶部有「统一配置」开关（加粗置顶）：
  - 勾选后其余渠道配置卡全部隐藏，仅保留一张卡且标题变为「全部所选渠道」。
  - 上方出现提示条「已开启统一配置——以下配置将应用到全部所选渠道」。
  - 取消勾选恢复全部渠道卡独立填写。
- 顶部实时汇总「将为 N 场测评 × M 个渠道生成 N×M 条关联」。
- 提交：已存在的关联跳过不覆盖，结果提示「新增 X 条，跳过 Y 条（已存在）」。

#### 3.2.3 批量修改渠道配置

勾选行 →「修改渠道配置」→ 单选一个渠道 → 弹窗同批量添加第二步（带出当前值）。仅可改报名费、展示开关、展示时间（含「永久展示」勾选，默认勾选）；报名费修改不溯及已报名订单。

#### 3.2.4 批量解除渠道关联

勾选行 →「解除渠道关联」→ 多选渠道 → 二次确认页列影响清单：

- 将删除 N 条关联（按渠道分组计数）。
- 已有报名的 M 条默认跳过（不可勾选删除）。
- 含隐藏报名的 K 条明示「删除后定向链接永久失效」。

#### 3.2.5 单格配置弹窗

点击单元格打开，配置项：报名费（≥0，0 显示「免费」）、前端展示开关 + 展示时间、报名可见性（正常报名 / 隐藏报名）。

- 「正常报名 / 隐藏报名」为选项组，选中态高亮显示。
- 切「隐藏报名」：
  - 展示开关与展示时间区块整体收起隐藏。
  - 出现定向链接区块（只读链接 + 复制 + 二维码）。
  - 改回「正常报名」再次隐藏会生成新链接（与线上 20260910 隐藏报名 PRD 3.3 口径一致）。
- 底部显示该关联的报名量；有报名时改价提示「修改不溯及已报名订单」。
- 保存后格子即时刷新：费用、免费字样、人数、琥珀色状态同帧更新。

#### 3.2.6 测评行操作

| 操作 | 说明 |
|---|---|
| 解除全部渠道关联 | 行内红色链接，二次确认，确认页列「N 条关联 / 其中 X 人已报名 / 含 Y 个隐藏报名链接将失效」 |
| 编辑 / 复制测评 | 不在矩阵页提供；测评内容修改统一回「活动管理」详情页操作 |

「详情」入口已移除（信息量低）。

## 4. 字段归属总表

| 配置 | 阶段 | 粒度 | 配置入口 |
|---|---|---|---|
| 名称/时间/试卷/监考/模拟考/标签 | 一 | 测评 | 批量创建向导、活动详情批量修改 |
| 分组 | 一 | 活动 | 详情页分组管理 + 创建时勾选落位 |
| 报名费 / 展示开关 / 展示时间 | 二 | 测评×渠道 | 单格弹窗、批量添加/修改弹窗 |
| 报名可见性（隐藏报名）+ 定向链接 | 二 | 测评×渠道 | 单格弹窗、批量添加第二步配置卡 |

## 5. 边界与既定口径

- 展示时间默认「不展示」：
  - 批量关联后前端默认隐藏，运营确认后手动开启。
  - 展示时间支持勾选「永久展示」：勾选后起止时间输入收起禁用，不用填写。
  - 三处入口（批量添加卡 / 单格弹窗 / 批量修改）均有此勾选，与线上渠道管理页「永久有效」交互一致。
- 报名费允许 0 元（展示「免费」）；改价不溯及已报名订单。
- 无试卷测评可创建、可关联渠道、可报名（报名占位、试卷后补），矩阵与行头均标「待关联试卷」。
- 解除关联后该渠道定向链接失效，属预期行为，确认页明示。
- 复核只补考不重考；标签用下拉；成绩公示后分数与报告数据锁定（2026-09-12 会议决议随本改版落入边界）。
- 用户端影响：分组改挂活动下后，报名页「选机构→按分组分节展示测评卡片」（待研发评估，在报名端改版 PRD 细化）。
