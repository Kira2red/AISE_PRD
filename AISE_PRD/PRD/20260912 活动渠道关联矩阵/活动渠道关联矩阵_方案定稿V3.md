## 1. 背景

2026-09-12 考务系统需求评审结论：现有活动管理方案「太乱、看不明白」。根因有三：①一行=渠道×考试×分组，14 个配置列全平铺；②批量创建缺字段（模拟考大面积缺失）又混入不需要的字段；③考试创建与渠道关联耦合在一步。

改版核心：**按业务流程分两阶段**，矩阵只承载「渠道关联覆盖」一个信息，配置全部收进弹窗。

## 3. 总体流程

```
第 1 步  建活动            名称 + 起止日期，2 个字段
   │
第 2 步  建分组（可选）     不建分组 = 全部考试在「未分组」
   │
第 3 步  批量创建考试       考试清单 → 正式考配置 → 模拟考配置
   │                        ← 阶段一结束：考试模型就绪，尚无渠道可报名
   ▼
第 4 步  关联渠道           矩阵二维图：批量添加 / 批量修改 / 批量删除
                            每格子：报名费、展示开关、展示时间、报名可见性
```

阶段一完成时明确提示：「考试模型已就绪，尚未关联渠道，前端不可见」——给运营一个检查点，再进入阶段二。

## 4. 阶段一：考试模型

### 4.1 第 1 步：创建活动

输入活动名称、开始日期、结束日期。创建即进入活动详情页。

### 4.2 第 2 步：添加分组（非必须）

- 分组管理面板：新建 / 重命名 / 排序 / 删除（有考试的分组不可删）
- 不建分组时所有考试归「未分组」（系统默认区，置灰不可改名）
- 分组活动内唯一；**所有渠道看到的分组一致**；分组顺序 = 矩阵行分区顺序 + 用户端展示顺序

### 4.3 第 3 步：批量创建考试（两小步）

**入口**：分组分区「+ 批量创建考试」；或顶部按钮后先勾选目标分组。

**3a · 考试清单**（建哪几场）

- 每行一场考试，仅 3 字段：考试名称、开始时间、结束时间
- **批量生成器前置**（多场同构考试是主场景）：名称 + 场数 + 起始时间 → 自动展开 N 行（名称 -第1场/-第2场，时间固定间隔 30 分钟顺延）
- 行内可改任意字段、加空行、复制行
- 勾选目标分组（可多选 = 每组各生成一套）
- **试卷字段留空可创建**（拍板 13）：状态「待关联试卷」，创建后可补

**3b · 考试配置**（正式考 + 模拟考两节，严禁平铺）

正式考：
- 基础：关联试卷（可空）、时长、交卷限制、标签（**下拉多选**）
- 监考 8 项：摄像头 / 录屏 / 检录照片（三档）、候考时长、手机监考、成绩 / 分数 / 读题开关
- 低频折叠区「更多设置」：检录引导文案、检录示意图、测评描述、证书落款

模拟考（总开关）：
- 开启后：模拟卷（可与正式卷不同）、**起止时间、次数限制**（N 次 / 无限次）、交卷时限
- 监考口径：**跟随正式考 / 自定义**（自定义展开同构 8 项，不含检录文案/示意图）

**提交后**：生成考试（含爱测评自动创建，失败行「未关联」可补建不回滚）→ 就绪提示。

## 5. 阶段二：渠道关联矩阵

### 5.1 矩阵形态

```
                    │ 猿编程        │ 核桃编程      │ 编程猫        │
────────────────────┼───────────────┼───────────────┼───────────────┤
【3月批】            │               │               │               │
 Python一级         │ ¥300 · 编辑   │ ¥300 · 编辑🔒 │ ＋ 关联       │
 图形化一级(待试卷)  │ ¥280 · 编辑   │ ＋ 关联       │ ¥280 · 编辑   │
【6月批】            │               │               │               │
 Python二级         │ ¥320 · 编辑   │ ＋ 关联       │ ○ 创建失败    │
```

- **行** = 分组分区 × 考试（行头：勾选框、考试名称+试卷状态、标签、时间、报名量、行尾「…」菜单）
- **列** = 渠道（表头：渠道名+号、列勾选框）
- **单元格**（拍板 8，全部可见文字态）：
  - 已关联：`¥300 · 编辑`；隐藏报名加「🔒隐」角标（不出现「展示中/隐藏中」字样，拍板 6）
  - 未关联：`＋ 关联`
  - 无试卷考试：行头标「待试卷」，照常关联渠道报名
  - 创建失败：红色角标 + 悬浮原因
- **按钮**（拍板 14）：「+ 添加渠道」在矩阵上方工具条右侧；矩阵无占位列；空矩阵中央引导「尚未关联渠道，点击右上角『+ 添加渠道』开始」

### 5.2 批量添加渠道（两步弹窗）

入口：勾选行 / 分组头整组选 / 全选 → 「+ 添加渠道」

**Step 1 选渠道**：卡片式多选（渠道名/码/已关联考试数）；已与全部勾选行关联的置灰标「已全部关联」。

**Step 2 配置报名**（复杂配置区，非确认页）：
- 每渠道一张配置卡：**报名费**（必填，带出该渠道上次价，支持「应用到全部渠道」）、**前端展示开关（默认关）+ 展示时间**（选填）——拍板 10
- **无「隐藏报名」选项**：隐藏报名涉及链接生成/失效，只允许单格操作，防误伤
- 顶部汇总：「将为 12 场考试 × 2 个渠道生成 24 条关联」
- 提交：已存在关联跳过不覆盖 →「新增 20 条，跳过 4 条（已存在）」

### 5.3 批量修改渠道配置

勾选行 →「修改渠道配置」→ 选一个渠道（单选）→ 弹窗同 5.2 Step 2（带出当前值）。只改报名费、展示开关、展示时间；**报名费修改不溯及已报名订单**（拍板 11）。

### 5.4 批量删除渠道关联

勾选行 →「解除渠道关联」→ 选渠道（多选）→ 确认页列影响清单：
- 将删除 N 条关联（按渠道分组计数）
- 已有报名的 M 条**默认跳过**（拍板 15）
- 隐藏报名的 K 条：明示「删除后定向链接永久失效」（拍板 4）

### 5.5 单格配置弹窗

- 报名费、前端展示开关 + 展示时间、报名可见性（正常 / 隐藏报名）
- 切「隐藏报名」→ 展示开关/展示时间区块**收起消失**，出现定向链接区块（只读 + 复制 + 二维码）；改回「正常报名」再隐藏会生成新链接（旧行为，保留）
- 底部显示该关联报名量；有报名时改价提示「不溯及已有订单」

### 5.6 行「…」菜单

详情（跨渠道配置抽屉）/ 复制考试 / 编辑考试（阶段一配置整体编辑）/ 补关联试卷（待试卷状态时）/ 解除全部渠道关联（**保留，二次确认**，拍板 12）

## 6. 字段归属总表

| 配置 | 阶段 | 粒度 | 配置入口 |
|---|---|---|---|
| 名称/时间/试卷/监考/模拟考/标签 | 一 | 考试 | 批量创建 3a/3b、行「…」编辑考试 |
| 分组 | 一 | 活动 | 分组管理面板 + 创建时勾选落位 |
| 报名费 / 展示开关 / 展示时间 | 二 | 考试×渠道 | 单格弹窗、批量添加/修改弹窗 |
| 报名可见性（隐藏报名）+ 定向链接 | 二 | 考试×渠道 | **仅单格弹窗** |

## 7. 用户端影响（待研发评估，不在本 PRD 展开）

分组改挂活动下后，报名页「机构→分组→考试」两级下拉数据源变化。产品口径：**选机构后按分组分节展示考试卡片**（分组顺序=阶段一配置顺序，各渠道一致），分组从必选下拉降级为视觉分区。具体交互在报名端改版 PRD 细化。
