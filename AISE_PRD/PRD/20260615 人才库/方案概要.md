# AISE 人才库网站 方案概要

## 产品定位
独立于 AISE 测评平台的「人工智能人才资源库」展示网站，为用户提供官方人才认可凭证（人才信息卡）。

## 页面结构

### 1. 寄语页（Landing Page）
- 紫色/蓝色渐变科技感背景
- CSIA + AISE 双标识
- 大标题"寄语"（MESSAGE 水印）
- 白色圆角寄语卡片
- 两份红头文件缩略图（PC横排/移动端竖排）
- 5秒后淡入"注册""登录"按钮

### 2. 登录/注册页
- 复用 AISE 登录注册交互
- 唯一ID：身份证号（兼容港澳台通行证、护照）
- 注册后以身份证号匹配 AISE 已有数据，建立账号关联
- 两套独立用户体系（AISE测评 + 人才库），通过身份证号桥接

### 3. 人才卡页
- 完全还原品宣物料样式
- 数据来源：
  - 基本信息：AISE 同步（姓名/性别/出生年月/籍贯/身份证号/入库时间）
  - 人工智能应用创新能力：AISE 考试数据同步
  - 特长领域、综合分析：静态模板
  - 社会实践、专利软著、荣誉：用户上传 + 后台审核
- PC端和移动端保持相同的竖版卡片样式

## 技术约定
- 纯前端 HTML/CSS/JS 原型
- 移动端响应式（768px断点）
- 无外部依赖（除 Tailwind CDN + Font Awesome）
- 部署目录：`/html/talent_pool/`
