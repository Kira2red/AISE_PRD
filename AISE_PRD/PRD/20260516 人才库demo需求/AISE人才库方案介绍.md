# AISE 青少年AI竞赛人才库 — 产品方案

## 一、产品定位

面向 **中小学生信息技术竞赛**（CSP-J/S、NOI、蓝桥杯等）的四端人才管理与服务平台，连接 **学生、家长、教师/教练、赛事主办方**，实现从能力档案、竞赛管理到数据洞察的全链路服务。

> 📌 **Demo 入口**：同目录下 `AISE人才库Demo.html`，浏览器打开即可体验四端差异化功能。

---

## 二、四端角色与核心功能

### 🎓 学生端

| 功能 | 说明 |
|------|------|
| 个人能力档案 | 知识模块（算法设计、数据结构、编程实现、数学基础、调试能力、思维创新）的雷达图 + 各项得分 |
| 竞赛成绩与证书 | 参赛历程时间线，按时间展示获奖记录（CSP-J/S、蓝桥杯、市赛等） |
| 个性化学习建议 | 基于薄弱环节的智能诊断：薄弱项预警、推荐学习路径、下次竞赛建议 |

### 👨‍👩‍👧 家长端

| 功能 | 说明 |
|------|------|
| 孩子能力档案查看 | 查看孩子各模块掌握度、总体评级、同年龄段排名（只读） |
| 成长报告 | 半年能力提升趋势、同龄排名百分比、阶段性评估摘要 |
| 竞赛规划建议 | 适合孩子当前水平的竞赛推荐（含难度、匹配度、时间线） |

### 👨‍🏫 教师/教练端

| 功能 | 说明 |
|------|------|
| 学员列表与分组管理 | 按班级/水平分组查看学员，支持搜索筛选 |
| 学生能力批量查看 | 班级间能力雷达图对比（竞赛A班 vs 提高班 vs 基础班） |
| 教学数据看板 | 班级整体统计：在管人数、获奖率、平均提升、需关注学员预警 |

### 🏆 赛事主办方/机构端

| 功能 | 说明 |
|------|------|
| 赛事发布与管理 | 创建/管理赛事，查看报名人数与状态 |
| 选手信息导出 | 支持导出选手档案与能力数据 |
| 赛事数据统计 | 注册选手总量、本月新增报名、选手水平分布（入门→国奖） |
| 机构/学校合作管理 | 合作学校 TOP 排行、各校选手数量 |

---

## 三、Demo 演示说明

Demo 展示四个端在同一个页面中，通过顶部角色切换栏切换视角：

1. **学生端** — 林小川（13岁，初二，深圳南山外国语学校）的个人档案，含能力雷达图（Chart.js）、竞赛时间线（CSP-J一等奖→蓝桥杯省二→CSP-J三等奖→市赛）、三条个性化学习建议
2. **家长端** — 孩子档案（只读）+ 半年成长报告（+12分、Top15%、省一）+ 三条竞赛规划建议（CSP-S 2026、蓝桥杯国赛、NOI省选远期）
3. **教师端** — 32名学员列表表格 + 班级筛选 + 三班能力雷达图对比 + 重点关注预警
4. **赛事方端** — 赛事管理表格 + 选手水平分布（柱状图）+ 合作学校TOP5排行

## 四、技术选型

| 层面 | 选择 |
|------|------|
| 前端框架 | 纯 HTML/CSS/JS（零依赖，适配轻量 Demo） |
| 图表渲染 | Chart.js 4.5.1（CDN 异步加载，失败不阻塞页面） |
| 响应式 | CSS Grid + 三档断点（960px / 640px） |
