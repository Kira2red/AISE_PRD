# 20260106 活动标签与分组

## 标签配置管理

📎[文件]

### 1.1 业务概述

构建一套结构化的标签体系，用于对测评活动进行多维度的分类、属性标记和检索。

这一期的证书上，需要提前创建：

- 标签属性 = 模块，标签有：图形化、python、...

- 标签属性 = 等级，标签有：1级、2级、3级、4级

然后给相关的测评添加分组或者直接添加标签，关联上对应的标签，证书读这两个属性标签的值。

### 1.2 标签属性管理

🖼️[图片]

属性是标签的分类维度（Key），用于规范标签的层级关系。

- 页面布局：列表展示。

- 列表字段：

- 标签属性名称：显示名称，如“难度等级”、“所属模块”、“年份”。

- 标签属性类型：标签属性的类型，可以设置为通用标签。

- 关联标签数：该属性下包含多少个标签。

- 选择模式：

- 单选：一个测评在该属性下只能拥有一个标签（例如“难度”通常互斥）。

- 多选：一个测评在该属性下可拥有多个标签（例如“能力维度”）。

- 状态：启用/停用。

- 操作：

- 新增标签：输入名称、属性、选择模式、状态。

- 编辑：修改名称或模式（需校验历史数据兼容性）。

- 删除：若该属性下已存在标签，需提示先删除标签。

🖼️[图片]

### 1.3 标签管理 

在特定的属性维度下，维护具体的标签。

- 页面布局：

- 左侧：属性列表导航栏（包含“无属性/通用标签”分类）。

- 右侧：选中属性下的标签列表。

- 列表字段：

- 标签名称：如“Python”、“图形化”、“2025春季赛”。

- 颜色标记：用于前端 Badge（徽章）的背景色显示（提供色盘选择器）。

- 核心操作：

- 新增标签：

- 选择标签属性。

- 输入标签名称（必填）。

- 选择显示颜色（选填，默认灰色）。

🖼️[图片]

- 合并标签值：

- 场景：将“Python编程”和“Python语言”两个标签合并。

- 逻辑：选择源标签 -> 选择目标标签 -> 确认。合并后，所有原挂载“Python编程”的测评自动变更为“Python语言”，原标签删除。

## 测评组管理

📎[文件]

### 2.1 业务概述

测评组是测评的“集合容器”，用于解决多入口分发、专题页运营及批量上下架的需求。

- 场景示例：

- 运营在首页 Banner 配置了一个“2025 春季赛”入口，该入口绑定了后台的一个“测评组”。

- 运营只需在后台向该组添加/移除测评，前端页面内容即自动更新，无需发版。

### 2.2 测评组列表

🖼️[图片]

- 列表字段：

- 组名称：如“首页推荐位”、“Python 专项赛合集”。

- 组 ID：系统生成的唯一 ID，供前端或后台调用。

- 组内测评数：当前组内包含的测评数量（生效中/总数）。

- 备注：选填，运营说明。

- 状态：启用/停用。

- 操作：

- 新建组：输入组名称、备注。

- 管理成员：点击跳转至“组成员管理”详情页。

- 删除：物理删除该组（不删除测评本身）。

🖼️[图片]

### 2.3 组成员管理

🖼️[图片]

此页面为测评组的详情页，用于维护组内的测评列表及其属性。

- 成员列表：

- 展示字段：测评名称、ID、标签（Badge展示）、组内展示时间、状态。

- 排序：支持拖拽排序。

- 添加测评：弹窗勾选多个测评，添加到组里。

🖼️[图片]

- 批量操作： 勾选列表中的测评后，触发批量操作栏。

1. 批量设置有效期：统一修改在组内的展示起止时间。

🖼️[图片]

1. 批量移除：将测评从组内删除。

1. 批量设置标签：

- 交互：弹出标签选择模态框。

- 模式选择：

- 模式 A：增量模式—— 默认选中。

- 逻辑：在原有标签基础上增加新标签。

- 冲突处理：若新选标签所属的属性是“单选”（如：等级属性只能选1级或2级），则替换掉测评身上原有的该属性标签；若属性是“多选”，则直接追加。

- 模式 B：覆盖模式。

- 逻辑：清空测评身上原有的所有标签，仅保存当前选中的标签。

## 测评管理 

📎[文件]

### 3.1 业务概述

本模块是运营人员的高频工作台。在原有列表管理的基础上，集成了“标签”能力。

### 3.2 列表页升级

🖼️[图片]

#### 3.2.1 筛选栏升级

在原有“名称”、“同步状态”筛选的基础上，新增：

- 标签筛选：

- 交互：点击输入框弹出下拉面板。

- 展示：面板内按 1.2 中定义的“属性”分类展示标签（如：【等级】1级/2级... 【模块】Python/C++...）。

- 逻辑：支持多选（AND 逻辑），例如筛选 模块:Python + 难度:入门 的所有测评。

- 测评组筛选：

- 交互：下拉选择已创建的“测评组”。

- 逻辑：选中“2025 春季赛”组，列表仅展示该组内的所有测评。

#### 3.2.2 列表字段升级

- [新增] 标签列：

- 展示：以彩色 Badge 样式展示。

- 排序：优先展示“属性标签”（如 [模块:Python]），后展示“通用标签”（如 热门）。

- 折叠：若标签超过 3 个，显示前 3 个 + ...，鼠标悬停 Tooltip 展示全部。

- [新增] 所属分组列：

- 展示：文本展示该测评当前归属的组名称（如 首页推荐, Python专区）。

### 3.3 单个测评编辑 

点击列表操作栏中的 “编辑” 按钮，弹出编辑模态框。

🖼️[图片]

- 基础信息：

- 显示名称：支持修改（同步自题库，但允许运营改名）。

- 有效时间：设置测评本身的开始与结束时间。

- [新增] 标签配置：

- 交互组件：使用多选下拉搜索组件（与批量操作一致）。

- 回显逻辑：打开弹窗时，需自动展示该测评当前已拥有的所有标签（以 Tag 胶囊形式显示）。

- 操作：

- 添加：点击下拉框，在分组列表中勾选新标签。

- 移除：点击已选 Tag 上的 × 号移除。

- 互斥逻辑：若某属性配置为“单选”（如难度），当用户选择了“2级”时，自动顶替掉原有的“1级”。

🖼️[图片]

[新增] 证书落款时间配置：

- 业务背景：证书生成时，底部通常需要展示一个日期。为了满足不同运营场景（如固定发证日或随考随发），需提供灵活配置。

- 配置选项（单选）：

- 选项 A：用户初次查看时间 —— 默认选中。

- 逻辑：当C端用户在“我的证书”页面首次点击“查看/下载证书”时，系统记录当前服务器时间作为该用户的证书落款时间，并固化（后续再次查看不改变）。

- 选项 B：指定日期。

- 交互：选中此项后，右侧/下方激活日期选择器，管理员需选择一个具体日期（YYYY-MM-DD）。
