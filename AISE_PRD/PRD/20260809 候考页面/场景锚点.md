# 候考功能 — 场景锚点

> 产品大师阶段零产出，基于 20260809 需求讨论 + 线上测试环境（portal.dev.aica.org.cn / aica.test.iceping.org.cn）实测采集。
> 工作目录：PRD/20260809 候考页面/

## 一、产品定位

在正式测评开始前，提供「设备检测 + 检录 + 等待开考」的统一候考流程，让用户在开考前完成环境准备，不占用正式测评时间。模拟测评同样提供候考环节，检测检录完成后可直接进入模拟测。

## 二、现状（线上实测确认）

### 2.1 学生端考试流程（现）

```
我的活动/我的考试 → 进入测评 → 设备检测（弹窗）→ 检录（页面）→ 答题
```

- **设备检测**：弹窗形式。内容：浏览器环境检测提示条（通过/失败）、摄像头调试卡片（测试按钮）、录屏调试卡片（测试按钮）、底部「进入测评」主按钮。摄像头+麦克风一起检测授权，录屏单独检测。检测失败显示红色错误提示（含原因和重试按钮），强制开启时检测不过不能进入。
- **检录**：页面形式。左侧摄像头实时画面，右侧「检录要求」标题 + 后台配置的引导文案 + 后台配置的示意图 + 「拍 照」按钮；拍照后显示照片 + 「重新拍照」「开始答题」按钮。
- 检测/录屏/检录的强制程度由考试配置（强制开启/非强制开启/不开启）。
- 检测和检录结果存爱测评后台，监考端可查看检录照片和录像。

### 2.2 管理端配置（现）

爱测评考试管理表单（examManageForm）结构：左侧步骤导航（基础考试信息/监考信息/学生管理）+ 右侧表单卡片。
- **基础考试信息**：考试名称、考试时间（起止）、考试时长（分钟）、考试地点、关联试卷、考试描述、可见范围、提交即批改
- **监考信息**：摄像头监考（三档）、录屏监考（三档）、检录照片（三档）、成绩开关、分数开关、读题开关、检录视频引导文案（文本）、检录视频示意图（上传）
- **学生管理**：考生名单（导出/添加/批量移除）

## 三、目标流程

### 3.1 核心规则

1. 考试后台新增「候考时长（分钟）」配置。留空或 0 = 不开启候考（走现有流程，行为不变）。
2. 配置 N 分钟后：开考前 N 分钟至开考时间 = 候考窗口。窗口内入口按钮显示「准备考试」。
3. 候考窗口内进入：设备检测 → 检录 → 等候页（考试名称、开始时间、倒计时）。
4. 倒计时归零（开考时间到）：等候页出现「开始考试」按钮，点击直接进入考试，不重复检测检录。
5. 检测检录完成时刻 >= 开考时间 → 直接进入考试（不进等候页）；< 开考时间 → 进入等候页等待。
6. 开考后新进入：直接走现有流程（设备检测 → 检录 → 进入考试），不经过等候页。
7. 模拟测评：先进等候页流程，检测+检录后直接进入模拟测（无倒计时等待）。
8. 候考流程中检测/检录逻辑与现有完全一致，只改流程编排。

### 3.2 入口与文案

- 入口按钮「开始考试」→「准备考试」（候考窗口内统一显示）。
- 开考前 N 分钟之外显示「考试未开始」并提示开始时间和可候考时间（N 分钟前点击入口的行为）。

### 3.3 与现有配置联动

- 检录照片「不开启」的考试：候考流程跳过检录步骤，检测完成后直接到等候页/进考试。
- 检录照片「非强制」：可跳过检录。
- 摄像头/录屏「非强制/不开启」：相应检测项可跳过（沿用现有逻辑）。

## 四、约束条件

- 配置只加在爱测评考试后台（检测/录屏/检录开关也都在爱测评）。
- AISE 侧（portal）不改配置，只改入口文案（统一改）。
- 检测/录屏/检录结果仍存爱测评，本需求不改变检测检录原有逻辑和数据结构。
- 用户端在 PC 浏览器（Chrome/Edge）使用，考试系统要求 HTTPS + 摄像头/录屏授权。

## 五、待确认事项

1. 「准备考试」按钮具体出现在哪些入口（AISE 我的活动/我的考试/iceping 端答题入口），统一改的范围。
2. 开考前 N 分钟之外点击入口：提示「未到候考时间」还是可进原流程。
3. 等候页「开始考试」按钮出现后是否还需要倒计时剩余显示（开考后 X 分钟内仍可点）。
4. 候考时长取值上限/校验（如最长 120 分钟）。
