# 渠道选择 — 方案概要

## 1. 背景与问题

AISE 支持多个 B 端渠道合作（如 AISE 官网、作业帮等），不同渠道有独立的用户体系。同一个用户可能在 AISE 官网注册了一个账号，又在作业帮渠道注册了另一个账号——两套账号的用户名和密码可能相同，但实际是两个独立身份。

现有登录流程不区分渠道：用户输入账号密码 → 直接登录。当同一组凭证对应多个渠道账号时，系统无法判断用户想以哪个身份登录。

## 2. 功能定位

在登录流程中插入「渠道检测」环节：

- 用户输入账号密码，点击登录
- 系统检查该凭证对应的渠道账号数量
- 1 个 → 直接登录（与现有行为一致）
- 多个 → 弹出渠道选择弹窗，用户选择后以该渠道身份登录
- 登录完成后回到触发登录的前置页面（首页、报名流程等）

## 3. 涉及页面

| 页面 | 类型 | 说明 |
|------|------|------|
| `01_登录注册.html` | 修改 | 登录表单提交后增加渠道检测逻辑 + 渠道选择弹窗 |

仅涉及登录页一个文件，不新增页面。

## 4. 交互流程

```
用户输入账号密码 → 点击「立即登录」
  → 登录按钮变为「检测中...」
  → 系统查询该凭证的渠道账号列表（Demo 模拟 1~3 秒延迟）
  → 结果判断：
      ├── 0 个账号 → 提示「账号或密码错误」（现有行为）
      ├── 1 个账号 → 直接登录，跳转回前置页面（现有行为）
      └── 2+ 个账号 → 弹出渠道选择弹窗
           → 用户点击某个渠道卡片
           → 卡片高亮 + 按钮变为「以该身份登录」
           → 点击确认 → 登录成功，跳转回前置页面
```

## 5. 渠道选择弹窗设计

### 5.1 弹窗结构

- 半透明深色遮罩层
- 居中白色卡片弹窗（宽约 440px）
- 顶部标题：「检测到多个关联账号」
- 副标题：「请选择您要登录的渠道身份」
- 中间：渠道账号卡片列表（可滚动）
- 底部：取消按钮（关闭弹窗，回到登录页）

### 5.2 渠道账号卡片

每张卡片展示：

- 左侧：用户头像（圆形，Demo 用首字母头像或固定占位图）
- 中间上方：用户姓名
- 中间下方：渠道名称（如「AISE 官网」「作业帮」）
- 右侧：两行小字
  - 首次注册：2024-03-15
  - 最近登录：2026-07-28

卡片默认灰边框，hover 时蓝色边框，点击后选中态（蓝色边框 + 浅蓝底色），底部确认按钮激活。

### 5.3 视觉规范

沿用现有 `01_登录注册.html` 的设计语言：
- 字体：Inter
- 色系：slate 灰 + brand blue（#3b82f6 / #2563eb）
- 圆角：xl（12px）
- 阴影：shadow-card（0 25px 50px -12px rgba(0,0,0,0.25)）
- 按钮：深色渐变背景

## 7. 边界场景

| 场景 | 处理 |
|------|------|
| 输入错误凭证 | 与现在一致，提示「账号或密码错误」 |
| 只有一个渠道账号 | 不弹弹窗，直接登录，与现在行为一致 |
| 弹窗中点击取消/遮罩 | 关闭弹窗，回到登录页，不清空已输入的账号密码 |
| 弹窗中点击确认前切换选择 | 卡片选中态切换，上一个取消选中 |
| 网络延迟/检测超时 | 按钮恢复，提示「检测超时，请重试」 |
