# 方案V1：监考配置开关迁移至 AISE

> 版本：V1 | 日期：2026-08-27 | 阶段：产品方案（产品大师·阶段一）
> 所属需求：[爱测评考试自动创建 PRD](爱测评考试自动创建 PRD.md)（20260825，飞书版见 https://jxlgonmlzq7.feishu.cn/docx/Nmxjd2PmioH1qIxxcVOc88C1nDg）
> 需求来源：运营原始需求「AISE后台增加考场监考开关、手机监考、等开关项」+ 用户决策「开关从爱测评创建考试配置挪到 AISE，AISE 关联试卷自动创建考试」
> 写作口径：研发同一团队，只讲业务规则，不讲技术实现。

---

## 1. 背景与目标

考试创建链路改造后（爱测评考试自动创建 PRD），运营在 AISE 新建测评活动、关联爱测评试卷，系统自动在爱测评创建考试。原链路中「监考开关、手机监考」等配置项在爱测评考试表单（创建考试时三步表单第二步「监考信息」）配置；新链路下爱测评考试一律程序创建，这些配置项需迁移到 AISE，作为 AISE 考试要素随自动创建一并下发爱测评。

**目标**：运营在 AISE 一个平台完成「考试要素 + 监考配置」全部配置；爱测评侧不再需要人工创建考试（存量除外）。

## 2. 开关盘点（依据：爱测评考试表单 17_考试表单.html，线上样式还原版）

爱测评创建考试三步表单全部配置项与迁移判定：

### 2.3 学生管理（第三步）

### 2.4 盘点结论

- 需迁移：监考信息 10 项（§2.2 全部）。
- 需判定：考试地点、考试描述、可见范围、提交即批改（§2.1 四项）。
- 不迁移：名称/时间/时长/关联试卷（AISE 已有）、学生名单（AISE 报名制）。
- 爱测评侧监考类配置项共 10 项，无遗漏（依据：爱测评线上考试表单还原 demo，含候考配置演示页 12_考试管理_候考配置.html 交叉核对；12 页无「手机监考」项，17 页线上还原版有，以 17 页为准）。

## 3. 迁移方案

### 3.1 配置位置

- **单考场考试**：监考配置放 AISE「编辑测评信息」弹窗（04_测评活动详情 / 05_新建测评活动），与名称、时间、时长、交卷限制等要素同弹窗。
- **多考场考试**：默认按考场独立配置（每个 AISE 考场对应一个爱测评考试，配置随考场下发）。候考 PRD 曾定「候考时长统一按考试配置、不做按考场覆盖」（20260809，当时考试整体在爱测评配置），本方案默认随多考场模式「要素下沉考场」原则改为按考场配置——见待确认 C1。

### 3.2 功能清单

| 编号 | 功能 | 优先级 | 依据 |
|------|------|--------|------|
| F1 | AISE 考试创建/编辑弹窗新增「监考配置」区块：摄像头监考、手机监考、录屏监考、检录照片、成绩开关、分数开关、读题开关、检录视频引导文案、检录视频示意图、候考时长 | P0 | 运营原始需求 + 爱测评线上表单 |
| F2 | 配置随「自动创建爱测评考试」下发：新建时随创建下发；编辑时随编辑联动（爱测评考试自动创建 PRD 3.7）同步更新爱测评侧 | P0 | 爱测评考试自动创建 PRD |
| F3 | 下发失败与考试创建强一致：爱测评考试创建失败则整体失败，报错可重试（复用既有强一致规则） | P0 | 爱测评考试自动创建 PRD 3.3 |
| F4 | 模拟考配置：开启模拟考的考试，监考配置是否随模拟考创建下发——待确认 C6 | P0 | 飞书 PRD 3.2（模拟考要素未含监考配置） |
| F5 | 爱测评侧考试表单（17_考试表单）：新考试程序创建，人工表单仅服务存量考试编辑，监考配置字段保留供存量修改 | P1 | 爱测评考试自动创建 PRD 3.8 存量策略 |
| F6 | 联动规则保留：候考时长「考试已开考后修改不生效」、上限 120 分钟等既有规则随配置迁移保留 | P1 | 候考 PRD 20260809 |

### 3.3 核心流程

运营在 AISE 新建测评活动 → 填要素（名称/时间/时长/交卷限制/标签）→ 配置监考开关（摄像头监考/手机监考/录屏监考/检录照片/成绩开关/分数开关/读题开关/检录引导文案/示意图/候考时长）→ 关联爱测评试卷 → 保存 → 系统自动在爱测评创建考试并携带监考配置 → 考生在爱测评考试引擎作答，设备检测/检录/候考/手机监考入口均按配置生效（检测与检录三态、候考窗口、读题、成绩展示）。

## 4. 边界与异常场景

- 三态开关必填：摄像头监考、录屏监考在爱测评侧为必填项，AISE 侧保持必填（默认值待确认 C7）。
- 编辑联动边界：考试已开考后候考时长修改不生效（既有规则）；已报名考场禁止修改开始/结束时间，此情形编辑联动不触发（既有规则）。
- 存量考试：爱测评存量考试保留人工编辑通道（17_考试表单），配置迁移不影响存量考试执行；存量活动处理方式由研发评估（爱测评考试自动创建 PRD 3.8）。
- 手机监考开关联动：开关「关闭」时用户端设备调试页手机监考入口不展示（当前入口「始终展示」为手机监考 PRD 口径，本次随开关收口——待确认 C8）。
- 检录视频引导文案/示意图：为空时使用系统默认文案/默认示意图。
