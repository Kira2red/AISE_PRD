# AISE 爱测评考试自动创建

> 需求文件夹：20260825 爱测评考试自动创建 ｜ 方案依据：[方案V2.md](方案V2.md) ｜ 相关需求：[测评多考场 PRD](<../20260708 多考场/测评多考场_PRD.md>)

术语口径：本文「考试」指 AISE 的测评活动；「考场」指多考场模式下考试内的子场次；「爱测评考试」指系统在爱测评侧自动创建的考试（用户口径亦称「爱测评考场」）。一个 AISE 考试（单考场）或一个 AISE 考场（多考场）对应一个爱测评考试。

---

## 1. 背景与收益

AISE 新建测评活动时，关联的是爱测评的**考试**——运营需先在爱测评手动新建考试，再回到 AISE 关联同步，考试创建依赖人工在两个平台间来回操作，效率低、且两平台配置易不一致。

本次改造：运营在爱测评只需新建**试卷**（组卷）；在 AISE 新建考试时关联爱测评试卷，系统按 AISE 填写的考试起止时间等要素，**在 AISE 创建考试的同时自动在爱测评对应组织程序化创建考试**。爱测评侧考试一律程序创建，人工环节仅剩「爱测评组卷 + AISE 关联试卷」。收益：运营在 AISE 一个平台内完成考试创建全流程，消除双平台来回操作；爱测评侧人工建考试次数降为 0；考试要素以 AISE 为单一数据源，避免两平台配置不一致影响考试执行。

写作口径：研发团队为同一团队，本文档只描述业务规则，不涉及技术实现细节。

## 2. 业务流程

1. 运营在爱测评新建试卷（组卷）——唯一人工环节。
2. 运营在 AISE 新建测评活动：选择考试形态（单考场 / 多考场 / 开启模拟考），关联爱测评试卷（可暂不关联），填写名称、起止时间、时长、交卷限制、标签、模拟考配置等要素。
3. 保存时：
   - 已关联试卷 → 系统自动在爱测评对应组织创建考试：单考场创建 1 个；多考场每个考场创建 1 个（各考场可关联不同试卷）；开启模拟考时创建对应模拟考试（关联模拟卷）。
   - 未关联试卷 → 保存为「未关联爱测评」状态。
4. 创建结果：爱测评考试创建成功，AISE 考试才算创建成功、活动可用；创建失败则 AISE 考试同样不成功，报错并可重试，或先保存为未关联状态。
5. 未关联活动后续编辑补关联试卷并保存 → 自动触发创建爱测评考试。
6. 考生在 AISE 报名、在爱测评考试引擎作答，报名、考试、证书、报告等下游链路不变。

每个考试（活动）的爱测评关联状态为四种：未关联、创建中、已创建、创建失败。

## 3. 详细功能说明

### 3.1 关联爱测评试卷

- **位置**：admin 端「新建测评活动」弹窗（05）、单考场模式「编辑测评信息」弹窗（04）、多考场模式考场编辑弹窗（04）。
- **关联对象改造**：「关联爱测评考试」改为「关联爱测评试卷」，下拉从爱测评试卷列表中选择，展示试卷名称（含标签、题量、更新时间等，支持搜索）。
- **关联非必填**：不关联时保存为「未关联爱测评」状态；关联后保存即触发自动创建（见 3.2）。
- 已创建考试编辑时可修改关联试卷，保存后按 3.7 联动更新爱测评侧。
- 试卷选择后可预览试卷内容（复用 04 页试卷预览弹窗）。

### 3.2 自动创建爱测评考试

- **触发时机**：保存考试且已关联爱测评试卷时（新建、编辑补关联均触发）。
- **创建数量与对应关系**：
  - 单考场考试：创建 1 个爱测评考试。
  - 多考场考试：每个 AISE 考场创建 1 个爱测评考试，按各自关联的试卷创建，不同考场试卷可以不同。
  - 模拟考试：开启模拟考的考试，创建对应的爱测评模拟考试（关联模拟卷）；落地形态由研发确定。
- **创建要素**（以 AISE 填写为准）：起止时间、时长、交卷限制、关联试卷；模拟考另含模拟卷、模拟考起止时间、考试次数限制。
- **要素执行分工**：除容量限制已删除（见 3.5）外，其他限制要素爱测评侧有对应能力的由爱测评执行，没有的由 AISE 执行业务逻辑；报名相关要素（如报名截止时间）属 AISE 报名流程，由 AISE 执行。
- **时间规则**：允许同组织多场考试时间重叠；AISE 侧先行校验（起止时间合法、时长不小于交卷限制、考场时间在测评边界内），校验通过才发起创建。
- **创建过程**：展示「正在自动创建爱测评考试」提示，完成后展示创建结果（见 3.3）。

### 3.3 创建结果与异常处理（强一致）

- **强一致**：爱测评考试未创建成功，AISE 考试创建也不成功。
- **成功**：关联状态变「已创建」，活动可用，考生可正常报名。
- **失败**：关联状态变「创建失败」，报错并展示失败原因，运营可：
  - 重试：重新发起自动创建；
  - 保存为未关联：保存为「未关联爱测评」状态，之后补关联试卷保存时再触发创建。
- **多考场批量创建**：任一考场创建失败则整体创建失败，重试按整体重新发起。
- **列表展示**：admin「测评活动列表」关联状态展示「未关联 / 创建中 / 已创建 / 创建失败」四种，创建失败提供「重试」操作。

### 3.4 未关联状态与补关联

- 「未关联」状态保留：AISE 可先创建考试不关联试卷。
- 未关联活动后续编辑补关联试卷并保存 → 自动触发创建爱测评考试，成功后状态变「已创建」。
- 未关联活动用户端不展示（爱测评考试尚未创建，不可报名参加）。

### 3.5 容量限制删除

- 考场不再配置容量上限：admin 考场编辑弹窗删除「容量上限」字段；考场统计卡片删除「总容量」「剩余容量」，保留「考场总数」「已报名」，新增「爱测评已创建」；考场列表删除容量列。
- 联动：用户端报名选考场「满员不可选」逻辑随之移除（无容量即无满员）。

### 3.6 试卷删除保护（爱测评侧）

- 一份试卷已被考试/考场引用后，该试卷不允许删除，需先解除引用方可删除。

### 3.7 编辑联动

- AISE 修改考试/考场要素（起止时间、时长、交卷限制、试卷等）并保存后，同步更新爱测评侧对应考试（实现方式由研发确定）。
- 既有规则保持不变：已报名考场禁止修改开始/结束时间，此情形编辑联动不触发。

### 3.8 存量活动

- 存量「已同步 / 未同步 / 未关联」活动不受影响，处理口径由研发评估，不强制迁移。
