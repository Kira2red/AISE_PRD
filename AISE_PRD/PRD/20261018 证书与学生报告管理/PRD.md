## 1. 背景与收益

需求简介：管理后台「学生证书管理」补齐证书编号精确查询与导出追踪能力，运营据此核对纸质证书发放批次，并确认证书生成时机口径。

业务诉求与收益：纸质证书分批印制寄出后，运营无法回答「这份证书是否已导出制作过、何时导出、第几批寄出」，核对靠翻聊天记录；证书编号作为唯一凭证没有后台查询入口，家长报编号后运营只能按姓名手机号间接找。本需求把导出动作沉淀为可查记录，纸质发放核对在系统内闭环；预期消除导出台账手工维护，证书查询从「间接猜」变为「编号直达」。

## 2. 业务流程

运营在「学生证书管理」页：

1. 家长或合作方提供证书编号 → 筛选区输入编号精确查询 → 列表直接定位该学员
2. 导出证书包（既有能力，走消息中心下载）
3. 导出完成后，系统自动累计包内每个学员的导出次数，并写入导出记录
4. 印制寄出后，运营点开该学员的「导出记录与备注」弹窗，在备注里登记批次和时间（如「第2批 10-09 寄出」）
5. 下次核对时，列表直接看导出次数与备注摘要，点开弹窗看每次导出明细

## 3. 详细功能说明

### 3.1 证书编号精确搜索

| 变更项 | 说明 |
|---|---|
| 新增「证书编号」筛选 | 筛选区身份证号后新增输入框，占位文案「证书编号（精确搜索）」 |
| 匹配方式 | 精确匹配（全值比对，编号唯一）；已拍板，不做模糊搜索 |
| 触发方式 | 点击「查询数据」或在输入框内按回车 |
| 命中 | 列表只显示证书编号等于输入值的学员 |
| 无命中 | 列表清空，表格上方显示提示条「未找到证书编号为「XX」的记录（精确匹配）」 |
| 清除条件 | 清空输入后再次查询、或点击「重置」，恢复显示全部并清除提示条 |

明细见下：

- 筛选区其余条件维持现状，本需求不加活动、渠道、分组、照片状态等筛选（2026-10-18 拍板：不需要改筛选）
- 证书编号为空的学员不参与编号匹配（输入任意编号均不命中）
- 编号查询与其他筛选条件叠加生效

### 3.2 导出追踪（导出次数与备注）

| 变更项 | 说明 |
|---|---|
| 新增「导出次数」列 | 位置在「照片」列后；显示该学员证书被包含在导出包中的累计次数；点击打开导出记录弹窗 |
| 新增「备注」列 | 同排；显示备注摘要，超长截断显示省略号（悬停看全文）；点击打开导出记录弹窗；无备注显示「—」 |
| 导出次数计数口径 | 每次导出证书包，包内包含该学员即计 1 次（已拍板）；导出任务失败不计入 |
| 计数时机 | 导出任务生成成功（消息中心可下载）后自动累加，运营无需手工记录 |
| 备注用途 | 追踪纸质证书发放批次和时间；运营手工填写 |
| 备注编辑位置 | 详情弹窗内编辑，列表不提供内联编辑（已拍板） |
| 导出表格同步 | 导出证书包内的名单表格新增「导出次数」「备注」两列，纸质发放核对在表内闭环 |

明细见下：

- 列表只显示有证书学员的口径维持现状（源表 #31），「是否发证」筛选不建设（已拍板：与「无证书不显示」口径合并）
- 备注属于证书记录维度，跟着学员证书记录走

### 3.3 导出记录与备注弹窗

| 项 | 说明 |
|---|---|
| 入口 | 点击列表「导出次数」数字或「备注」内容 |
| 头部信息 | 学员姓名 + 身份证号、证书编号、照片状态 |
| 导出记录表 | 列：导出任务号、导出时间、包内总行数、操作人；按导出时间倒序 |
| 空态 | 该学员从未被包含在导出包中时，记录表显示「暂无导出记录」 |
| 备注编辑 | 多行文本框，placeholder 示例「记录纸质证书发放批次和时间，如：第2批 10-09 寄出」 |
| 保存 | 点击「保存备注」后保存、关闭弹窗、列表备注列即时刷新、轻提示「备注已保存」 |
| 取消 | 点击「取消」、右上角关闭或遮罩层，关闭弹窗不保存 |

### 3.4 口径说明（本需求不含开发）

1. 特殊修改：身份证改名等特殊证书修改不提供后台入口，由技术团队直接修改数据库（线下流程）；常规信息修改走列表既有「修改信息」；改库后的证书重生成按「20260816 重新生成证书」流程执行
2. 证书生成时机（源表 #32）：正式环境证书在证书流转第二环节「待复核」生成，生成后考务老师即可在后台复核证书信息，成绩公示与推送把关由「20260921 待复核生成推送把关」承接；本条为现状确认，无开发项
3. 导出白屏修复（源表 #28）：学生证书管理导出白屏按缺陷直接修复，修复后导出能力（含证书编号、照片、身份证号、级别）即达成，不占本需求范围
