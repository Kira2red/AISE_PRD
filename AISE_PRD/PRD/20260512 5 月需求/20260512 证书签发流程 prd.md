# 20260512 电子证书签发流程 PRD

## 1. 项目背景

### 1.1 平台概述

AISE 考试平台通过三种模式对外提供考试能力：

1. **AISE 网页端直接测评**：考生在 AISE 平台网页端完成考试
2. **API 嵌入测评**：合作方通过 AISE 开放 API 在自己的平台嵌入考试能力，管理功能在 AISE 组织后台模块
3. **预备测（外部测评）**：合作方自己组织内部测评，不用 AISE 测评能力，但将部分测评结果以 JSON 格式回传给 AISE

AISE 的底层考试引擎复用自爱测评平台（基于学校部署的考试平台）。对爱测评而言，AISE 平台是一个特殊的学校组织，考试、试卷管理等功能均复用爱测评。

### 1.2 现有证书系统说明

AISE 当前存在一套**实体证书制作流程**，以测评活动为单位，状态机如下：

```
批改中 → 待复核 → (成绩公示) → (证书公示) → 制作中 → 已寄送
```

该流程面向物理证书的生产生命周期（打分→复核→公示→制作实体证书→邮寄），管理入口在 admin 后台的「活动证书管理」和「学生证书管理」。

### 1.3 本次需求概述

本次新增**电子证书签发能力**，包括：

- **证书模板系统**：运营可自行配置证书样式（底图 + 拖拽字段占位 + 电子章位置）
- **证书实例配置**：以测评活动为单位，绑定模板并配置数据映射规则
- **电子签发流程**：生成 PDF → 调用第三方电子签章 API → 已签发
- **签发中心**：独立平台，供软协管理员统一管控所有用户证书的签发状态

电子证书签发与旧实体证书制作是**两条并存的链路**，互不替代，各自独立运转。

## 2. 业务流程简述

### 2.1 核心模型关系

```
证书模板 ──1:N──> 证书实例 ──1:N──> 用户证书
(样式)          (测评配置)        (个人证书)
```

| 对象       | 职责                                    | 关联          |
| -------- | ------------------------------------- | ----------- |
| **证书模板** | 纯样式层：底图、布局、字体、字段占位符、电子章位置             | 无业务关联       |
| **证书实例** | 一次测评的证书配置：绑定某场测评 + 选用哪个模板 + 定义数据字段从哪取 | 关联一场测评（1:1） |
| **用户证书** | 某用户在某证书实例下生成的具体证书，含个人信息、PDF 地址、签发状态   | 关联用户 + 证书实例 |

**签发对象是用户证书**，不是证书实例。

### 2.2 三种测评类型的数据来源

| 测评类型 | 考试数据位置 | 数据获取方式 |
|---|---|---|
| AISE 网页测评 | AISE 平台内 | 直接查 AISE 考试记录 |
| API 嵌入测评 | AISE 平台内（合作方调 API，数据落 AISE） | 直接查 AISE 考试记录 |
| 预备测（外部测评） | 合作方自己系统，仅结果 JSON 回传 AISE | 解析 JSON 结构取字段 |

网页测评和 API 测评的数据来源是同一套（AISE 考试库），统一处理。预备测走独立 JSON 解析路径。

### 2.3 电子签发核心链路

```
开发者调用证书申请 API
  → 开放平台创建申请记录（状态：pending_issue / 待签发）
    → 开放平台生成证书 PDF（根据模板填充：姓名、测评名称、成绩、等级、证书编号、签发日期）
      → 开放平台调用第三方电子签章 API（提交 PDF + 电子章 ID + 签章位置 + 业务流水号）
        → 成功：状态改为 issued，保存证书编号、PDF 地址、验签地址
        → 失败：状态改为 issue_failed，保存失败原因
          → 返回结果给开发者
```

每个用户证书的签发为一条异步任务，通过**消息队列**消费。签发中心提供全局启停开关控制所有签发任务。

## 3. 详细功能需求说明

### 3.1 证书模板管理

**位置**：admin 后台 → 侧边栏「证书管理」分组 → **证书模板管理**（导航项）

**对应文件**：`26_证书模板管理.html`

**目标**：运营人员管理所有证书模板，支持搜索、新建、编辑、复制。模板支持**启用/禁用**（不设删除操作），已禁用的模板排至列表底部。

#### 3.1.1 页面元素与展示规则

**布局**：左侧导航栏 + 右侧内容区。内容区分为顶部工具栏和模板卡片网格区。网格区按启用状态分为上下两个区域：**已启用**（上）、**已禁用**（下）。

**顶部工具栏**：

| 元素 | 类型 | 说明 |
|---|---|---|
| 模板总数 | 文本标记 | 显示 `共 N 个模板`，实时随搜索/筛选更新 |
| 搜索框 | 输入框 | 占位文案「搜索模板名称...」，支持按模板名称模糊搜索，同时搜索启用和禁用区域 |
| 启用状态筛选 | 下拉选择器 | 选项：**所有启用状态**、**已启用**、**已禁用** |
| **新建模板** | 按钮 | 主色调（brand-600），点击跳转至 `27_证书模板编辑器.html`，创建空白模板并进入编辑器 |

**模板卡片网格**：

- 采用 `grid-cols-1 md:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4` 响应式自适应布局
- 每张卡片由**缩略图区域**和**信息区域**组成
- 网格区分为两个区域，以灰色小标题分隔：**「已启用 N」**（上方）和 **「已禁用 N」**（下方），N 为各区域卡片数量

**缩略图区域**（卡片上部）：

| 元素 | 说明 |
|---|---|
| 比例 | **非固定**，根据模板存储的画布宽高（`canvasWidth` × `canvasHeight` mm）动态计算 `padding-bottom` 比例，缩略图等比缩放适配卡片宽度。默认新建模板为 A4 竖版 210 × 297mm（比例 141.4%） |
| 内容 | 显示模板底色和简化版证书文案（标题 + 装饰线 + 占位名字），不同模板用不同主题色区分 |
| 交互 | 启用态鼠标悬浮时浮现半透明蓝色遮罩 + **「点击编辑」**提示标签，点击跳转至编辑器。禁用态悬浮不显示遮罩 |
| 主题色 | 用不同的渐变色区分不同模板（如灰色默认、靛蓝、翠绿、紫色、玫红、琥珀），由模板存储的 `themeColor` 字段决定 |

**信息区域**（卡片下部）：

| 元素 | 说明 |
|---|---|
| **模板名称** | 粗体，最大宽度 100%，超出自动截断 + 省略号。禁用态文字颜色变灰（`text-slate-500`） |
| **启用状态标签** | 名称右侧显示状态徽章：**启用**（绿色）或 **已禁用**（灰色） |
| 画布尺寸 + 更新日期 | 灰色小字，格式：`210 × 297mm · 更新于 YYYY-MM-DD`，尺寸为模板实际存储的宽×高 |
| 操作按钮组 | 三个按钮水平均分：**编辑**、**复制**、**启用/禁用**（切换按钮） |

**卡片视觉差异（启用 vs 禁用）**：

| 属性 | 启用态 | 禁用态 |
|---|---|---|
| 整体透明度 | 正常（opacity: 1） | 降低（opacity: 0.55），hover 时恢复至 0.75 |
| 名称颜色 | `text-slate-800` | `text-slate-500` |
| 状态标签 | 绿色底 + **启用** | 灰色底 + **已禁用** |
| 操作按钮 | 正常灰色 `text-slate-500` | 偏灰 `text-slate-400` |
| 禁用/启用按钮 | 显示「禁用」图标 + 文字 | 显示「启用」图标 + 文字 |
| 排序位置 | 网格区上方「已启用」区域 | 网格区下方「已禁用」区域 |

**操作按钮的交互状态**：

| 按钮 | 默认态 | Hover 态 | 点击行为 |
|---|---|---|---|
| **编辑** | 灰色文字 | 蓝色背景 + 蓝色文字 | 跳转 `27_证书模板编辑器.html`（启用和禁用均可编辑） |
| **复制** | 灰色文字 | 绿色背景 + 绿色文字 | 弹出确认弹窗，副本默认启用 |
| **禁用** | 灰色文字 | 橙色背景 + 橙色文字 | 弹出确认弹窗 → 卡片移至「已禁用」区域 |
| **启用** | 灰色文字 | 绿色背景 + 绿色文字 | 弹出确认弹窗 → 卡片移至「已启用」区域 |

#### 3.1.2 交互逻辑与状态流转

**搜索过滤**：

```
初始化 → 加载全部模板卡片（启用区 + 禁用区）
  → 用户在搜索框输入关键词
    → 实时过滤两张网格区的卡片（按模板名称模糊匹配），同步更新各区域计数与总数
      → 若搜索结果为空：显示空态提示「没有找到匹配的模板，试试其他关键词」
```

**新建模板**：

```
点击「新建模板」按钮
  → 跳转至 27_证书模板编辑器.html，URL 带参数 ?mode=create
    → 编辑器以「空白模板」初始化（默认 A4 竖版 210 × 297mm、白色空白底图、无元素）
      → 保存后模板默认状态为「启用」，出现在「已启用」区
```

**复制模板**：

```
点击卡片底部「复制」按钮
  → 弹出浏览器 confirm 弹窗，文案：「确认复制模板「{模板名称}」？复制后将生成一份完全相同的副本。」
    → 用户点击「确定」：系统创建一份完全相同的模板（名称自动追加「 - 副本」），副本默认「启用」，插入「已启用」区
    → 用户点击「取消」：关闭弹窗，不做任何操作
```

**启用/禁用模板**：

```
【禁用操作】
点击卡片底部「禁用」按钮
  → 弹出浏览器 confirm 弹窗，文案：「确认禁用模板「{模板名称}」？\n\n禁用后该模板将不可用于新建证书实例，已有证书不受影响。」
    → 用户点击「确定」：卡片从「已启用」区移除，整体透明度降低、名称变灰、状态标签变为「已禁用」，按钮文案变为「启用」，卡片插入「已禁用」区末尾，更新计数
    → 用户点击「取消」：关闭弹窗，不做任何操作

【启用操作】
点击卡片底部「启用」按钮
  → 弹出浏览器 confirm 弹窗，文案：「确认启用模板「{模板名称}」？启用后将恢复可用于新建证书实例。」
    → 用户点击「确定」：卡片从「已禁用」区移除，恢复完整透明度、名称和按钮颜色恢复正常，状态标签变为「启用」，卡片插入「已启用」区末尾，更新计数
    → 用户点击「取消」：关闭弹窗，不做任何操作
```

**卡片点击**：点击卡片缩略图区域直接跳转编辑器（启用和禁用均可进入编辑）。

#### 3.1.3 模板生命周期与数据影响

| 操作 | 对已有证书实例的影响 | 对已有用户证书的影响 | 对新证书实例的影响 |
|---|---|---|---|
| 禁用模板 | 无影响，已关联此模板的证书实例仍可正常签发 | 无影响，已生成的用户证书不受任何影响 | **不可选**，新建证书实例时该模板不出现在可选列表 |
| 启用模板 | 恢复可选 | 无影响 | 重新出现在新建证书实例的可选模板列表 |
| 编辑模板 | 无影响，修改后的样式仅对新生成的用户证书生效 | 无影响，已生成的用户证书仍保留旧样式 | 新建的证书实例使用更新后的模板样式 |
| 复制模板 | 无影响 | 无影响 | 副本作为独立模板，可用于新建证书实例 |

> **设计原则**：模板只有启用/禁用，**没有删除功能**。原因：已生成的用户证书与模板存在关联关系，删除模板会导致历史证书的样式源丢失，无法追溯。通过禁用机制达到"不再使用"的目的，同时保证历史数据的完整性。

#### 3.1.4 数据校验与异常处理

| 场景 | 处理方式 |
|---|---|
| 复制模板 | 副本名称自动追加 ` - 副本`，若已存在同名副本则追加数字后缀 ` - 副本(2)`，以此类推 |
| 搜索无结果 | 网格区显示空态占位图 + 文案：「没有找到匹配的模板」 |
| 禁用的模板被设为默认 | 若某证书实例中该模板被设为默认，禁用后新建证书实例时默认模板自动回退到系统预设模板 |

#### 3.1.5 页面状态总结

| 状态 | 触发条件 | 表现 |
|---|---|---|
| 默认态 | 页面加载完成 | 展示全部模板卡片，「已启用」区在上，「已禁用」区在下 |
| 空态 | 系统中无任何模板 | 网格区显示空态引导「暂无证书模板，点击上方「新建模板」开始创建」 |
| 仅启用区为空 | 所有模板均已禁用 | 「已启用」区显示空态「暂无启用的模板」，下方正常展示「已禁用」区 |
| 仅禁用区为空 | 所有模板均已启用 | 正常展示「已启用」区，隐藏「已禁用」区分隔标题 |
| 搜索空态 | 搜索关键词无匹配 | 两张网格区均显示「没有找到匹配的模板，试试其他关键词」 |
| 筛选「已启用」 | 选择启用状态筛选 | 仅展示「已启用」区，「已禁用」区隐藏 |
| 筛选「已禁用」 | 选择禁用状态筛选 | 仅展示「已禁用」区，「已启用」区隐藏 |

### 3.2 证书模板编辑器

#### 3.2.2 顶部工具栏

| 元素 | 类型 | 说明 |

**画布尺寸变更**：

```
用户修改宽或高数值 → 点击「应用」
  → 画布按新尺寸等比缩放（显示宽度固定 280px，高度 = 280 × (高/宽)）
    → 已放置元素按比例重新计算位置
      → 若元素坐标超出新画布边界，自动裁剪到边界内
```

#### 3.2.3 左侧面板

#### 3.2.4 中间画布

**画布规格**：

| 属性 | 说明 |
|---|---|
| 显示宽度 | 固定 280px |
| 显示高度 | 等比缩放：280 × (画布高 / 画布宽)。默认 A4 竖版：280 × 396px |
| 背景 | 默认灰色点阵（`radial-gradient`，间距 16px）。上传底图后替换为底图图片 |
| 坐标系 | 原点在左上角，单位 mm。显示坐标 = 物理坐标 × 缩放比例 |
| 缩放比例 | 280 / 画布宽度（mm） |

**拖入元素**：

```
从左侧字段列表拖拽字段 → 拖入画布区域
  → 画布边框变蓝色高亮（drag-over 状态）
    → 释放鼠标：在释放位置创建新元素
      → 默认文本元素：显示「{{字段名}}」占位文字，默认字体宋体 14px 黑色居中
      → 默认电子章：60×60mm 圆形虚线框 + 「公章」文字，默认位置锁定
```

新元素默认添加在释放坐标（mm 取整），最小坐标 0，最大不超出画布边界。

**画布内操作**：

| 操作 | 行为 |
|---|---|
| 点击元素 | 选中元素 → 蓝色实线框（`outline: 2px solid #3b82f6`），右侧属性面板刷新 |

**吸附对齐**：

开启对齐参考线后（顶部复选框勾选），拖拽元素时当元素中心点距离画布中心线 ≤ 3mm 时自动吸附。参考线为红色 1px 实线，水平和垂直方向各一条，释放后自动隐藏。

**新建实例流程**：


#### 3.5.6 交互逻辑

**全局签发启停**：

```
默认：开关开启，签发运行中
  → 关闭开关 → confirm 确认
    → 开关变灰色，标签变红色「签发已停止」
      → 所有待签发任务暂停入队，新申请直接标记为「签发暂停」
    → 重新开启 → 开关变绿色，标签恢复「签发运行中」
      → 恢复所有暂停的签发任务
```

**单条操作**：

| 操作 | 触发条件 | 行为 |
|---|---|---|
| 立即签发 | 待签发 | 单条证书提交签发任务，状态→签发中 |
| 重签 | 已签发 / 失败 | 对已签发的重新生成 PDF+签章；对失败的重新提交签章 API |
| 查看 | 已签发 | 弹窗展示证书预览（模板渲染 + 电子章） |
| 下载 | 已签发 | 下载 PDF 文件 |
| 原因 | 签发失败 | 弹窗/ tooltip 显示失败原因（如「电子签章 API 超时」） |

**批量重签失败**：勾选失败行 → 点击「批量重签失败」→ confirm → 提交批量重签任务。

#### 3.5.7 数据实效性

- 统计数字和列表数据通过轮询或 WebSocket 实时刷新
- 「签发中」状态行，蓝色圆点带 `animate-pulse` 动画，表示任务进行中
- 签发完成后自动更新状态为「已签发」或「签发失败」

#### 3.5.8 页面状态总结

| 状态 | 表现 |
|---|---|
| 签发运行中 | 开关绿色，标签绿色「签发运行中」 |
| 签发已停止 | 开关灰色，标签红色「签发已停止」，待签发行仍可手动「立即签发」但不会自动入队 |
| 空态 | 无证书记录时显示「暂无证书数据」 |
| 搜索空态 | 无匹配结果时显示「没有找到匹配的证书，试试其他条件」 |
