# 改动日志

## 2026-10-22 V1.1 子账号遗弃规则调整（用户拍板）

**需求口径变化**：账号合并时，子账号（孩子）遗弃规则由「遗弃后其报名与考试记录并入主账号」调整为「遗弃仅适用于无报名与考试记录的子账号；有记录的子账号须先指定记录接收方（其他保留子账号），转移完成后方可遗弃；记录始终挂在子账号名下，不并入主账号」。

**背景**：报名以子账号（孩子）为主体，原「记录并入主账号（家长）」口径会导致记录与人对不上（家长名下出现孩子的考试记录）。

**落地范围**：
- PRD：3.1 子账号区块规则重写（5 条子规则）、报名记录明细标注转移来源、确认弹窗摘要含转移情况、回收站合并恢复含记录回退、验收标准 10→12 条
- demo：01_账号合并.html 子账号交互重构（取消勾选触发转移弹窗 → 选接收方 → 转移并遗弃；取消弹窗恢复勾选态；行内展示转移去向；摘要含转移说明）
- 飞书文档：原位更新（版本行/子账号块/4条子规则/记录块/摘要块/恢复块/demo行/修订与补充验收说明），demo 文件块 replace_file 换版并 download 验证一致

**验证**：node --check、vm 冒烟（11 项断言）、浏览器实走全链路（直接遗弃/弹窗拦截/取消恢复/转移遗弃/摘要）零错误

## 2026-10-28 V1.3 需求组答疑五点口径落稿（用户拍板）

**需求口径变化**（对应需求组五问）：
1. 记录转移同场测评冲突：强提示「仅保留接收方记录」+ 二次确认；来源方同场记录标记作废（保留在库支撑合并恢复回退），恢复时解除作废。
2. 在途业务范围补全：自报名创建起算，含待支付/审核中/退款中报名、候考中/模拟考中/进行中测评。
3. 恢复时原手机号被占用：由「允许恢复+提示处理」改为「暂不允许恢复」，提示提醒用户换新手机号重新注册，记录保留在回收站（用户拍板：不允许恢复）。
4. 90 天到期清理范围：学员名下全部明细数据（含爱测评侧）彻底删除；统计汇总计数不回溯；审计日志保留（用户拍板）。
5. 爱测评侧数据：合并时遗弃子账号的爱测评虚拟账号数据同步合并至接收方；恢复按快照回退；到期清理一并删除；同步机制由研发评估。

**落地范围**：
- PRD：3.1 冲突处理子规则、3.1/3.2 在途范围、3.3 恢复占用口径、3.3 清理范围与不回溯项、系统关联表新增爱测评行、修订记录 V1.3、验收标准 12→15 条
- demo：01_账号合并.html 转移弹窗冲突警示+二次确认（含接收方切换联动）；03_账号回收站.html 手机号占用禁用恢复（刘芸演示数据）；html/admin/12_学员管理.html 在途场景数据与边界文案更新
- 索引：12_学员管理 在途口径同步

**验证**：三份 demo node --check 通过；浏览器实走 01（冲突提示显示/二次确认拦截后执行/切非冲突接收方警示消失/摘要含转移说明）与 03（占用警示+按钮禁用/正常恢复不受影响）全链路零错误

**待确认遗留**：无（原刘玮确认项已由用户拍板「不允许恢复」）
