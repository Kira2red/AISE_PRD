# AISE 数据统计需求框架

> 文档性质：需求框架稿，用于对齐统计范围、阶段划分与指标口径；确认后可细化为正式 PRD 与页面 demo。
> 目标用户：AISE 管理员（运营后台）、AISE toB 客户（组织后台）
> 创建日期：2026-09-07　|　更新日期：2026-09-07（融合爱测评数据分析设计，闭环 Q1/Q3/Q4）

## 一、背景与收益

AISE 平台目前的数据分散在各个业务页面：报名数据在报名管理、考试过程数据在考生监控、成绩与证书数据在证书与报告相关页面，缺少一个按考试全流程聚合的统计视图。管理员与 toB 客户都需要在统一入口查看各阶段的关键数据与进度，快速掌握测评活动的整体运行情况。

本需求提供覆盖「考前—开考后—考中—考后」全流程的数据统计能力，管理员与客户使用同一套指标口径，客户仅限定为本组织的数据范围。

## 二、用户与数据范围

### 2.1 两类用户

| 用户 | 使用端 | 数据范围 | 说明 |
|------|--------|----------|------|
| AISE 管理员 | admin 运营后台 | 全平台数据 | 平台运营视角，可跨渠道/组织汇总与对比 |
| toB 客户（合作组织管理员） | org_admin 组织后台 | 仅本组织数据 | 沿用组织后台现有账号与数据隔离体系（学生列表、报名列表、项目管理均已按组织隔离） |

### 2.2 数据范围总原则

1. **指标全集一致**：管理员与客户看到的统计指标种类、口径、页面结构完全一致，客户的数据权限等同于管理员的指标全集。
2. **差异只在数据范围**：管理员看全平台并可按渠道/组织拆分；客户仅看本组织名下的报名、考生、考试过程与成果数据。
3. 数据隔离沿用组织后台既有设计：客户登录组织后台后，所有统计自动限定在该组织范围内，无需额外配置。
4. **数据权限可配置**（2026-09-07 拍板）：统计页各数据模块/指标对每个 toB 客户可按组织维度配置开放或隐藏；客户登录后仅看到被开放的模块，默认开放与既有 org_admin 页面一致的全量指标，涉及金额等敏感数据默认关闭、按商务需要逐组织放开。

## 三、统计框架总览

统计按考试生命周期分四个阶段，每个阶段回答一类问题：

| 阶段 | 时间窗口 | 核心问题 |
|------|----------|----------|
| 考前 | 报名开启 → 开考 | 报了多少人、审核与缴费进展如何 |
| 开考后（考前环节） | 模拟考开启 / 正式考开考前 | 模拟考参与情况、身份校验、录屏、到场情况 |
| 考中 | 正式考试进行中 | 作答进度、交卷进度、监考接入、异常情况 |
| 考后 | 考试结束 → 成果交付完成 | 批改、成绩、报告、证书各环节进度与结果 |

统计对象层级：平台（仅管理员）→ 渠道/组织 → 测评活动 → 场次；部分指标支持下钻到考生名单。

**页面结构借鉴爱测评「考试详情页四 Tab」设计**（[爱测评测评管理 prd](<参考 爱测评测评管理prd.pdf>) 3.1.1）：AISE 数据统计页内按「总览 / 明细」两级组织——总览页承载核心概况卡片与阶段指标，明细层包含按题统计（题目维度分析）、按人统计（成绩列表）与查看试卷，沿用爱测评已验证的交互骨架。

**数据更新与采样规则**（沿用爱测评口径，[爱测评测评管理 prd](<参考 爱测评测评管理prd.pdf>) 3.2.1）：

| 规则 | 口径 |
|------|------|
| 考前/考后统计 | 事件驱动（报名、批改、签发等业务动作落库后即更新） |
| 考中实时统计 | 每分钟更新；计算量大时可放宽至最长 5 分钟一次 |
| 过程采样留存 | 考试进行中每 1 分钟采样留存一帧：每个考生的考试状态、监考状态、答题详细数据，供时间变化图与事后分析 |
| 考试结束时点 | 考生统计类数据冻结；监考接入类数据（在线/摄像头/录屏）全部展示「-」 |
| 测评开始前 | 考中类实时指标全部展示「-」 |

## 四、分阶段指标明细

> 加粗指标为本次讨论明确提出的，其余为框架补全建议项，待逐项确认。正式 PRD 阶段再细化每项的展示形态与筛选条件。

### 4.1 考前：报名统计

| 分组 | 指标 | 口径说明 |
|------|------|----------|
| 报名规模 | **报名人数 / 报名单量**、每日新增趋势 | 按活动、场次、日趋势展示 |
| 报名状态分布 | 各状态报名量与占比 | 待支付/已支付/审核中/已通过/已驳回/已退款，状态口径对齐报名管理 |
| 审核进展 | 待审核量、已审核量、平均审核时长 | 用户信息审核与证件照审核合并统计，支持按审核类型拆分 |
| 渠道分布 | 各渠道/组织报名量 | 管理员视角指标；客户视角自动限定为本组织 |
| 场次饱和 | 各场次报名人数与饱和度 | 对照场次容量展示 |
| 费用概览 | 报名费收/退金额概览 | 金额明细报表已由交易数据统计（admin 30）承载；对客户是否开放金额跟随该组织的数据权限配置（2.2 第 4 条，默认关闭） |

### 4.2 开考后：模拟考与考前环节统计

模拟考：

| 指标 | 口径说明 |
|------|----------|
| **模拟考参与率** | 参加过模拟考的考生（进入过即算，含未完成）÷ 已报名考生；未进入模拟考的考生数单列展示 |
| 模拟考完成情况 | 参与人数、完成人次、人均次数 |

正式考·考前环节（按考试监考配置区分统计口径，配置为「不开启」的环节计入「未启用」，排除在分母外）：

| 指标 | 口径说明 |
|------|----------|
| **到场数据** | 应考人数、实际到场人数、到场率、未到场人数 |
| **身份校验情况** | 校验通过 / 校验未通过 / 未校验 |
| **录屏开启情况** | 已开启 / 未开启 / 开启异常 |
| 设备检测完成情况 | 摄像头、麦克风等设备检测完成率 |
| 检录提交情况 | 检录照片/视频已提交量（检录按考试配置为强制/非强制/不开启三态） |

### 4.3 考中：作答、交卷与监考统计

核心概况卡片（参照爱测评「考生统计」四指标）：

| 指标 | 口径说明 |
|------|----------|
| **进行中** | 已进入测评（测评开始后进入过即算，含当前在场与不在场）、未交卷的考生总数 |
| **在线** | 当前在线的考生数量 |
| **已交卷** | 已交卷的考生总数 |
| **未进入** | 已报名但从未进入本测评的考生总数 |

监考接入统计（参照爱测评「监考统计」四指标）：

| 指标 | 口径说明 |
|------|----------|
| 摄像头+录屏 | 当前在线考生中，同时接入摄像头和录屏监考的人数 |
| 仅摄像头 / 仅录屏 | 当前在线考生中，仅接入对应监考形式的人数 |
| 未接入 | 当前在线考生中，未接入任何形式监考的人数 |
| 补充：手机监考 | AISE 特有监考形式，接入口径同上，纳入接入状态统计 |

过程趋势分析（基于每分钟采样数据）：

| 指标 | 口径说明 |
|------|----------|
| **作答状态-时间变化图** | 横轴以测评开始时间为起点至结束，每 10 分钟一段，每段统计（当前段，当前段-10min]内已完成/进行中/缺考考生数；纵轴考生数；hover 气泡展示「字段-学生数量」 |
| **作答率-时间变化图** | 每 10 分钟一段统计作答率；已作答标准为题目无空白答案（选择题已选、填空题所有空已填）；作答率 = 已参测学生的已作答题目数 ÷（题目总数 × 参测学生总数）；纵轴学生数；hover 展示「作答率-XX%」 |
| 考中异常 | 切屏人数与次数、摄像头异常人数（数据来源为考生监控已有记录） |

### 4.4 考后：批改、成绩、报告与证书统计

交卷与批改：

| 指标 | 口径说明 |
|------|----------|
| **交卷时间分布** | 横轴从 0 到最大交卷时间每 10min 分档（(0,10min]），纵轴档内人数；配套平均交卷时间、最快交卷时间；hover 展示「XXmin 交卷 XX人 XX%」（档位人数÷参测总人数） |
| **批改进度** | 待批改 / 批改中（已批试卷数/总试卷数）/ 已完成（量与占比） | 
| 批改说明 | 主观题（编程、实践等）批改进度，含平均批改时长；批改中状态展示「批改中（已批改试卷数 / 总试卷数）」 |

成绩统计：

| 指标 | 口径说明 |
|------|----------|
| **平均分、最高/最低分、分数段分布、达标率、等级分布** | 按活动/场次维度；等级对齐成绩等级映射 |
| ABCD 等级口径 | 试卷总分为 100 时 A:90-100、B:60-89、C:45-59、D:45 以下；总分非 100 时等比例换算（爱测评成绩列表口径） |

成果交付进度：

| 指标 | 口径说明 |
|------|----------|
| **报告生成进度** | 已生成 / 生成中 / 未开始 / 失败；生成时机为成绩发布后自动触发 |
| **证书生成进度（电子）** | 等待成绩 / 生成中 / 待签发 / 已签发 / 失败，对齐电子证书签发状态链路 |
| 证书制作进度（实体） | 待复核 / 公示 / 制作中 / 已寄送各环节量，对齐实体证书生命周期 |

### 4.5 明细下钻：按题、按人、试卷

> 对应爱测评「题目详情页」「成绩列表页」「查看试卷」三块，AISE 侧落位为统计页的明细下钻层。

| 明细 | 内容 |
|------|------|
| 成绩列表（按人） | 全量考生列表：考生信息、起止时间、作答时长、跳出次数、考试状态（已交卷/进行中/未进入）、批改状态（未批改/批改中/最近批改分数）；支持查看试卷 |
| 题目统计（按题） | 每题展示序号、题干、知识点、难度、分值、题型 + 按题型统计：客观题（单选/多选/判断）= 正确答案选择率（选对人数÷参测人数）；填空题 = 满分占比 + 各空得分率；主观/编程/实践题 = 满分占比 + 平均得分率（得分总和÷(分值×参测人数)) + 作答率 |
| 逐题作答热力矩阵 | 题目序号 × 已作答人数占比（当前题已作答人数÷参测人数），四色分档 0-45% / 45-60% / 60-90% / 90-100% |
| 查看试卷 | 只读试卷详情：考生名称、得分、限时、总分，每题展示正确答案/考生答案/考生得分；考中实时可看（未交卷题号区分已作答/未作答两色，未作答题考生答案显示「-」，未批改显示「暂未批改」） |

## 五、统一功能规则

| 规则项 | 内容 |
|--------|------|
| 页面载体 | admin 端与 org_admin 端各新增「数据统计」一级菜单；admin 页面编号自 31 起顺延、org_admin 自 09 起顺延 |
| 展示形态 | 指标卡片 + 图表（趋势/分布）+ 明细列表，支持下钻到考生名单 |
| 筛选维度 | 时间范围、测评活动、场次、渠道（仅管理员）、报名/考试状态 |
| 数据导出 | 统计结果与明细支持导出，沿用消息中心异步导出链路 |
| 权限 | 管理员沿用 admin 账号体系；客户沿用组织后台账号体系，数据自动限定本组织 |
| 客户数据权限配置 | admin 端渠道/组织管理处为每个组织配置可开放的统计模块（2.2 第 4 条）；批改操作类按钮（重新批改等）仅管理员可用 |

## 六、与既有模块的边界

| 既有模块 | 边界说明 |
|----------|----------|
| admin 30_交易数据统计 | 收入对账报表由其承载；本需求在报名概览中只引用金额结论，明细与多维分析跳转该页面（金额模块对客户默认关闭，见 2.2 第 4 条） |

| issuance 签发中心 | 证书签发的管控操作（启停/重签）由其承载；本需求只读展示签发进度 |
| admin 14_活动证书管理 | 单活动的证书生命周期管理由其承载；本需求统计各环节数量与进度 |
