# AISE 数据分析（测评全流程数据统计）

> 需求依据：本文件夹《数据统计需求框架.md》（口径总纲）与《数据统计指标清单.md》（68 项指标明细，含单位、显示样式、可见起点、更新周期、停止时点五列）；页面原型：html/admin/36_数据分析.html、32_活动管理.html（入口）。
> 撰写日期：2026-09-14　|　状态：待评审

## 1. 背景与收益

AISE 平台的测评数据目前分散在报名管理、学员监控、证书与报告等各业务页面，运营与渠道客户无法在一个入口看全一场活动的运行全貌。本期在管理后台新增「数据分析」页：从活动管理进入，按报名、模拟考、候考、考中、考后五个阶段展示单场活动的全部关键数据，运营掌握进展、渠道客户核对己方数据，减少跨页面拼数据与开发临时取数。

## 2. 业务流程

### 2.1 入口与页面结构

- 入口：管理后台「活动管理」列表，每行操作区「数据分析」按钮，打开该活动的数据分析页（地址携带活动编号）。
- 页面从上到下：顶栏（返回活动管理、活动基本信息、当前阶段标签、导出按钮）→ 筛选区（渠道、分组、测评三个下拉 + 筛选数据按钮）→ 按阶段分区的数据内容。
- 单活动视角：页面只呈现所选活动的数据，不提供跨活动对比。

### 2.2 统计范围与筛选

- 几乎全部数据项都通过筛选确定统计范围，层级为：活动（最大颗粒度）→ 分组 → 测评；渠道为横切维度，任意层级均可按渠道拆分查看。
- 三个筛选均为下拉多选：下拉面板内支持输入关键词模糊检索选项，勾选后需点击「筛选数据」按钮才应用到页面全部数据；勾选未应用时页面提示「有未应用的筛选」；「重置」一键回到全量。
- 筛选联动规则：筛选了某维度，对应分布图只显示已选项；该维度自身占比不再参与数值折算，其余维度照常折算。

### 2.3 阶段与数据可见规则

- 数据按五阶段组织：报名、模拟考、候考（均属考前）、考中、考后。
- 页面只展示当前进展阶段及之前的数据；未到的阶段不展示。顶栏显示当前阶段标签。
- 各阶段的可见起点、更新周期、停止时点按《数据统计指标清单.md》逐项执行；总体规则：报名与考后为事件驱动（业务动作落库即更新）；考中实时类每分钟更新（计算量大时可放宽至最长五分钟）；测评进行中每分钟采样留存一帧（学员状态、监考状态、答题明细）供趋势图与事后分析；测评结束时学员统计类冻结、监考接入类展示「—」，测评开始前考中类实时指标全部展示「—」。

### 2.4 数据权限

- 管理员与渠道客户使用同一套指标口径；客户侧数据自动限定本渠道（组织后台，本期暂缓建设，入口与页面同构、后续需求承接）。
- 各数据模块对每个渠道客户可按组织维度配置开放或隐藏；金额等敏感模块默认关闭，按商务需要逐组织放开。

## 3. 详细功能说明

### 3.1 报名阶段

- 指标卡四张：报名总人数（一人一单，人数即单量）、有效报名（已支付或免支付的单，待支付不计）、待支付单量、已退款单量。
- 每日新增报名趋势：折线图，按自然日展示新增人数，支持查看整体与逐日。
- 审核数据：堆叠柱状图（每日通过、不通过、待审核）与整体指标（累计通过、累计不通过、当前待审核）；审核来源为首次报名信息审核、照片审核（随 20260911 报名信息审核闭环落地）与定制报名既有审核。
- 支付方式统计：各支付方式人数与单量（现阶段微信支付，新增支付方式自动纳入维度）。
- 支付状态统计：已支付、待支付、已退款的环形分布。
- 分布三图：分组分布、测评分布、渠道分布的报名量柱状图；渠道分布支持按报名可见性（正常、隐藏报名）筛选。
- 报名量矩阵表：行为分组（一级，加粗带小计）与测评（二级，缩进），列为渠道，单元格为对应报名量；底部为各渠道合计与总计；随筛选联动裁剪行列，筛选后无数据时显示「当前筛选下没有测评」。

### 3.2 模拟考阶段（属考前）

- 参与漏斗：应参人数（有效报名且该测评模拟考开启）、参考人数（进入过即算，含未完成）、完成人数（完成交卷），漏斗条同时展示各级占比。
- 监考开启率四组（成对显示实际人数与应开启人数及比率）：摄像头监考、录屏监考、手机监考、检录照片上传；分母为实际参考学员中该监考项配置为强制或非强制的人数（检录照片为强制或非强制配置），「不开启」配置排除并显示「未启用」；模拟考监考按其生效配置计算（可跟随正式测评或自定义）。

### 3.3 候考阶段（属考前）

- 指标卡四张：应参人数（有效报名）、候考人数（进入过候考页即算）、候考率（候考人数÷应参人数）、平均候考时长（进入候考页至测评开始）；测评未配置候考时相关项显示「未启用」。
- 监考开启四组（成对显示与开启率、上传率）：摄像头监考、录屏监考、手机监考、检录照片；摄像头与录屏的「实际开启」口径为设备检测对应项通过的学员数（同一数据源不重复统计）；检录视频随照片环节一并提交，不单独统计；分母排除「不开启」配置；测评开始时本组数据冻结，考中的在线监考情况由考中阶段另行统计。

### 3.4 考中阶段

- 到场数据六卡：应到人数（有效报名）、实到人数（进入过答题环节即算，含已离场与已交卷）、进行中人数（实到−已交卷，含不在场）、在线人数（当前在线）、已交卷人数、未进入（缺考）人数。
- 缺考口径：手机监考、电脑摄像头、录屏监考均未开启的学员计为缺考；与「应到−实到」原则同口径，作答状态图的缺考线同口径。
- 监考相关五项（当前在线学员口径，横向条形图）：摄像头与录屏同时开启、仅摄像头、仅录屏、未监考（三项均未开启）、手机监考开启人数。
- 作答状态时间变化图：横轴每十分钟一刻度，纵轴三条线为已交卷人数、测评中人数、缺考人数。
- 作答率时间变化图：横轴每十分钟一刻度，纵轴为全场平均作答率（已作答标准为题目无空白答案）。
- 交卷时间分布图：横轴刻度为十分钟、三十分钟、五十分钟……间隔二十分钟，纵轴为交卷时间落入对应区间的学员数（首档为零至十分钟）。
- 逐题作答情况大表：每题一个色块格子，分两行展示（第一行题号、第二行完成人数与百分比，如「第1题、903人 · 92%」）；按完成率四色分档：零至百分之四十五、四十五至六十、六十至九十、九十至一百。
- 考中异常三项：切屏人数与次数、摄像头异常人数、多 IP 同时在线人数与人次（同一学员同一时段多 IP 登录答题，本期只做可见，不拦截）。

### 3.5 考后阶段

- 交付进度四卡（百分比与分子分母并列）：批改进度（已批/总试卷）、报告生成（已生成/应生成）、电子证书签发（已签发/达标学员）、实体证书寄送（已寄送/达标学员）。
- 成绩统计：平均分、最高分、最低分、达标率指标卡与分数段分布柱状图；达标口径为达到证书分数线规则中勾选「发放证书」的最低档，未配置规则时走固定映射表兜底。
- 个人报告等级分布：环形图，按报告管理（admin 34）配置的报告等级分数段统计各档人数。
- 证书等级分布：环形图，按证书分数线规则配置的等级档位（如一等奖、二等奖、三等奖）统计各档人数。
- 交付进度明细：批改、报告、电子证书、实体证书四行的进度条与各状态数量（如报告已生成、生成中、失败；证书已签发、待签发）；报告等级按生成时点的配置计算，配置修改不溯及已生成报告。

### 3.6 导出

- 页面「导出」按钮导出当前筛选范围的数据，走消息中心异步导出链路（与既有导出一致）。

### 3.7 边界与状态

- 未配置环节（如该测评未开模拟考、未配置候考、某监考项为「不开启」）：对应模块整体或单项显示「未启用」，不参与分母计算。
- 阶段未开始：该阶段及之后的数据区块不展示，页面只保留已发生阶段的内容。
- 测评已结束：学员统计类数据冻结为最终值；监考接入类实时数据全部展示「—」。
- 筛选后无匹配数据：矩阵表显示空态文案，图表显示空态。
