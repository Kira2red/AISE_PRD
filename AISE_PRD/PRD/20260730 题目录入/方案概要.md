# 题目录入增强 — 方案概要

## 1. 背景

AISE 题库体系需要支持按「所属题库」区分题目来源（默认题库 / 我的题库 / AISE 题库），并在 AISE 题库下按级别（一级~八级）组织题目。当前录题表单和列表页缺少这些维度，需要增强。

## 2. 涉及页面

| 页面 | 文件 | 改动类型 |
|------|------|---------|
| 题目管理列表 | `html/admin/08_题目管理_列表.html` | 功能增强（筛选区扩展） |
| 录入/编辑题目 | `html/admin/09_题目管理_详情.html` | 功能增强（表单新增字段+模块） |

## 3. 需求与方案

### 3.1 所属题库 + AISE 级别 + 题目编号

**位置**：录题表单「基础属性」卡片内，在「题目类型」之前新增。

**方案**：

- 新增「所属题库」字段：三个 checkbox（可多选），选项为 默认题库、我的题库、AISE 题库。三个选项平级，运营可同时勾选多个——同一道题可以同时属于默认题库和 AISE 题库。
- 勾选「AISE 题库」后，下方出现「AISE 级别」单选组：一级到八级，8 个 radio button，必选其一。
- 题目编号在保存时由系统自动生成，不在表单中展示（只读展示在列表页和题目详情）。生成规则：

  | 题库类型 | 编号格式 | 说明 |
  |---------|---------|------|
  | 默认题库 | `DF-{题目ID}` | 题目ID为系统自增，不重复 |
  | 我的题库 | `MY-{创建者ID}-{题目ID}` | 创建者ID+题目ID联合唯一 |
  | AISE题库 | `A{级别}-{序号}` | 级别为1-8，序号为该级别下自增（如 A1-001, A1-002...A8-001） |

  其中「默认题库」「我的题库」的题目ID即为系统已有自增ID，AISE 题库的序号为按级别独立计数。编号生成时机：保存题目时由后端自动分配，前端不可编辑。

### 3.2 题目标题

**位置**：录题表单中，在「知识点标签」和「题干内容」之间新增一行。

**方案**：

- 新增一个单行文本输入框「题目标题」，placeholder 例如「1.程序输出判断」
- 非必填。如果填写了，在答题报告页面的题目区展示该标题；如果未填写，报告页沿用现有逻辑（直接用题干前 N 个字或全部题干）
- 列表页的搜索范围从仅「题干」扩展为「标题 + 题干」联合搜索

### 3.3 列表页筛选增强

**位置**：题目管理列表页的筛选搜索区域。

**方案**：

- 搜索框行为调整：原「搜索题干关键词...」改为搜索「标题 + 题干」，placeholder 更新为「搜索标题或题干关键词...」
- 新增筛选维度（在现有「全部题型」下拉旁边增加）：
  - 「全部题库」下拉：全部 / 默认题库 / 我的题库 / AISE 题库
  - 「全部级别」下拉：全部 / 一级 ~ 八级（仅在选择「AISE 题库」筛选项后可用，或始终可用但仅在适用时有结果）

### 3.4 编程 OJ 参考答案上传

**位置**：录题表单中，当题目类型为「实操编程题」时，在「选项设置」卡片位置替换为「参考答案」卡片。

**方案**：

- 题目类型选「实操编程题」时，隐藏「选项设置」卡片，展示「参考答案」卡片
- 「参考答案」卡片包含：
  - 参考答案代码文件上传框（支持 .py / .java / .cpp / .js 等常见编程文件格式）。上传后显示文件名和文件大小
  - 上传后，后端保存文件内容，视为该编程题的标准答案
- 在考生个人报告（或答题结果页）中，如果是编程题，提取参考答案的前 5 行展示（标注「参考答案预览」），帮助考生对照自己的答案

## 4. 不做事项

| 事项 | 原因 | 
|------|------|
| Markdown 批量上传 | 产品批注「先不做」，后续单独出需求 |
| AISE 级别筛选在非 AISE 题库时的禁用联动 | 先做基础版本，联动逻辑后续迭代 |
| 题目编号在表单中可编辑 | 编号由系统自动生成，避免人工冲突 |

- [ ] 录题表单中「标签」和「题干」之间新增「题目标题」输入框
- [ ] 列表页搜索框能同时搜索标题和题干
- [ ] 列表页新增「题库」和「级别」两个下拉筛选
- [ ] 编程 OJ 题型下有文件上传区域，上传后显示文件名
