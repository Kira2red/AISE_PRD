# 爱测评题目录入增强 PRD

> 适用范围：爱测评平台「题目管理」录题/列表功能（AISE 组织复用爱测评能力，本题需求在爱测评基础上修改）
> 规则出处：`方案V1.md`（本文件夹）、线上采集材料（`线上采集/`，2026-08-26 登录 adminAica 实测）、需求原文（2026-08-26）

## 1. 背景与收益

**需求简介**：爱测评录题功能对编程类题目支持不足——图形化编程题的答案/解析常以积木截图表达但解析框只能写文字、题目无法标记编程语言、读题配文需要手工誊抄题干选项、编程题录入后无法预览和测试。本次在录题表单和题目列表上做 4 项增强：答案解析支持插入图片、新增编程语言字段与按语言搜索、读题文本一键复制题干/选项、编程题增加预览/测试按钮。

**业务诉求与收益**：AISE 运营在爱测评录入 Scratch/代码类编程题时，答案解析图片与文字可一并保存，题目按编程语言标记后可快速检索，读题配文从手工誊抄变为一键复制，录入后可直接预览学生端效果并进入答题页测试，录入效率和题目质量均有提升。

## 2. 业务流程

- **图形化编程题录入**：运营登录爱测评 → 题目管理 → 录入题目 → 勾选所属题库（勾选 AISE题库 后选择 AISE级别）→ 题型选「图形化编程」→ 选择编程语言 → 选择知识标签 → 填写题目标题/题干 → 配置读题文本（可一键复制题干/选项）→ 答案解析中输入文字并插入图片 → 题目设置区配置可用积木 → 预览/测试 → 保存。
- **代码编程题录入**：题型选「编程OJ」或「编程」→ 选择编程语言 → 填写题干与 OJ 配置（代码类型/输入输出描述样例/答题时长/内存限制/参考答案文件）→ 预览/测试 → 保存。
- **按语言检索**：题目管理列表页 → 「编程语言」筛选下拉选择语言 → 列表仅展示该语言题目。

## 3. 详细功能说明

### 3.1 图形化编程「答案解析」支持插入图片

- **位置**：录题/编辑表单「答案解析」字段（题型为「图形化编程」时展示；「编程OJ」按线上规则不展示答案解析）。
- **目标**：答案解析从纯文本输入框升级为富文本编辑框，支持文字与图片混排，图片随解析内容一并保存。
- **形态**：答案解析为富文本编辑框，工具栏提供 加粗/斜体/下划线/插入图片；编辑区内文字与图片混排展示，图片以缩略图（最大宽 200px、圆角）形式插入光标位置。
- **图片规则**：
  - 支持格式：png / jpg / jpeg / gif / webp；
  - 单图大小不超过 5MB（上限以后端实际文件服务配置为准）；
  - 支持一次选择多张、分次插入多张；已插入图片可直接在编辑区内选中删除；
  - 保存时图片与解析文字一并保存；编辑已有题目时解析富文本（含图片）原样回显。
- **边界与异常**：
  - 格式不支持或超过大小限制时，轻提示具体原因（如「不支持的图片格式」「图片超过 5MB」），该图片不入编辑区，其余正常；
  - 解析内容为空时编辑区显示占位提示「请输入答案解析」。

### 3.2 编程语言字段与按语言搜索

- **位置**：录题/编辑表单，所属题库/AISE级别 之后、题型之前（标注截图第③步）；题目管理列表页筛选区与表格。
- **目标**：编程类题目标记所属编程语言，录题后可按语言检索题目。
- **录题侧规则**：
  - 字段名「编程语言」，必选，单选；
  - 选项：图形化（Scratch）、Python、C++、C（与线上「代码类型」字典对齐：Scratch3/命令行Python/C语言/C++）；
  - 仅在编程类题型（图形化编程、编程OJ、编程）下展示；切到非编程题型时字段隐藏、已选值清空；切回时需重新选择；
  - 编辑已有题目时回显已保存的语言值，允许修改；
  - 选择语言后，「知识标签」树联动过滤，仅展示该语言对应的知识树（图形化→Scratch 知识树，Python→Python 知识树）；该语言暂无知识树时显示空态提示「该语言暂无知识标签」；未选择语言时展示全部语言知识树；
  - 保存时未选语言校验拦截，提示「请选择编程语言」。
- **列表侧规则**：
  - 筛选区新增「编程语言」下拉：全部/图形化（Scratch）/Python/C++/C，与其他筛选条件（关键词/所属题库/AISE级别/题型/难度）可组合使用，重置筛选时一并恢复默认；
  - 表格新增「编程语言」列，位于「题型」列之后；无语言值的题目该列显示「-」；
  - 语言值以标签样式（浅蓝底蓝字圆角标签）展示。

### 3.3 读题文本配置一键复制题干/选项

- **位置**：录题/编辑表单「读题文本配置 (TTS)」区域，标题行右侧操作按钮（与「试听发音」同排）。
- **目标**：运营配置读题文案时，一键复制题干文本、选项文本，免手工誊抄。
- **操作与格式**：
  - 「复制题干」：复制题干纯文本到剪贴板，轻提示「已复制题干文本」；题干为空时提示「题干为空，请先填写题干」；
  - 「复制选项」：复制全部选项文本到剪贴板，格式为 `选项字母、选项文本`（顿号分隔，如 `A、短作业优先调度`），多个选项之间换行分隔；复制后轻提示「已复制选项文本」；
  - 复制失败（剪贴板不可用）时自动降级为兼容复制方式，仍失败则提示「复制失败，请手动复制」。
- **状态规则**：
  - 非选择题型（填空/编程类等无选项题型）下「复制选项」按钮置灰不可点，悬浮提示「本题无选项」，点击提示「本题型无选项，无法复制」；
  - 选择题型下若尚未填写选项，点击提示「暂无选项内容」；
  - 题干中包含图片时，复制出的文本中以 `[图片]` 占位该图片。

### 3.4 编程题「预览/测试」按钮

- **位置**：录题/编辑表单，编程类题型（图形化编程、编程OJ、编程）下「预览/测试」行，答案解析/代码类型之后。
- **目标**：录入过程中随时确认题目在学生端的效果；「测试」按题型提供两种自测能力——图形化编程预览预置积木、代码题按测试用例判分自测（口径：2026-08-27 与运营确认）。
- **预览（两类题型通用）**：
  - 点击「预览」打开弹窗，标题「题目预览（学生端）」，按学生端视图展示当前表单内容：题目标题、题干、选项（选择题型）、答案解析（含已插入图片；无解析时不展示该区）；
  - 未填写的内容按占位展示（标题占位「例：程序输出判断」，题干占位提示填写）；
  - 弹窗关闭方式：右上角 ✕、点击遮罩、底部「关闭」按钮。
- **测试（按题型分叉）**：
  - **图形化编程**：测试即**预览预置积木**——弹窗展示题目标题/题干 + 「可用积木」清单（按分类展示积木块，与「题目设置」积木区数据同源，仅展示未禁用积木），即学生端答题时 Scratch 编辑器可用的积木范围；图形化无判分，故不涉及测试用例；
  - **代码题（编程OJ/编程）**：测试即**判分自测**——老师已上传参考答案文件并配置测试用例（输入/预期输出/分值）后，点击「测试」触发判分：
    - 判分过程中弹窗显示「判分中」状态；
    - 判分完成后展示测试用例结果表：编号 / 输入 / 预期输出 / 实际输出 / 结果（通过/失败，失败标红）/ 该用例得分；
    - 底部汇总：通过数 / 总用例数 + 总分 / 满分；
    - 提供「重新判分」按钮；判分失败时提示失败原因并可重试；
    - 目的：让老师确认测试用例与参考答案的判分结果符合预期，再发布题目。
- **边界**：预览/测试读取的是当前表单草稿内容，不依赖是否已保存；参考答案未上传或测试用例未配置时点击「测试」给出对应提示。

### 3.5 不做事项

- Scratch 编辑页（/scratch3）与答题页本身不在本次改造范围，仅作为跳转目标引用；
- 编程OJ 的参考答案上传、测试用例、评分标准为线上已有能力，本次不调整；
- 列表页其余筛选、表格列、题目详情弹窗为线上既有形态，本次仅新增编程语言维度。
