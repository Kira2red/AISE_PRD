## 1. 背景与目标

AISE 的题目录入复用爱测评平台「题目管理」的录题功能（AISE 在爱测评视角下为特殊组织）。本次在爱测评现有录题/列表基础上做 4 项增强，全部 P0：

1. 图形化编程「答案解析」支持图片上传
2. 录入时支持选择编程语言（Scratch/Python/C/C++），支持通过编程语言搜索题目
3. 读题框一键复制题干文本、选项文本（复制选项格式：ABCD 后顿号「、」+选项文本）
4. 编程题增加「预览/测试」按钮

### 线上采集结论（2026-08-26 实测，已登录 adminAica）

- 页面可访问；browser 工具修复后完成登录采集（表单 4 状态、列表页、详情弹窗、知识标签树、scratch3 页全部截图+HTML 存档于 `线上采集/`）
- 线上真实结构（从 bundle + 渲染 DOM 提取）：
  - 主色 `#2A55E5`；题型按钮为胶囊形（#F4F4F5 底，选中 #E5F5FF/#2A55E5）
  - 表单字段顺序：所属题库 → AISE级别（勾选 AISE题库后出现）→ 题型（客观6+主观8）→ 知识标签 → 题目标题 → 题干（CKEditor5）→ 读题文本配置(TTS) → 分隔符 → 答案解析 → 代码类型/模板文件 → OJ配置 → 可见范围 → 取消/仅保存/保存并提交
  - 图形化编程态已含「题目设置」积木配置区（Scratch 积木 9 大类）；其「编辑题目」按钮线上行为即 `window.open("/scratch3/index.html?scene=create&role=teacher")`
  - 「代码类型」字典：Scratch3 / 命令行Python / C语言 / C++
  - 列表页：关键词（搜索标题或题干）/所属题库/AISE级别/题型/知识标签/难度 筛选 + 表格列（题目ID/题型/题干/知识标签/可见范围/出题人/操作）+ 详情弹窗
  - 编程OJ 态线上已有：参考答案文件上传+前5行预览+测试用例评分标准；OJ 隐藏答案解析（线上规则 questionType != 6 && != 8）

## 2. 需求落点（用户拍板结论）

| # | 需求 | 拍板结论 |
|---|------|---------|
| 1 | 答案解析图片上传 | 答案解析是**单一字段**（纯文本 textarea）；支持图片上传（png/jpg/gif/webp，单图≤5MB 假设值），图片随解析内容一并保存展示 |
| 2 | 编程语言 | 字段位置按标注截图第③步（所属题库→AISE级别→编程语言）；仅编程类题型（图形化编程/编程OJ/编程）显示且必选；选项 图形化(Scratch)/Python/C++/C（与线上 codeType 字典对齐：Scratch3/命令行Python/C语言/C++）；选语言后知识标签树联动过滤（纳入）；列表页加「编程语言」筛选下拉 + 表格加「编程语言」列 |
| 3 | 读题框一键复制 | 读题文本配置(TTS)区加「复制题干」「复制选项」两按钮，复制到剪贴板；选项格式 `A、文本` 换行分隔；非选择题复制选项置灰；题干含图片以 [图片] 占位 |
| 4 | 预览/测试按钮 | 编程类题型内容区加按钮：预览=学生端题目预览弹窗；**测试=打开编程题答题页（学生端答题体验，线上路由 `/examine`，需 userPaperId）——线上代码核实：学生答题页为 /examine，图形化编程题在答题页内嵌 Scratch 编辑器（player iframe）作答、代码题以代码编辑器作答；测试并非打开 Scratch3 编辑页（`/scratch3/index.html?scene=create&role=teacher` 是题目设置区「编辑题目」按钮的线上目标页）** |

## 4. 边界与异常场景

| 场景 | 处理 |
|------|------|
| 上传图片格式不支持 | 前端拦截提示（png/jpg/gif/webp） |
| 单图 >5MB | 拦截提示压缩或换图 |
| 非选择题复制选项 | 按钮置灰，toast「本题型无选项，无法复制」 |
| 题干含图片复制 | [图片] 占位 |
| 编程题未选语言保存 | 校验拦截「请选择编程语言」 |
| C/C++ 无知识树 | 知识标签树显示空态「该语言暂无知识标签」 |
| 积木删除/恢复/全选/清空 | 可用/不可用双向切换（线上形态） |
| 测试按钮 | window.open 新窗口打开 scratch3（线上行为同构） |
