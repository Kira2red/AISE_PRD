# 考试管理看板 — 方案概要（V1）

> 日期：2026-09-08 ｜ 阶段一：产品方案（待确认后进入 demo） ｜ 交付流程：产品大师三阶段

## 1. 背景与目标

一句话：在 admin 端新增「考试管理看板」页面，用类似多维表格的形式，把全平台所有渠道、所有分组、所有活动的所有考试收进一页，支持批量上传新建、批量导入修改，让运营整体全览进度、快速批量调整。

现状痛点（依据 D：用户反馈 2026-09-08）：
- 一场考试散在多处配置：爱测评组卷 → AISE 05 新建测评活动 → 02 渠道关联（分组/报名费/展示时间）。没有全局视图，进度全靠逐个点开。
- 05 新建测评活动弹窗 20+ 字段，逐条配置效率低；一场考级常配多场活动（多时间段/多科目），重复劳动多。
- 线上版本部分字段创建后不易修改，需要表格化批量修改补齐这条通路。
- 「03 测评活动列表」只有活动维度，看不到渠道/分组/报名费，起不到全局看板作用。

不做的事：不改造现有 02/03/04/05 页面（单条编辑通路保留），看板是新增的批量入口；不涉及用户端改动。

## 2. 用户故事与旅程

### 2.1 运营侧

- 作为运营，我希望打开一个页面就能看到所有渠道 × 分组 × 活动 × 爱测评创建状态（未关联/创建中/已创建/创建失败）× 报名费 × 展示时间 × 报名量，一眼掌握全局进度。（依据 D）
- 作为运营，我希望在表格里批量勾选多行，统一改分组/报名费/展示时间/展示开关，不用逐个点开弹窗。（依据 D）
- 作为运营，我希望下载模板、线下填好、上传直接批量新建一整批活动（含渠道关联配置），系统逐行校验并反馈结果。（依据 D；三步上传交互参照 admin/10_批量导入 内部先例）
- 作为运营，我希望上传一份「修改表」批量更新既有活动/关联配置的字段，解决「字段创建后不好修改」的问题。（依据 D）
- 所有批量操作走异步任务，消息中心通知 + 结果文件下载，可留痕可追溯。（依据 E：平台既有异步导出惯例，如导出证书包）

### 2.2 旅程

- 批量改旅程：登录 admin → 考试管理看板 → 筛选（渠道/分组/状态/时间）→ 勾选行 → 批量设置 → 确认 → 表格刷新 → 消息中心收结果。
- 批量建旅程：看板 → 批量上传新建 → 下载模板 → 填写 → 上传 → 校验预览（成功/失败逐行反馈）→ 确认创建 → 消息中心收创建结果。

## 4. 范围边界：哪些字段进批量修改（关键口径）

看板与批量修改覆盖：
- **活动基础字段**：测评名称、考试起止时间、时长、交卷限制、标签、测评描述
- **渠道关联配置**：所属分组、报名费、前端展示时间、前端展示开关

不进批量修改（仍走 05/02 弹窗单条配置）：
- **监考配置**（10 项，随自动创建下发爱测评，逐项三档/开关语义，批量改误操作风险高）
- **模拟考配置**（独立面板、与正式考监考联动）
- **关联试卷**的更换（涉及爱测评考试重建/联动，单条操作可控）
- **证书落款**（低频）

「线上字段创建后不好修改」的痛点，本期由批量导入修改覆盖活动基础字段 + 渠道关联配置来解决；考试引擎侧字段（监考/模拟考/试卷）不在本期批量范围。

## 5. 核心流程

### 5.1 看板浏览与批量修改
看板页 → 筛选 → 勾选行 → 批量设置（分组/报名费/展示时间/展示开关）→ 预览影响行数 → 确认 → 表格刷新 + toast → 消息中心任务记录。

### 5.2 批量上传新建
模板下载（列：活动基础字段 + 渠道/分组/报名费/展示时间/展示开关；监考等未列出字段按系统默认值）→ 上传 → 逐行校验（必填/格式/渠道内活动不重名/时长≥交卷限制/时间合法）→ 校验预览（失败行标红+原因）→ 确认创建 → 异步创建活动 + 渠道关联 + 自动创建爱测评考试 → 消息中心收结果。

### 5.3 批量导入修改
下载当前筛选结果模板（回填现有值）→ 线下改目标列 → 上传 → 按活动ID+渠道ID定位行、只更新填写/改动的列 → 校验（同上 + 已报名活动禁改起止时间）→ 预览 → 确认更新 → 消息中心收结果。

### 5.4 典型场景（用户旅程）
某渠道 5 场活动报名费 ¥300 → ¥280：旧路径 02 渠道管理逐个点开关联活动弹窗改 5 次；新路径看板筛渠道 → 勾 5 行 → 批量设 280 → 确认，一次完成。

## 6. demo 页面规划

- 新页面：`html/admin/32_考试管理看板.html`（编号顺延），侧边栏挂教务中心分组下
- 结构：筛选区 → 工具栏（批量操作/上传新建/导入修改/导出）→ 多维表格；数据变化用 localStorage 模拟持久化
- 上传/导入弹窗参照 10_批量导入 的三步流程交互样式

## 7. 风险与依赖

- 依赖 20260825 自动创建链路（批量新建每行都触发爱测评考试创建，失败行需单独反馈与重试口径）
- 已报名活动改起止时间的禁改规则须在校验中硬性拦截（既有规则）
- 数据量评估：渠道×活动关联行数为几十~几百量级，表格无性能压力（依据 E）
- 修改表「部分填写列」语义需在校验预览里明确展示，避免误改

## 8. 待拍板清单

**A. 范围与页面形态**
1. 批量新建模板是否含监考配置列：含（一次配好但模板列多、校验复杂）vs 不含（监考走默认值，建完进 05 单条调）？→ 建议不含。
2. 批量导入修改可改字段范围：仅渠道关联配置 vs +活动基础字段 vs +监考？→ 建议活动基础字段+渠道关联配置（即 §4 口径）。
3. 行内快速编辑（F9）本期做不做？→ 建议后置，本期靠批量操作栏+行操作跳弹窗。
4. 统计卡片区（F8）做不做？→ 建议不做，纯看板足够。

**B. 业务口径**
5. 修改表定位行的方式：活动ID+渠道ID vs 渠道+活动名称？→ 建议双 ID（模板回填自带）。
6. 批量新建行结构：一行=活动+一个渠道关联 vs 活动/关联分段多行？→ 建议一行=活动+一个渠道关联，一场活动挂多渠道就填多行（活动名称相同、渠道不同）。
7. 编辑联动口径沿用：修改表改起止时间/时长/交卷限制 → 按既有规则同步爱测评侧；已报名活动禁改起止时间。是否 OK？
8. 批量新建触发的爱测评考试创建失败：该行活动存为「未关联」状态可后续补建 vs 整批回滚？→ 建议失败行存未关联+结果文件标明，不回滚整批（与 20260825 单条口径一致）。

**C. 交互细节**
9. 批量操作栏支持字段：分组/报名费/展示时间/展示开关四项？→ 建议就四项。
10. 校验预览展示：全量行（失败标红）vs 只展示失败行？→ 建议全量（参照 10_批量导入）。
11. 结果文件：成功/失败明细 Excel？→ 建议 Excel，zip 打包可后置。

**D. 命名与入口**
12. 页面命名：「考试管理看板」？「考试总览」？→ 建议「考试管理看板」，demo 文件 `32_考试管理看板.html`。
