# AISE 考试管理看板 PRD

> 需求文件夹：20260908 考试管理看板 ｜ 方案依据：[方案V1.md](方案V1.md)（12 项拍板）＋ 2026-09-08 五轮 demo 修正 ｜ 页面 demo：[html/admin/32_考试管理看板.html](<../../html/admin/32_考试管理看板.html>) ｜ 相关需求：[爱测评考试自动创建 PRD](<../20260825 爱测评考试自动创建/爱测评考试自动创建 PRD.md>)、[渠道分组与报名活动卡片 PRD](<../20260826 渠道分组/渠道分组与报名活动卡片 PRD.md>)

术语口径：本文「活动」指测评活动（一场活动对应一场爱测评考试）；「渠道」指合作机构；「分组」指渠道内活动分组（含系统「默认」分组）；「一行」指一个活动在一个渠道下的关联配置（渠道 × 活动）；「锁定」指因前置状态不允许修改。

---

## 1. 背景与收益

在 admin 端新增「考试管理看板」页面，用多维表格把全平台所有渠道、所有分组、所有活动的考试配置收进一页，支持勾选批量修改、批量导入（自动判定新建或修改）。业务诉求：一场考试的配置散在渠道管理、测评活动等多个页面，无全局视图，进度全靠逐个点开；线上部分字段创建后不易修改，逐条调整效率低。收益：运营在一个页面完成考试配置的全览与批量调整，批量调价、批量换分组等场景从逐条操作变为一次完成。

## 2. 业务流程

1. 运营进入考试管理看板，通过筛选（关键词 / 渠道 / 分组 / 爱测评创建状态 / 考试进度）定位目标行，统计卡与表格呈现全局进度。
2. 批量修改：勾选多行 → 打开批量修改弹窗（分区展示全部可改字段）→ 填写要改的字段（留空保持原值）→ 底部摘要确认改动项 → 应用；触发爱测评联动的字段按既有规则同步更新。
3. 批量导入：下载模板（空白模板或回填修改表）→ 线下填写 → 上传 → 系统按「活动ID + 渠道ID」自动判定每行是新建还是修改 → 校验预览（标类型、失败行标原因）→ 确认导入可执行行。
4. 批量操作均走异步任务：提交后即时返回，执行结果通过消息中心通知，并提供成功 / 失败明细文件（Excel）下载。

## 3. 详细功能说明

### 3.1 看板主页

**位置**：admin 端新页面「考试管理看板」（侧边栏教务中心分组下，demo 编号 32）。

**统计卡片区**（只保留核心指标）：关联总行数（及覆盖渠道数）、已创建、创建中 / 未关联、创建失败、总报名量。

**筛选区**：
- 关键词（活动名称 / 活动ID / 渠道名称）、渠道下拉（全部渠道 + 各渠道，显示名称与渠道号）、分组下拉（联动渠道：仅列该渠道的分组，含默认）、爱测评创建状态（已创建 / 创建中 / 未关联 / 创建失败）、考试进度（未开考 / 进行中 / 已结束）、重置。

**表格（一行 = 渠道 × 活动）**：

| 列 | 说明 |
|----|------|
| 渠道 | 渠道名称 + 渠道号 |
| 分组 | 所属分组；「默认」以系统分组样式展示 |
| 测评活动 | 活动名称 + 活动ID + 标签（彩色小标） |
| 关联试卷 | 试卷名称；未关联显示占位 |
| 考试时间 | 考试起止时间（同日合并显示）+ 进度标签（进行中 / 已结束） |
| 时长 / 交卷限制 | 分钟数 |
| 报名费 | 该渠道配置价（支持列头排序） |
| 前端展示时间 | 起止日期；勾选「永久有效」的行显示「起始日期 起 · 永久有效」 |
| 展示 | 展示中 / 隐藏 |
| 监考配置 | 摘要（摄像头、录屏、检录照片档位，手机监考，开关差异，候考时长） |
| 模拟考 | 未开启；或「已开启 · 模拟卷 · 次数 · 交卷≤N分」+ 监考口径（同正式考 / 自定义） |
| 爱测评状态 | 未关联 / 创建中 / 已创建 / 创建失败（失败行展示原因） |
| 报名量 | 人数（支持列头排序） |
| 操作 | 创建失败行「重试」、未关联行「补关联」（选试卷后自动创建）、全部行「详情」 |

- 考试时间、报名费、报名量三列支持列头排序。
- 「详情」打开抽屉：分组查看该行全部字段（渠道关联、考试要素、监考配置、模拟考含模拟考监考），锁定字段带锁标识；底部「去单条编辑」跳现有编辑入口。
- 不做行内单元格编辑；深度配置仍走现有页面（05 编辑弹窗、02 关联活动弹窗），看板不替代它们。
- 行数规模为渠道 × 关联活动数（几十至几百量级），整表平铺展示。

### 3.2 批量修改弹窗

**入口**：勾选一行或多行后，工具栏「批量修改」按钮（未勾选时置灰）。

**弹窗形态**：大尺寸弹窗（约 1080px 宽），全部字段分五个分区内联铺开，不出子弹窗：

| 分区 | 字段 |
|------|------|
| 渠道关联 | 所属分组（下拉）、报名费（元）、展示开始日期、展示结束日期 + 「永久有效」勾选（勾选后日期输入禁用，与渠道管理页交互一致）、前端展示开关 |
| 活动基础（考试要素） | 测评名称、关联试卷（下拉）、考试开始 / 结束时间、时长（分钟）、交卷限制（分钟）、标签（逗号分隔、覆盖式，如「Python,2级」）、测评描述、证书落款时间（用户初次查看时间 / 指定日期，选指定日期联动日期输入） |
| 正式考监考配置 | 摄像头监考、录屏监考、检录照片（各三档分段选择：强制开启 / 非强制开启 / 不开启）、候考时长（0–120 分钟，0=不开启）、手机监考、成绩开关、分数开关、读题开关、检录视频引导文案（文本，留空不修改，填「恢复系统默认」语义见下）、检录视频示意图（不修改 / 恢复系统默认 / 上传新图） |
| 模拟考配置 | 开启模拟考（是 / 否）、模拟卷、模拟考开始 / 结束时间、次数限制、模拟考交卷时间限制（分钟，空 = 不限） |
| 模拟考监考配置 | 口径切换（跟随正式考 / 自定义）+ 自定义字段（摄像头、录屏、检录照片三档，候考时长，手机监考、成绩、分数、读题开关）。模拟考监考允许与正式考不同；未自定义时跟随各行正式考配置；改回「跟随正式考」即清除自定义 |

**填写语义**：
- 留空 /「不修改」/ 保持弹窗初始默认值的字段一律不改，仅下发明确改动的字段。
- 底部实时摘要「将修改：××、××」只列实际改动的字段，与填写联动。
- 引导文案：填写即覆盖；恢复系统默认通过清空语义（修改表）或单独选项实现。示意图：批量链路只支持「不修改 / 恢复系统默认」，上传新示意图需到单条编辑完成。

**可改范围**：单条配置能改的字段均可批量修改（上表全量）。

**锁定规则（前置条件校验）**：

| 前置状态 | 锁定字段 |
|---------|---------|
| 考试已开始或已结束 | 全部考试要素：名称、起止时间、时长、交卷限制、试卷、标签、描述、证书落款、监考配置、模拟考配置（含模拟考监考与模拟考交卷限制） |
| 已有报名（考试未开始） | 考试起止时间（线上既有规则：已报名禁改起止时间） |
| 渠道关联类字段（分组、报名费、展示时间、展示开关） | 任何状态均可改，不锁定 |

- 弹窗内：所选行中存在锁定该字段的行时，该字段置灰并带锁标识；应用时对应行跳过该字段，其余字段正常应用。
- 应用结果轻提示：「批量修改完成：N 行已应用，M 行因锁定字段被跳过」。

### 3.3 批量导入（新建 + 修改合一）

**入口**：顶栏「批量导入」按钮。三步流程：下载模板 → 上传文件 → 校验预览。

**模板**（一套模板两种用法，列一致）：
- 空白模板（批量新建用）：活动ID、渠道ID 留空。
- 回填修改表（批量修改用）：导出当前筛选结果并回填现有值，线下改动目标列。
- 模板列覆盖表格全字段：活动ID、渠道ID、测评名称、渠道名称、所属分组、关联试卷、考试起止时间、时长、交卷限制、报名费、展示起止日期、永久有效、前端展示、标签、测评描述、证书落款、正式考监考全项（摄像头 / 录屏 / 手机 / 检录照片 / 成绩 / 分数 / 读题 / 候考时长 / 引导文案 / 示意图口径）、模拟考全项（开启 / 模拟卷 / 起止 / 次数 / 交卷时间限制 / 模拟考监考口径）。
- 模板列头注明「活动ID（修改行填，新建留空）」。

**判定规则**：「活动ID + 渠道ID」已存在 = 修改该行配置（留空列保持原值）；留空或组合不存在 = 新建。新建行与修改行可混合上传。

**上传**：支持 Excel / CSV，单次上限 200 行。

**校验预览**：
- 每行标注类型：新建（蓝）、修改（紫）；失败行整行标红并注明原因。
- 汇总条：新建 N · 修改 N · 失败 N；确认按钮显示「确认导入 N 行（新建 x · 修改 y）」，仅执行可执行行，失败行不影响其他行。
- 校验项：必填（新建行的测评名称、渠道、考试时间、时长、交卷限制）、时长不小于交卷限制、渠道内活动不重名、时间合法、修改行的锁定规则与已报名禁改起止时间（同 3.2）、试卷为空的新建行可执行但保存为「未关联」状态。

**执行**：
- 新建行：创建活动 + 渠道关联，已填试卷的自动创建爱测评考试（失败行存「未关联」，不回滚整批，与单条创建口径一致）。
- 修改行：按定位更新填写的列；触发爱测评联动的字段（时间 / 时长 / 交卷限制 / 试卷 / 监考 / 模拟考）按既有编辑联动规则同步更新爱测评侧。
- 提交后进入异步执行，结果见消息中心。

### 3.4 异步任务与结果反馈

- 批量修改、批量导入均走异步任务：提交即时返回，页面刷新当前数据。
- 消息中心通知执行结果，提供成功 / 失败明细文件（Excel）下载；失败明细含行标识与失败原因。
- 导出：看板支持「导出当前结果」，按当前筛选导出全字段 Excel。

### 3.5 范围与边界

- 本需求为新增页面，不改造现有渠道管理（02）、测评活动列表（03）、测评活动详情（04）、新建测评活动（05）页面；单条编辑通路保留，看板与批量导入不替代它们。
- 不做行内单元格编辑（后续视需要迭代）。
- 「模拟考交卷时间限制」为测试环境已有字段（2026-09-08 用户确认），本地 demo 与[爱测评考试自动创建 PRD](<../20260825 爱测评考试自动创建/爱测评考试自动创建 PRD.md>) 的模拟考要素清单（模拟卷 / 起止 / 次数）尚未收录该字段，该 PRD 待同步修订；本文按线上实有口径纳入。
- 定制报名流程（元创S营等）不涉及本需求；渠道选择（登录渠道检测）无改动。
- 数据口径：渠道内活动分组、「默认」分组规则、一个活动一个渠道内只归一个分组，沿用[渠道分组 PRD](<../20260826 渠道分组/渠道分组与报名活动卡片 PRD.md>)；爱测评考试自动创建、四态状态、编辑联动、已报名禁改起止时间，沿用[爱测评考试自动创建 PRD](<../20260825 爱测评考试自动创建/爱测评考试自动创建 PRD.md>)。
