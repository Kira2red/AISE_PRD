# AISE 活动管理与考试批量配置 PRD

> 需求文件夹：20260908 考试管理看板 ｜ 方案依据：[方案V2_重构版.md](方案V2_重构版.md)（同事反馈 + 7 项拍板，替代方案V1 全局看板设计） ｜ 页面 demo：[32_活动管理.html](<../../html/admin/32_活动管理.html>)、[33_活动详情.html](<../../html/admin/33_活动详情.html>) ｜ 相关需求：[爱测评考试自动创建 PRD](<../20260825 爱测评考试自动创建/爱测评考试自动创建 PRD.md>)、[渠道分组与报名活动卡片 PRD](<../20260826 渠道分组/渠道分组与报名活动卡片 PRD.md>)、[测评多考场 PRD](<../20260708 多考场/测评多考场_PRD.md>)（已废弃）

术语口径（本需求统一名词）：**活动** = 一个时间段内的一组考试，纯组织主体（名称 + 起止时间 + 挂考试）；**考试** = 一场考试（起止时间、试卷、监考、模拟考等全配置），一场考试对应一场爱测评考试，即现线上「测评活动」实体更名不改实体；**考试分组** = 考试的聚簇，服务报名页展示，本期仍挂在渠道下（沿用现状）；**渠道** = 合作商户 / 第三方开发者（渠道码、API 对接）；**一行** = 一个考试在一个渠道一个分组下的关联配置。

---

## 1. 背景与收益

在 admin 端新增「活动」组织主体与两个管理页面，把「一次活动」建成明确主体：活动下列出全部考试 × 渠道关联配置矩阵，支持勾选批量修改与批量创建考试（线上表单）。
业务诉求：现有「测评活动」实质是一场考试，「一次活动」的聚簇职责由渠道下的分组临时承担，运营对活动、考试、渠道三个模型认知混乱；一场考级常含多场考试（多级别 / 多场次，除开始时间与名称外配置相同），逐条创建效率低；线上部分字段创建后不易修改，批量调整缺入口。
收益：一次活动的考试场数、参与渠道、报名量、爱测评创建状态一页可见；同构多场考试由「公共配置 + 差异行」一次建成；批量修改覆盖单条可改的全部字段。

## 2. 业务流程

1. **建活动**：运营在活动管理页新建活动（名称 + 起止时间段），活动是组织主体，创建后进入活动详情配置考试。
2. **批量创建考试**：活动详情内打开批量创建表单——填公共配置（试卷 / 时长 / 交卷限制 / 标签 / 监考 / 模拟考）→ 逐行填考试差异项（名称、起止时间）→ 勾选渠道并勾选该渠道分组（可多选）、填渠道统一报名费 → 实时校验通过后提交，系统创建考试并自动创建爱测评考试，同时生成「每场考试 × 所选渠道 × 所选分组」的关联行。
3. **日常调整**：活动详情的考试 × 渠道矩阵中筛选、勾选行，批量修改弹窗统一设置字段（留空保持原值），触发爱测评联动的字段按既有规则同步。
4. **结果闭环**：批量创建与批量修改均走异步任务，消息中心通知执行结果并提供成功 / 失败明细（Excel）下载；矩阵支持导出当前结果。

## 3. 详细功能说明

### 3.1 活动管理页（admin 新页面）

**位置**：admin 端侧边栏教务中心分组「活动管理」（demo 编号 32）。

- **统计卡**：活动总数（含筹备中）、进行中活动、考试总场次（全平台累计）、参与渠道数（有考试关联的渠道）、总报名量（全活动累计）。
- **筛选**：关键词（活动名称 / 活动ID）、活动状态（未开始 / 进行中 / 已结束，按活动时间段判定）。
- **活动列表**（一行 = 一个活动）：活动名称 + 活动ID、活动时间段、考试场数、参与渠道数、报名量、活动状态、考试状态概览（已创建 / 创建中 / 未关联 / 创建失败的分项计数标签）、操作「进入详情」。考试场数、参与渠道数、报名量支持列头排序。
- **新建活动弹窗**：活动名称、开始日期、结束日期；校验必填、结束不早于开始；创建后提示进入详情配置考试。
- 活动暂不做编辑与删除的批量操作；活动名称 / 时间段的单条维护随详情迭代补充。

### 3.2 活动详情页（admin 新页面）

**位置**：活动管理 → 进入详情（携带活动ID），demo 编号 33。

- **头部**：返回活动管理、活动名称 + 活动ID、时间段与活动状态；右上角「导出当前结果」「批量创建考试」。
- **统计卡**：考试场次（关联行数）、已创建、创建中 / 未关联、参与渠道、报名量（本活动累计）。
- **筛选**：渠道（全部 + 各渠道）、分组（联动渠道，仅列该渠道分组含默认）、爱测评创建状态（已创建 / 创建中 / 未关联 / 创建失败）、考试进度（未开考 / 进行中 / 已结束）、重置。
- **考试 × 渠道矩阵**（一行 = 渠道 × 考试，同一考试挂多分组为多行）：渠道（名称 + 渠道号）、分组（默认以系统分组样式展示）、考试（名称 + 考试ID + 标签彩色小标）、关联试卷（未关联显示占位）、考试时间（同日合并显示 + 进度标签）、时长、交卷限制、报名费（可排序）、前端展示时间（含「永久有效」展示）、展示开关、监考配置摘要（摄像头 / 录屏 / 检录照片档位、手机监考、开关差异、候考时长）、模拟考（未开启；或「已开启 · 模拟卷 · 次数 · 交卷≤N分」+ 监考口径「同正式考 / 自定义」）、爱测评状态（四态，失败行展示原因）、报名量（可排序）、操作。
- **行操作**：创建失败行「重试」、未关联行「补关联」（选试卷保存后自动创建）、未开考行「复制考试」、全部行「详情」抽屉（分组查看全部字段：渠道关联 / 考试要素 / 监考配置 / 模拟考含模拟考监考，锁定字段带锁标识）。
- **行级复制考试**：以该行考试的全部配置为基础（时长、交卷限制、标签、描述、证书落款、监考配置、模拟考配置、渠道关联[渠道 + 分组 + 报名费]、展示时间与开关）批量生成 N 条新考试。交互：行内「复制考试」→ 弹窗输入复制条数（1–50）→「生成副本行」（名称自动加「·第X场」后缀，时间可选自动顺延，间隔 30 分钟）→ 逐条修改名称 / 起止时间 / 试卷（默认「同原考试」，可换）→ 确定后自动创建考试并继承渠道关联，同步自动创建爱测评考试（无试卷行存「未关联」）。校验：名称必填、起止时间合法、副本名称不重复。
- 不做行内单元格编辑；单条深度配置仍走现有编辑入口（新建测评活动弹窗、渠道管理关联活动弹窗）。
- 数据量为一个活动内的考试数 × 渠道关联数，整表平铺。

### 3.3 批量修改弹窗

**入口**：矩阵勾选一行或多行 → 「批量修改」按钮（未勾选置灰）。大尺寸弹窗（约 1080px 宽），全部字段分五个分区内联铺开，不出子弹窗：

| 分区 | 字段 |
|------|------|
| 渠道关联 | 所属分组、报名费（元）、展示开始日期、展示结束日期 +「永久有效」勾选（勾选后日期输入禁用）、前端展示开关 |
| 活动基础（考试要素） | 考试名称、关联试卷、考试开始 / 结束时间、时长、交卷限制、标签（逗号分隔覆盖式）、测评描述、证书落款时间（用户初次查看时间 / 指定日期联动输入） |
| 正式考监考配置 | 摄像头监考、录屏监考、检录照片（各三档：强制开启 / 非强制开启 / 不开启）、候考时长（0–120 分钟，0=不开启）、手机监考、成绩 / 分数 / 读题开关、检录视频引导文案（文本）、检录视频示意图（不修改 / 恢复系统默认；上传新图走单条编辑） |
| 模拟考配置 | 开启模拟考、模拟卷、模拟考开始 / 结束时间、次数限制、模拟考交卷时间限制（分钟，空 = 不限） |
| 模拟考监考配置 | 口径切换（跟随正式考 / 自定义）+ 自定义字段（摄像头 / 录屏 / 检录照片三档、候考时长、手机监考、成绩 / 分数 / 读题开关）。模拟考监考允许与正式考不同，未自定义时跟随各行正式考配置 |

**填写语义**：留空 /「不修改」/ 保持弹窗默认值的字段一律不下发，仅下发明确改动的字段；底部实时摘要「将修改：××、××」只列实际改动项。

**锁定规则（前置条件校验）**：

| 前置状态 | 锁定字段 | 说明 |
|---------|---------|------|
| 考试已开始或已结束 | 名称、起止时间、时长、交卷限制、试卷、标签、描述、证书落款、监考配置、模拟考配置（含模拟考监考、模拟考交卷限制） | 考试要素整体锁定 |
| 已有报名（考试未开始） | 考试起止时间 | 线上既有规则 |
| 渠道关联字段（分组、报名费、展示时间、展示开关） | 不锁定 | 任何状态可改 |

所选行中存在锁定某字段的行时，弹窗内该字段置灰带锁标识，应用时对应行跳过该字段；结果轻提示「N 行已应用，M 行因锁定字段被跳过」。可改范围 = 单条配置能改的字段均可批量修改。

### 3.4 批量创建考试（线上表单）

**入口**：活动详情「批量创建考试」按钮，三段式表单弹窗：

1. **公共配置**（全部考试共享，填一次）：关联试卷（必填）、时长（必填）、交卷限制（必填）、标签（逗号分隔）、摄像头监考 / 录屏监考 / 检录照片（三档）、候考时长、手机监考 / 成绩 / 分数 / 读题开关、开启模拟考（开启后模拟卷必填，可选模拟考交卷时间限制）。
2. **考试行差异区**：每行 = 考试名称（必填）+ 开始时间（必填）+ 结束时间（必填）+ 试卷（默认「同公共配置」，可在行内单独指定——单独指定的行不受公共试卷约束）；支持添加行、删除行（至少保留一行）、复制行（复制该行名称与时间生成相邻行，便于改场次）。基于已存在考试的批量复制走 3.2 行级「复制考试」——2026-09-08 用户决策：表单内「复制考场」入口移除，统一由行级复制承接。
3. **渠道关联**：渠道列表逐行勾选（可多选）；勾选后该渠道的分组以胶囊多选呈现（含「默认」，可多选）；每渠道填统一报名费（必填）。创建后每场考试关联到所选渠道的所选分组——同一渠道勾选多个分组即生成多行关联。

**实时校验**（提交时集中展示错误清单，不通过则不创建）：
- 公共配置：试卷必填（若每行考试均已单独指定试卷，公共试卷可留空）；时长 / 交卷限制必填；时长不小于交卷限制；开启模拟考时模拟卷必填。
- 考试行：名称、起止时间必填；结束时间晚于开始时间。
- 渠道关联：至少勾选一个渠道；每个勾选渠道至少勾选一个分组；报名费必填。

**执行**：创建考试并自动创建爱测评考试（失败行存「未关联」可补建，不回滚整批，与单条创建口径一致）；生成关联行（含分组归属、渠道统一报名费）进入矩阵；异步执行，结果见消息中心。

### 3.5 异步任务与导出

- 批量创建、批量修改走异步任务：提交即时返回，页面刷新当前数据；消息中心通知结果并附成功 / 失败明细（Excel）下载。
- 活动详情支持「导出当前结果」：按当前筛选导出全字段 Excel（含活动信息、渠道、分组、考试要素、监考、模拟考、状态、报名量）。
- 原 Excel 批量导入链路（模板下载 / 上传 / 校验预览）整体废弃，不在本期范围。

### 3.7 范围与边界
