# 活动管理与考试批量配置 — 方案概要（V2，重构版）

> 日期：2026-09-08 ｜ 依据：同事反馈（微信群「爱测评需求组」两屏讨论，LXM/刘玮_未来基因 参与）+ 用户 7 项拍板 ｜ 替代：方案V1（考试管理看板全局大表 + Excel 导入）

## 1. 反馈要点与重构决策

| 反馈要点 | 出处 | 决策 |
|---------|------|------|
| 「核心是要有一个主体，建立一次活动的概念」——活动=一个固定时间段的一组测试 | LXM | 新增「活动」组织主体（纯组织层，不改考试模型） |
| 名词统一：活动=时间段内一组考试；考试=考试；考试分组=考试分组 | 用户 | 采纳为新模型名词表 |
| 「实际业务的批量需求是针对某一个活动，多个分组下的多个考试修改」——全局大表打偏 | LXM | 渠道×考试矩阵收进活动详情；全局总览由活动列表承接 |
| 「批量考场：一个级别 6 个考场除开始时间名称外都一样」 | 刘玮 | 批量创建表单：公共配置+考试行差异区 |
| 「这种导入没法校验，还得频繁尝试」 | 刘玮 | Excel 导入链路全部移除，改线上表单（实时校验） |
| 分组维持渠道下（活动分组确定+渠道可见范围差异化为 LXM 理想态，优先级不高） | 用户拍板 A | 本期分组仍挂渠道，零侵入 |
| 批量创建表单带关联步骤（一步到位选渠道+分组+报名费） | 用户拍板 B | 三段式表单第三段即渠道关联 |
| 渠道统一价 + 差异价建完到矩阵单点改 | 用户拍板 | 渠道级统一报名费 |
| 逐渠道勾选要关联的考试 | 用户拍板（修订） | 后改为「勾选渠道→勾选该渠道分组（可多选）」，所选每场考试关联到所选渠道×所选分组（用户追加要求：分组支持批量选择） |
| 原看板 demo 重构替换；Excel 仅保留导出 | 用户拍板 | 32→活动管理，33→活动详情 |

## 2. 新模型名词表

| 名词 | 定义 | 与现状关系 |
|------|------|-----------|
| 活动 | 一个时间段内的一组考试（名称+起止时间+挂考试），纯组织主体 | 新增 |
| 考试 | 一场考试（全配置），对应一场爱测评考试 | = 现「测评活动」改名不改实体 |
| 考试分组 | 考试聚簇，服务前端展示 | 沿用现分组（仍挂渠道下） |
| 渠道 | 商户/第三方开发者（渠道码/API） | 不变；考试↔渠道关联方式沿用 |

与多考场方案（20260708，已废弃）区别：多考场在考试实体内嵌套子场次改考试模型；本方案活动为纯组织层，考试模型零改动，对现有系统侵入小。

## 3. 页面结构

- **32_活动管理**：统计卡（活动总数/进行中/考试总场次/参与渠道数/总报名量）+ 筛选（关键词/活动状态）+ 活动列表（时间段/考试场数/参与渠道数/报名量/活动状态/考试状态概览/进入详情，三项可排序）+ 新建活动弹窗。
- **33_活动详情**（URL 带活动ID）：头部（返回/活动名/时间段/状态）+ 统计卡（场次/已创建/创建中未关联/参与渠道/报名量）+ 筛选（渠道/分组联动/爱测评状态/考试进度）+ 考试×渠道矩阵（16 列，一行=渠道×考试×分组）+ 勾选批量修改（五分区弹窗全字段，继承 V1 全部修正：锁定规则/模拟考监考独立/永久有效/证书落款/引导文案示意图/模拟考交卷限制）+ 批量创建考试 + 导出当前结果。

## 4. 批量创建考试（线上表单，三段式）

1. **公共配置**（填一次）：试卷*/时长*/交卷限制*/标签/监考（摄像头/录屏/检录照片/候考/手机监考/成绩/分数/读题）/模拟考（开关→模拟卷*+模拟考交卷限制）。
2. **考试行差异区**：每行=考试名称*+开始时间*+结束时间*；支持添加/删除/复制行。
3. **渠道关联**：勾选渠道（多选）→ 每渠道勾选分组（**可多选**，含默认）→ 填渠道统一报名费*；创建后每场考试×所选渠道×所选分组生成关联行。
- 实时校验：公共必填/时长≥交卷限制/考试行必填/结束晚于开始/渠道至少一个/每渠道至少一个分组/报名费必填——错误集中展示。
- 执行：创建考试（自动创建爱测评考试，失败行存「未关联」可补建）+ 渠道关联行入库进矩阵。

## 5. 废弃项

- Excel 批量导入（新建+修改合一的三步弹窗）——整体移除。
- 全局渠道×考试大表（原 32 看板主视图）——由活动列表统计卡 + 活动详情矩阵替代。
- 仅保留「导出当前结果」Excel 导出。
