# 手机监考 — 方案概要

## 1. 背景与问题

AISE 考试系统支持视频监考。考生进入考试前需通过「设备调试」页面（21_测评_设备调试.html）完成摄像头、麦克风、屏幕共享三项检测，全部通过后才能进入考试。

**核心问题：** 部分考生电脑没有摄像头（如台式机未配外接摄像头），摄像头检测无法通过，整个流程卡死，考生无法进入考试。

**解决思路：** 提供手机作为备选摄像头方案——考生用手机扫码后在手机上开启视频推流，替代电脑摄像头完成监考。

---

## 2. 用户流程

```
考生进入设备调试页
  ├── 电脑有摄像头 → 正常检测流程（原有）
  └── 所有考生均可见「手机监考」备选入口
        ├── 扫码 → 手机打开引导页
        │     ├── 查看两张引导图（手机摆放位置示意）
        │     └── 点击「确认」→ 进入直播页
        └── 直播页
              ├── 查看摄像头实时画面
              ├── 翻转摄像头（前置/后置切换）
              ├── 查看网络连接状态
              └── 电脑端设备调试页同步感知手机连接状态
```

## 4. 页面设计

### 4.1 设备调试页改造（21_测评_设备调试.html）

**改造位置：** 右侧面板（原白色区域），在「摄像头」检测卡片下方新增「手机监考」模块。

**「手机监考」模块内容：**

- **标题：** 「手机监考」
- **说明文案：** 一行灰色小字：「电脑没有摄像头？用手机扫码开启视频监考」
- **二维码：** 居中的二维码图案，与当前考生一一对应（含唯一 token）
  - 二维码状态：正常（显示二维码）、已连接（显示绿色对勾 + 「手机已连接」）、已过期（置灰 + 刷新按钮）
  - 刷新逻辑：每 60 秒自动刷新，也可手动点击刷新
- **辅助文案（二维码下方）：** 小字灰色：「请使用手机浏览器扫码」

**与摄像头检测的关系：**
- 手机监考作为独立备选入口，与电脑摄像头检测平级
- 电脑摄像头通过 或 手机连接成功，均视为「摄像头检测通过」
- 两者都可通过时，以电脑摄像头为准（手机作为备份不强制要求）

**布局方案（与现有页面风格一致）：**

右侧面板目前结构：
```
设备检测（标题）
├── 摄像头卡片（绿色已通过 / 灰色未检测）
├── 麦克风卡片
├── 屏幕共享卡片
├── 网络连接卡片
└── [新增] 手机监考卡片
      ├── 标题：「手机监考」
      ├── 说明：「电脑没有摄像头？用手机扫码开启视频监考」
      ├── 二维码（居中，约 160×160px）
      └── 「请使用手机浏览器扫码」
```

**页面结构（自上而下）：**

1. **顶部标题：** 「手机监考 — 设备摆放指引」
2. **引导图区域：** 两张图上下排列，每张图配一行说明文字
   - 图一：（待用户提供）—— 预计为俯视示意图，展示手机与电脑、考生的位置关系
     - 文字参考：「将手机立在考生座位左前方或右前方，保持考生和电脑屏幕在同一画面里」

**布局说明：**

- 引导图为占位图，用户稍后提供实际图片替换

### 4.3 手机直播页（31_手机监考_直播页.html）

**定位：** 用户点击引导页「确认」后进入，是手机端视频推流的主页面。

**页面结构：**

1. **摄像头预览区（主体）：** 占据页面大部分面积，实时显示摄像头画面
   - 使用手机浏览器 `getUserMedia` API 获取后置/前置摄像头流
   - 画面填充预览区，保持视频比例
   - 预览区顶部左侧半透明状态条：「监考中 · 请勿关闭此页面」

2. **控制栏（预览区下方）：**
   - **翻转摄像头按钮：** 居左，切换前置/后置摄像头
   - **网络状态指示：** 居右，显示当前网络连接状态
     - 在线：绿色圆点 + 「连接正常」
     - 不稳定：黄色圆点 + 「网络波动」
     - 断开：红色圆点 + 「已断开，请检查网络」

3. **推流状态（预览区上方或控制栏旁）：**
   - 小型指示灯 + 文字：「推流中」
   - 异常时显示：「推流中断，正在重连...」

**技术约束（产品层面）：**
- 页面需保持前台运行，切后台或锁屏可能导致推流中断
- 手机需授予摄像头权限
- 使用手机数据网络或 WiFi 均可

---

## 5. 二维码与考生绑定逻辑

- 考生进入设备调试页时，服务端生成唯一 token，关联当前考生 ID + 考试场次
- token 编码进二维码 URL：`https://aise.xxx.com/proctor/mobile?token=xxx`
- 手机扫码打开页面 → 服务端根据 token 识别考生身份 → 绑定手机端推流会话
- token 有效期与考试场次时间一致，考试结束后失效
- 同一考生同一时间只能有一个手机推流连接，新连接踢掉旧连接

---

## 6. 与现有监考体系的关系

- 手机推流与电脑摄像头推流使用同一套监考端展示能力（监考页面已有的「查看摄像头」功能）
- 监考端不需要区分视频流来自电脑还是手机——对监考官透明
- 已有的「实时监考中」标识和录屏功能不受影响
