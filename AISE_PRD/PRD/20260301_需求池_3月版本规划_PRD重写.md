## 🔷 1. 项目背景与收益预估

### 1.1 需求简介

对爱测评后台及学生端进行集中功能增强，覆盖题目管理改版、试卷编辑体验优化、AIGC 题型次数管控、TTS 读题能力建设、交卷时间限制配置、实践题附件大小限制共 9 项功能。

### 1.2 业务诉求

- 题目管理页面原列表每屏仅展示 3-4 道题，浏览效率低
- 试题篮功能不完善：仅支持单篮，无法同时为多套试卷选题
- 教师在组卷时若需引用他人题目并微调，操作路径繁琐
- 实践题缺乏多维度评分量表（Rubric），阅卷依据不结构化
- AIGC 题型无次数限制，算力成本不可控
- 低龄/特殊考生阅读复杂题干有困难，缺乏听觉辅助
- 实践题附件上传无统一大小限制，存在超大文件风险

### 1.3 收益预估

- **用户收益**：
  - 教师浏览题目效率从每屏 3-4 题提升至 10-30 题（提升约 5-8 倍）
  - 多试题篮机制减少反复加入/移出操作，同时组多套试卷效率提升 60%
  - 引用他人题目并微调的操作路径从"手动复制→返回题库→替换"的 4 步缩减至"复制且修改"1 步
  - 低龄/特殊考生可通过 TTS 读题降低题干理解障碍
- **业务收益**：
  - AIGC 次数限制预计降低 30-50% 的无效生成调用，直接控制算力成本
  - 实践题评分量表（Rubric）结构化后，阅卷一致性提升，评分争议减少
  - 附件 150MB 统一上限降低存储成本和上传失败率
- **不做风险**：题目管理效率瓶颈导致教师弃用；AIGC 成本无管控可能导致单月 API 费用超预算。

## 🔷 2. 业务流程简述

教师通过爱测评后台进行题目管理、试卷编辑、测评活动配置；学生在答题页完成考试。本次规划覆盖教师端 6 个功能（题目管理改版、题目详情增强、实践题赋分、交卷时间限制、AIGC 次数配置、TTS 读题配置）和学生端 3 个功能（AIGC 次数提示、TTS 播放、附件大小限制）。

## 🔸 5. 详细功能说明

### 5.1 功能一：题目管理页面改版

- **位置**：爱测评后台 → 测评管理 → 题目管理
- **目标**：将卡片式题目列表替换为高密度紧凑型列表，同步升级试题篮为多篮管理

**5.1.1 整体布局**
- 顶部导航栏：含品牌标识、导航项（首页/测评管理/测评报告）、用户头像入口
- 侧边栏：宽度 220px，含题目管理/试卷库/考试任务，当前页高亮"题目管理"
- 内容区：上方筛选器 + 下方题目列表

**5.1.2 筛选查询区**
- 题干关键词：文本输入框，占位符"请输入..."，最多 100 字符，支持回车或点击"查询"触发
- 所属题库：下拉选择框，默认"全部"，动态加载有权限的题库列表
- 题型：下拉选择框，默认"全部"，固定选项：单选题/多选题/判断题/编程题/简答题
- 标签：文本输入框，占位符"如：高频、必考"，模糊匹配
- 难度：下拉选择框，默认"全部"，固定选项：简单/中等/困难
- 操作按钮："查询"（主按钮）、"重置"（次级按钮，清空所有筛选条件并重新加载）

**5.1.3 题目列表（紧凑型表格）**
- 工具栏：左侧"共找到 {N} 道试题"，右侧"+ 新增试题"按钮
- 列表为空：显示空状态插画 + "暂无符合条件的题目"
- 表头字段：题目 ID（70px）、题型（70px）、题干（弹性宽度，单行截断）、知识点（130px，胶囊样式）、标签（120px，胶囊样式）、可见范围（80px）、出题人（80px）、操作（180px）
- 横向溢出：列表设置最小宽度 1060px，出现水平滚动条
- 分页：底部右侧展示当前页码、总条数、翻页按钮

**5.1.4 题干预览气泡**
- 触发：点击题干文字或行尾眼睛图标（图标仅在行悬停时显示）
- 内容：完整富文本（支持图片、代码块、列表），气泡最大宽度 450px，最大高度 350px，超出滚动
- 定位：默认在题干下方展示；下方空间不足时翻转到上方
- 关闭：点击同一行眼睛图标切换关闭 / 点击气泡外区域 / 内容区滚动时自动关闭

**5.1.5 行内操作按钮**
- 按钮根据登录用户与出题人的关系动态展示：

| 条件 | 操作按钮 |
|------|---------|
| 题目尚未加入当前试题篮 | 选题（蓝色链接） |
| 题目已在当前试题篮中 | 移出（红色链接） |
| 出题人是当前用户 | 编辑 + 详情 |
| 出题人非当前用户 | 复制且编辑 + 详情 |

- 选题：将该题加入当前激活的试题篮，按钮变红色"移出"
- 移出：从当前试题篮移除，按钮恢复蓝色"选题"
- 编辑：跳转题目编辑页
- 复制且编辑：系统复制一道归属当前用户的新题，跳转新题编辑页，原题不变
- 详情：跳转题目只读详情页

**5.1.6 试题篮悬浮面板**
- 位置：页面右下角固定悬浮，圆形主色按钮 + 红色角标显示题目数量
- 展开面板头部：标题"试题篮" + 右侧"清空"
- 汇总区："已选 {N} 道题目" + 各题型数量胶囊标签
- 题目列表：最大高度 240px，超出滚动；每条显示题型、截断题干、删除按钮
- 底部："查看已选题目"（次级按钮）、"生成试卷"（主按钮）
- 空态："已选 0 道题目"，列表区居中文案"试题篮为空，请从列表中选题"
- 关闭：点击面板外区域自动收起
- 防遮挡：内容区底部预留 120px 内边距

**5.1.7 试题篮详情弹窗（多篮管理）**
- 展示：模态框覆盖层（半透明遮罩），点击遮罩关闭；弹窗宽度 720px，最大高度 80vh
- Tab 标签页：每篮一个 Tab，文案"{篮名}（{已选数量}）"，当前 Tab 底部高亮；行末"+ 新增试题篮"按钮
- 新增试题篮：弹出输入框输入篮名，确认后创建并自动切换
- 题目列表表格：序号（自增）、题干（单行截断）、题型（80px）、操作（删除图标）
- 底部栏：左侧"已选 {N} 道题目"，右侧"生成试卷"
- 空态："当前试题篮为空，请返回列表添加题目"
- 切换 Tab 后外层列表的"选题/移出"状态联动刷新

**5.1.8 加载态**
- 筛选加载：点击"查询"后列表区域显示骨架表格（6 行浅灰占位条）
- 试题篮面板展开时，题目列表加载中显示 3 条缩略占位条
- 试题篮详情弹窗打开时，表格区域显示加载旋转图标

**5.1.9 错误态**
- 题目列表接口失败：表格区域显示"加载失败"，提供"重试"按钮
- 试题篮数据接口失败："选题"按钮点击后若加入失败，轻提示"操作失败，请重试"
- 新增试题篮接口失败：轻提示"创建失败，请重试"

**5.1.10 边界数值**
- 题干关键词上限：100 字符
- 侧边栏宽度：220px
- 列表最小宽度：1060px
- 题干预览气泡：最大宽 450px / 高 350px
- 悬浮面板题目列表最大高度：240px
- 内容区底部防遮挡内边距：120px
- 弹窗宽度：720px；最大高度：80vh

### 5.2 功能二：试卷编辑页题目详情增强

- **位置**：试卷编辑页 → 题目列表 → 点击"题目详情"
- **目标**：根据出题人权限动态提供"修改题目"或"复制且修改"入口，减少引用他人题目时的操作路径

**5.2.1 入口展示**
- 题目列表每道题行末操作链接："题目详情" + "移除"
- 点击"题目详情"唤起详情弹窗

**5.2.2 题目详情弹窗**
- 展现：模态框，居中 + 遮罩层
- 内容区（只读）：题干富文本、选项（正确项高亮）、题型/难度/分值/知识点/解析
- 底部操作栏：
  - 始终展示"关闭"按钮
  - `当前题目.author == 当前登录用户` → 展示蓝色主按钮"修改题目"
  - `当前题目.author != 当前登录用户` → 展示橙色主按钮"复制且修改"

**5.2.3 "修改题目"流程**
1. 点击"修改题目"
2. 弹窗关闭，显示轻提示"正在打开题目的编辑页面..."
3. 新页签打开该题目的标准编辑页，保留原试卷编辑页状态
4. 编辑保存后，原试卷视图通过接口刷新同步最新内容

**5.2.4 "复制且修改"流程**
1. 点击"复制且修改" → 按钮显示加载动画，禁止重复点击
2. 后台原子操作：深拷贝题目数据 → 新题 author 设为当前用户 → 生成新 ID
3. 弹窗关闭，试卷列表中该题被静默替换为新题（ID 和出题人变更）
4. 轻提示"已复制该题并一键替换试卷内容，正在打开编辑页面..."
5. 新页签打开新题的编辑页

**5.2.5 错误态与异常处理**
- 试卷被他人锁定编辑时：点击按钮后前置阻断，弹窗提示"当前试卷正由其他教师编辑，无法执行题目替换或修改操作"
- 复制过程中网络中断：停止加载动画，停留在当前弹窗，弹窗提示"复制题目失败，请检查网络"，不执行替换和跳转
- 编辑保存失败：编辑页内提示，不影响原试卷数据

**5.2.6 边界数值**
- 复制操作超时阈值：[待定，建议 10s]

### 5.3 功能三：试卷编辑页实践题赋分增强

- **位置**：试卷编辑页 → 点击某题"赋分" → 赋分弹窗
- **目标**：为实践题提供多维度评分量表（Rubric）配置，各维度分值加和精确等于题目总分

**5.3.1 赋分弹窗 - 数据统计区（只读）**
- 采用网格布局展示 6 项参考数据：
  - 建议分值（题库默认分值）、当前分值、当前本题型总分
  - 修改后本题型总分 = 当前本题型总分 + (新分值 - 当前分值)，主题色高亮
  - 当前试卷总分
  - 修改后试卷总分 = 当前试卷总分 + (新分值 - 当前分值)，主题色高亮

**5.3.2 基础分值设定**
- 输入框：数字类型，标签"设定分值"，必须 > 0
- 输入 0、负数或清空时输入框标红，"确定"按钮置灰禁用

**5.3.3 实践题打分维度配置**（仅实践题可见）
- 标题："打分维度配置"
- 帮扶提示："各维度分值之和必须等于设定的本题分值"
- 维度列表：每行含维度名称输入框（必填）+ 分值输入框（必填，≥ 0）+ 删除按钮（列表仅剩 1 行时禁用）
- "+ 添加维度"按钮在列表头部右侧
- 底部汇总条：
  - 左侧动态文案"当前各维度总和：{Sum} 分"
  - 右侧"目标：{Target} 分"
  - Sum == Target → 黑色正常；Sum ≠ Target → 红色警示

**5.3.4 强校验与阻断**
- 点击"确定"时依次校验：
  1. 设定总分 > 0
  2. 所有维度名称非空，否则提示"请填写完整所有维度的名称"
  3. Sum == Target，否则提示"各维度分值加和不等于设定的总分值"
- 任一校验失败，"确定"按钮禁用

**5.3.5 错误态**
- 保存接口失败：弹窗不关闭，底部显示红色提示"保存失败：{错误原因}"

**5.3.6 边界数值**
- 分值必须 > 0，维度分值必须 ≥ 0
- 维度最少 1 个

### 5.4 功能四：测评活动交卷时间限制配置

- **位置**：测评活动管理 → 新建/编辑测评活动表单 → 紧邻"测评时长"字段
- **目标**：配置开考后禁止提前交卷的时间窗口，规范考场纪律

**5.4.1 界面元素**
- 字段名称："交卷时间限制（分钟）"，必填标识
- 组件类型：数字输入框，默认值 15
- 占位提示："输入限制交卷的分钟数"

**5.4.2 基础校验**
- 必须为正整数或 0
- 输入 0 表示不限制，考生随时可交卷
- 输入小数或负数时，前端向下取整或清空为 0

**5.4.3 逻辑关联校验（核心约束）**
- 约束条件：`交卷时间限制 ≤ 测评总时长`
- 打破约束时：输入框边框变红 + 底部显示红色提示"不能超过测评总时长" + "保存"按钮置灰禁用
- 符合约束时：清除红色警报，恢复按钮交互

**5.4.4 错误态**
- 保存接口失败：轻提示"保存失败，请重试"

**5.4.5 边界数值**
- 最小值：0
- 最大值：等于测评总时长
- 默认值：15 分钟

### 5.5 功能五：试卷编辑列表 - AIGC 题型答题次数限制

- **位置**：试卷编辑页 → 题目列表 → 鼠标悬停特定题型（文生文/文生图/文生视频）时
- **目标**：为 AIGC 题型配置考生最大生成次数，控制算力成本

**5.5.1 触发入口**
- 鼠标悬停题目卡片时，底部展示快捷操作工具栏：上方添加分组/设置分值/题目详情/更换题目/删除/上移/下移
- 当题目 type 属于 [文生文, 文生图, 文生视频] 时，在工具栏中插入【设置次数】按钮（蓝色/紫色强调色图标）
- 已配置次数限制时，题目信息区展示徽标"限制 {N} 次生成"

**5.5.2 设置答题次数弹窗**
- 展现：居中模态框 + 遮罩，点击遮罩或 X 关闭
- 标题："设置答题次数"
- 说明文案："针对 AIGC 题型可限制考生调用额度，超过限制后无法再生成并只能以此结果交卷"
- 输入组件："允许最大生成次数"数字输入框

**5.5.3 数据保存规则**
- 输入正整数：保存成功，题目信息区新增/更新"{N} 次生成"徽标，持久化 attemptsLimit
- 输入为空或清除：视为取消限制，保存后隐藏徽标，恢复不限次
- 输入 ≤ 0 或负数：输入框边框变红，阻断保存

**5.5.4 错误态**
- 保存接口失败：轻提示"保存失败，请重试"

**5.5.5 边界数值**
- 最小值：1（正整数）
- 无明确上限（由教师端自行控制）

### 5.6 功能六：学生端答题页 - AIGC 剩余次数提示与控制

- **位置**：学生端答题页 → AIGC 题型（文生文/文生图/文生视频）→ 生成按钮旁
- **目标**：向学生展示剩余可用生成次数，耗尽后禁止继续生成

**5.6.1 剩余次数徽标**
- 位置：紧邻"让 AI 开始写作"按钮右侧
- 样式：橙色/黄色系胶囊徽标（背景 #fff3e0，边框 #ffcc80，文字 #e65100）
- 文案："剩余次数: {Remaining}/{Max}"（如"剩余次数: 3/3"）
- 无限制时隐藏徽标

**5.6.2 状态流转**
- 初始化：加载 attemptsLimit，若无限制则隐藏徽标；有限制则显示"剩余次数: {Max}/{Max}"
- 消耗：每次点击生成并成功发起请求后，Remaining - 1，徽标实时更新
- 耗尽（Remaining == 0）：
  - 生成按钮置灰禁用，文案变更为"次数已用尽"
  - 输入框锁定为 Disabled
  - 前端拦截超限点击，提示"生成次数已用尽！"，禁止额外请求

**5.6.3 错误态**
- attemptsLimit 接口加载失败：徽标不显示，生成按钮保持可用（降级策略：不阻塞学生作答）
- 生成接口失败（非次数原因）：按原有错误提示处理，不消耗次数

**5.6.4 边界数值**
- Remaining 最小值：0
- 消耗时机：生成请求成功发起后立即 -1（非等待生成结果返回后）

### 5.7 功能七：题目管理详情页 - 读题文本 (TTS) 配置

- **位置**：爱测评后台 → 题目管理 → 题目编辑表单 → 解析说明下方
- **目标**：命题教师为单题配置口语化读题文本，供学生端 TTS 朗读

**5.7.1 界面元素**
- 表单字段标签："读题文本配置 (TTS)"，右侧对齐"试听发音"按钮
- 输入组件：多行文本框（textarea），不支持富文本
- 占位符："请在此输入系统朗读的文案，如果不填则默认直接朗读原题干纯文本。如果题干中有图片或代码，建议填写针对听觉优化的转述文案。"
- 辅助说明："学生在考试端点击'播放读题'时，系统将通过语音合成引擎朗读上方配置的纯文本内容。"

**5.7.2 试听发音**
- 按钮："🎧 试听发音"
- 逻辑：点击后调用 TTS 引擎朗读当前文本框内容；若为空则提取题干纯文本朗读
- 试听中按钮变为"⏹ 停止试听"

**5.7.3 入库规则**
- 填写了 tts_text → 随题目一并保存入库
- 留空 → 字段存 NULL 或空字符串
- 考场端渲染时：存在 tts_text → 优先朗读该文本；不存在 → 前端剥离 HTML 标签后朗读纯文本题干

**5.7.4 错误态**
- 试听接口失败：轻提示"试听失败，请检查网络后重试"
- 保存接口失败：按题目编辑页通用错误处理

### 5.8 功能八：学生端答题页 - 读题文本 (TTS) 音频播放

- **位置**：学生端答题页 → 所有题型 → 题目题头区域
- **目标**：为题目提供"播放读题"入口，支持 TTS 听觉辅助

**5.8.1 按钮展示**
- 位置：紧跟题型与分值徽标之后（如"单选题 · 5分"后方）
- 样式：青蓝色微渐变圆角边框（背景 #e1f5fe，边框 #81d4fa），文案"播放读题"
- 悬停时有提亮过渡效果

**5.8.2 发音内容优先级**
1. 优先读取考卷下发的 tts_text（教师配置的读题文案）
2. 若 tts_text 为空，则抓取题干 HTML 剥离标签后的纯文本朗读

**5.8.3 播控逻辑**
- 点击"播放读题" → 按钮状态变为"⏸ 停止读题"，开始朗读
- 播放中点击 → 停止播放，按钮恢复初始态
- 点击另一题的播放按钮 → 先终止当前朗读，再开始新朗读（绝对禁止多音轨同时发声）

**5.8.4 错误态**
- TTS 引擎不可用（浏览器不支持 SpeechSynthesis）：按钮置灰，悬停提示"当前浏览器不支持语音播放"
- TTS 接口失败：轻提示"读题播放失败"

**5.8.5 边界数值**
- 朗读文本预处理：剔除 HTML 标签、特殊无声字符

### 5.9 功能九：学生端答题页 - 实践题上传附件大小限制 (150MB)

- **位置**：学生端答题页 → 实践题 → 附件上传区域
- **目标**：限定实践题单个附件最大 150MB，防止超大文件消耗服务器资源

**5.9.1 界面文案更新**
- 格式要求卡片底部："请将所有内容整合为一个文档（Word、PDF 或 PPT），文件大小不超过 150MB。"
- 上传拖拽区下方："支持格式：.docx, .pdf, .pptx, .zip (Max 150MB)"

**5.9.2 前端前置校验**
- 学生选取文件后，前端立即通过 file.size 校验
- 超限：弹窗警告"上传失败：文件大小不能超过 150MB！"，清空本次选取，禁止提交
- 通过：正常进入上传进度条流程

**5.9.3 错误态**
- 上传过程中网络中断：进度条停止，提示"上传中断，请检查网络后重试"
- 上传接口返回失败：提示具体失败原因，保留已选文件以便重试

**5.9.4 边界数值**
- 单文件大小上限：150MB（即 150 × 1024 × 1024 Bytes）
- 支持格式：.docx, .pdf, .pptx, .zip
