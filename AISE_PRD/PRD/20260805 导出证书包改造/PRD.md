## 一、需求背景与目标

### 1.1 一句话需求（用户原话）

> 后台的学生证书管理已经有导出数据的功能了，只是把表格数据导出，但是没有证书文件。把这个改成，导出一个压缩包，压缩包里面有原来的表格和表格中所有学生的证书 pdf 文件。

### 1.2 背景

| # | 背景事实 | 出处 |
|---|---------|------|
| 1 | 「16_学生证书管理」页面的「导出数据」目前是纯前端演示：点击后按钮转两秒、弹一句提示就结束，不产生任何真实文件 | [16_学生证书管理.html](<../../html/admin/16_学生证书管理.html>)（导出逻辑） |
| 2 | 平台内已有学生电子证书 PDF 资产：证书签发成功时保存证书编号、PDF 地址（签发中心可下载），但导出功能没有接通这些资产，只导表格、不带证书文件 | [20260512 证书签发流程 prd.md](<../20260512 5 月需求/20260512 证书签发流程 prd.md>) |
| 3 | 20260728 需求中已声明「证书导出」拆分为独立 PRD，但仓库里一直没有实体文档——本需求补齐该缺口 | [20260728 业务需求梳理.md](<../20260728 个人报告与题库建设/业务需求梳理.md>) |

### 1.3 目标

- 按当前筛选条件一键导出「证书包」：学生名单 Excel（筛选全量行）+ 已签发学生证书 PDF，打包为 zip
- 压缩包内附「缺证书说明」，说清楚哪些学生没有证书、为什么（可溯源）
- 异步链路真实打通：点击导出 → 生成中 → 消息中心下载 zip；失败可重试，文件到期自动清理

### 1.4 非目标（本期不做）

| 不做 | 说明 |
|------|------|
| 列表查询/重置逻辑改造 | 页面查询按钮现状为静态占位，不在本期范围 |
| 增量导出、定时导出、分卷压缩、压缩选项调优 | 后续迭代预留 |
| PDF 重生成 | 重签属签发链路职责 |
| 渠道/模块/级别多选交互改造 | 现状为单选下拉，多选不在本期范围 |

### 1.5 用户锁定决策（4 条，不得违反）

| # | 决策原文 | 落地要点 |
|---|---------|---------|
| 1 | 导出范围：按当前筛选条件全量导出（跨页） | 导出内容是当前筛选条件下的**全部**学生，不是仅当前页或勾选行；导出内容以点击导出那一刻的筛选条件为准 |
| 2 | PDF 只打包已签发的证书；Excel 保留筛选全量行；zip 附缺证书说明.txt | 名单 Excel 保留所有筛选结果行（含未签发），证书 PDF 只放「已签发」学生的，没有证书的行在「缺证书说明.txt」里逐条写清原因 |
| 3 | 按钮保持「导出数据」原名不改文案；走异步链路 | 按钮名、点击后提示文案都不改；导出的 zip 到消息中心「导出记录」里下载 |
| 4 | 无硬件依赖、无外部系统集成 | 证书 PDF 是平台内已生成的资产，纯后台功能改进 |

## 三、功能需求

### 3.1 导出证书包（服务端）

#### 3.1.1 导出范围与内容

| 项 | 规则 |
|----|------|
| 导出范围 | 按点击导出时的筛选条件，全量查询（跨页），不限制条数 |
| 导出内容 | zip 压缩包：①学生名单 Excel（筛选全量行）②已签发学生的证书 PDF ③缺证书说明.txt |
| 内容一致性 | 名单与 PDF 均来自同一次查询结果，保证 zip 内部自洽（导出期间新签发的证书不追加入包，需要最新可重新导出） |
| 数据快照 | 以点击导出那一刻的筛选条件为准，导出期间筛选条件变化不影响本次任务 |

#### 3.1.2 导出流程

```
点击「导出数据」
  → 校验存储空间（空间不足直接提示，不创建任务）
  → 创建导出任务（生成中），按筛选条件异步执行：
      1. 查询全部学生证书行
      2. 生成学生名单 Excel（全量行）
      3. 逐行收集「已签发」学生的证书 PDF（缺文件/未签发的行记入缺证书说明，继续处理其他行）
      4. 打包 zip
  → 任务完成 → 消息中心「导出记录」出现可下载的 zip
失败（名单生成失败/打包失败/存储写入失败/超时）
  → 任务标记失败，可重试
```

#### 3.1.3 压缩包内容

```
学生证书包_20260805_共5682人_3200份.zip
├── 学生证书列表.xlsx        （名单 Excel，全量行，必含）
├── 缺证书说明.txt           （说明文件，每次导出都会生成）
└── 证书PDF/
    └── 张小明_CERT202608050001.pdf   （已签发学生的证书，命名：姓名_证书编号）
```

| 项 | 规则 |
|----|------|
| 压缩包文件名 | `学生证书包_日期_共N人_M份.zip`（日期 + 总人数 + 证书份数，方便直接识别批次规模） |
| 证书 PDF 命名 | `姓名_证书编号.pdf`（证书编号系统唯一，同名学生也不会冲突）；姓名中的非法字符（/ \ : * ? " < > \|）替换为下划线 |
| 无证书时 | 一个证书都没有时不生成「证书PDF/」空文件夹 |
| 大文件 | 压缩包预计很大（几 GB 级）时，创建任务时提示预计大小和耗时，任务照常执行（不强制拦截） |

#### 3.1.4 名单 Excel 内容

| 列 | 说明 |
|----|------|
| 学生姓名 | |
| 手机号 / 身份证号 | 默认脱敏（138\*\*\*\*1234 形式）；导出明文需前端二次确认 |
| 渠道名称 / 渠道编号 | |
| 成绩 / 测评结果 | 优秀/良好/合格 |
| 证书状态（实体） | 全量行保留 |
| 电子证书 | 全量行保留（未签发也保留，状态一目了然） |
| 模块 / 级别 | |
| 证书编号 | 与 PDF 一一对应 |
| 证书PDF文件名 | 已打包的行填文件名，未打包的留空 |
| 未打包原因 | 仅未打包的行填原因 |

#### 3.1.5 缺证书说明.txt

每次导出都生成（三种情况）：
- **全部打包成功**：注明「全部 N 行证书均已打包，无缺失」
- **筛选结果为空**：注明「筛选条件下无数据」
- **有学生没证书**：逐行列明（序号/姓名/证书编号/电子证书状态/未打包原因）

缺证书原因：

| 原因 | 说明 |
|------|------|
| 电子证书未签发 | 证书还在 等待成绩/生成中/待签发 状态 |
| 电子证书签发失败 | 签发流程失败 |
| 电子证书未配置 | 该测评未接入证书签发/未配置模板 |
| 证书PDF文件缺失 | 状态已签发但存储里找不到文件（异常） |
| 证书PDF文件损坏 | 已签发但文件读取失败 |
| 证书编号缺失 | 已签发但证书编号为空（数据异常） |
| 其他 | 兜底 |

#### 3.1.6 导出任务状态与操作

| 状态 | 消息中心展示 | 可操作 |
|------|-------------|--------|
| 生成中 | 蓝色「生成中」 | 不可下载 |
| 生成成功 | 绿色「生成成功」 | 下载 zip |
| 生成失败 | 红色「生成失败」（显示失败原因） | 重试（同一任务最多重试 3 次，重试沿用原筛选条件） |
| 已过期 | 灰色「文件已过期」 | 不可下载（文件保留 7 天后过期清理） |

| 项 | 规则 |
|----|------|
| 下载权限 | 仅任务发起人或管理员可下载/重试，其他人访问返回无权限 |
| 下载体验 | 大文件支持断点续传；文件生成中/已过期/已删除时给出明确提示 |
| 保留期 | 导出文件保留 7 天（默认），到期后状态变「已过期」并清理文件 |
| 配额 | 导出文件计入存储占用；存储空间不足时提示联系管理员，不创建任务 |

#### 3.1.7 存储与性能（实现口径，待实测回填）

| 项 | 口径 |
|----|------|
| 数量级 | 页面演示量级 5,682 条（仅参考）；实际按数百~数千行设计 |
| 单证书 PDF 大小 | 未实测（P0 上线前实测项），暂按 1.25MB/份估算 |
| 存储预估 | 预计占用 = 已签发证书数 × 单证书大小（未签发的学生不产生 PDF，不计入） |
| 超时 | 任务超时按预估大小联动：预估小于 2GB 时 30 分钟，大于等于 2GB 时 60 分钟（参数化，实测后回填） |
| 大包处理 | 分批读取 PDF、流式写入压缩包，控制内存占用 |

### 3.2 16_学生证书管理页（前端）

| 改造点 | 规则 |
|--------|------|
| 按钮 | 「导出数据」按钮名、图标、点击后提示文案（「正在导出，请稍后在「消息中心」查看下载」）全部保持现状不改 |
| 点击导出 | 收集当前筛选条件（空条件=导出全部）→ 发起导出任务；按钮进入 loading 并禁用，防止重复点击 |
| 完成后提示 | 保持现状提示（在消息中心查看下载） |
| 大导出提示 | 筛选结果很大时，追加提示预计大小/耗时（信息性提示，不弹确认框、不拦截） |
| 空间不足 | 提示「存储配额不足，请联系管理员」 |
| 网络/其他错误 | 提示「网络异常，请稍后重试」等，按钮恢复 |
| 重复导出 | 同一筛选条件短时间内可重复导出（允许创建多个任务） |

### 3.3 19_消息中心（前端）

| 改造点 | 规则 |
|--------|------|
| 数据源 | 「导出记录」表格从写死数据改为读取导出任务列表（进入页面即加载） |
| 状态展示 | 四种状态 + 未知状态兜底：生成中（蓝）/ 生成成功（绿）/ 生成失败（红，新增样式）/ 已过期（灰）/ 未知（灰） |
| 任务内容列 | 主标题「导出学生证书包」+ 副标题显示本次筛选条件摘要（如「姓名=张；电子证书状态=已签发」，无筛选条件时显示「全量导出」） |
| 文件名列 | 成功：文件名 + 大小 + 「N 行 / M 份 / 缺 K」（缺 K 橙色突出）；失败：红色失败原因；生成中：「计算中...」 |
| 下载 | 仅「生成成功」可下载；下载中按钮短暂禁用防连点 |
| 重试 | 仅「生成失败」可重试；重试后任务回到生成中重新执行；已达 3 次上限时按钮禁用并提示 |
| 搜索 | 新增搜索框（按文件名/任务类型搜索），输入防抖后刷新列表 |
| 加载更多 | 「加载更多」按钮追加下一页；没有更多时置灰/隐藏 |
| 自动刷新 | 列表存在「生成中」任务时自动定时刷新（几秒一次），全部完成后停止；切走/切回页面自动暂停/恢复 |
| 存储占用 | 预留真实存储接口联动；接口未就绪前保留现状静态文案 |

## 四、边界与异常场景

| # | 场景 | 行为 |
|---|------|------|
| 1 | 筛选结果为空（0 人） | 任务正常完成；zip 内只有名单 Excel（表头）+ 缺证书说明（注明无数据）；统计 0 人 0 份 |
| 2 | 全部学生都未签发证书 | zip 含名单全量行 + 缺证书说明（逐行列明未签发原因）；不生成空的证书文件夹；任务正常完成 |
| 3 | 已签发但证书 PDF 文件缺失/损坏 | 该学生跳过打包，记入缺证书说明；任务仍正常完成（不影响其他学生的证书）；缺证书数>0 |
| 4 | 同名学生 | 证书编号唯一，PDF 文件名含证书编号，不会冲突；名单行与 PDF 一一对应 |
| 5 | 导出期间有新证书签发/状态变化 | 以任务创建时刻的快照为准，新变化不追加入包；需要最新数据可重新导出 |
| 6 | 一个学生多张证书（多模块/级别） | 名单按「学生 × 证书」逐行，每行独立证书编号、独立 PDF；名单与 PDF 一一对应 |
| 7 | 超大批量（万人级） | 不拒绝：提示预计大小/耗时后照常执行；压缩包超大时超时时间自动放宽 |
| 8 | 任务失败（名单生成失败/打包失败/存储写入失败） | 任务标记失败并显示原因；可重试（≤3 次）；不产生半成品可下载文件 |
| 9 | 多人同时导出 | 各自独立任务、互不影响；同一个人重复点击 = 创建多个任务（允许） |
| 10 | 下载瞬间文件刚好到期清理 | 下载前校验文件存在性；文件已清理/已过期时给出明确提示 |
| 11 | 已签发但证书编号为空（数据异常） | 记入缺证书说明（编号缺失），不打包 |
| 12 | 越权访问他人任务 | 下载/重试仅任务发起人或管理员可操作，其他人返回无权限 |
| 13 | 中文/特殊字符文件名 | 姓名非法字符替换为下划线；压缩包内文件名 UTF-8 编码（Windows 解压兼容性待验证） |
| 14 | 存储空间不足/配额超限 | 创建任务时校验，不足直接拒绝并提示联系管理员；执行中写入失败则任务失败 |
| 15 | 任务长时间无响应（超时/服务重启） | 超时自动标记失败可重试；定时扫描兜底，避免「生成中」卡死；合法大任务因持续心跳不被误杀 |

## 五、成功度量

| 类别 | 指标 | 目标 |
|------|------|------|
| 硬校验（上线即生效） | 名单 Excel 行数 = 筛选结果行数 | 100% 一致（不一致即任务失败） |
| 硬校验（上线即生效） | 缺证书可追溯率 | 所有未打包学生均列入缺证书说明，100% |

## 附录 A：接口契约与技术要点（供开发）

> 本附录为技术实现要点，正文业务规则以第三、四章为准。产品大师子方案过程稿（S1/S2/S3 方案、业务需求梳理）已随正式 PRD 定稿清理，历史版本见 git 记录（AISE_PRD 仓库 `PRD/20260805 导出证书包改造/`）。

### A.1 接口（4 个）

| 接口 | 说明 | 关键约定 |
|------|------|---------|
| 创建导出任务 | POST /api/admin/export/tasks | 入参：任务类型 + 筛选条件 + 脱敏开关；返回：任务 ID + 状态（生成中）+ 可选大包提示；空间不足返回配额错误（创建时同步校验，不落任务） |
| 导出记录列表 | GET /api/admin/export/tasks | 分页 + 关键词；每行含任务 ID/名称/文件名/大小/操作人/时间/状态/统计（总行数、证书份数、缺证书数）/失败原因/重试次数/筛选条件快照 |
| 下载 | GET /api/admin/export/tasks/{taskId}/download | 返回 zip 流，支持断点续传；权限：发起人或管理员；错误码区分：生成中 / 文件不存在 / 已过期 |
| 重试 | POST /api/admin/export/tasks/{taskId}/retry | 仅失败状态可重试；重试沿用原筛选条件；重试次数 <3 允许，第 4 次返回已达上限 |

### A.2 状态枚举与前端映射

| 枚举 | 消息中心展示 | 操作列 | UI 现状 |
|------|-------------|--------|---------|

| success | 生成成功（绿） | 下载文件 | 已有 |
| failed | 生成失败（红） | 重试 | 新增样式（现状无） |
| expired | 文件已过期（灰） | 不可下载 | 已有 |
| 未知 | 未知状态（灰） | 禁用 | 新增兜底 |

### A.3 评审遗留与联调待办（随实现闭环）

| # | 事项 | 闭环方式 |
|---|------|---------|
| L1 | 空间校验过渡口径下，执行期可能写入失败——失败原因需明确区分「疑似存储配额不足」与真实存储故障 | 创建时提示存储压力；执行期失败原因明示配额嫌疑 |
