## 三、功能方案

> 三部分分别对应三个子任务方案：3.1 服务端（S1 V4 第 2 节）、3.2 16 页前端（S2 第 3 节）、3.3 19 消息中心（S3 第 3 节）。详细设计、代码示意、边界处理见各子任务方案原文。

### 3.1 服务端：导出任务（S1，含 S4 边界异常）

#### 3.1.1 导出任务表（export_task）

| 字段 | 说明 |
|---|---|
| id / task_id | 任务 ID（如 ET20260805001） |
| task_type | 固定 `student_cert_package`（预留其他导出类型） |
| filter_snapshot | 筛选条件快照 JSON（点击时刻筛选 = 产物内容） |
| desensitize | 脱敏开关（默认 true） |
| operator_id / operator_name | 发起人 |
| status | processing / success / failed / expired |
| file_name / file_path / file_size | zip 信息 |
| summary | { total_rows, pdf_count, missing_count } |
| warning | 信息性提示（预计体积/耗时） |
| estimated_size | 预估字节数（独立落库，评审遗留 L2：供超时扫描选阈值） |
| attempt_count | 已重试次数（初始 0，上限 3） |
| fail_reason | 失败原因 |
| created_at / finished_at / expire_at / updated_at | 时间戳（updated_at 兼作心跳） |

出处：S1 V4 L205-220、L389（L2 补 estimated_size 落库）。

#### 3.1.2 创建接口：配额预检 + 轻量预估 + warning（合并为一步）

1. **同步轻量预估（一次 COUNT）**：一次 COUNT 统计筛选总行数 totalRows + 已签发证书数 issuedCount（开销可忽略）。
2. **配额预检（双口径）**：`预估存储占用 = issuedCount × 平均 PDF 大小（假设 1.25MB，P0 实测项）`；
   - 正式口径（待确认#8 重估后启用）：预估占用 > 配额余量 → 拒绝创建、不落任务，返回 QUOTA_EXCEEDED；
   - **过渡口径（当前生效）**：仅「配额余量 < 最小阈值（假设 100MB，可配置）」才拒绝——保证默认参数下 5682 行主场景不被硬拒。
3. **warning（信息性，不阻塞）**：预估 ≥2GB 或 issuedCount >10,000（可配置）→ 响应带 warning `{ estimatedSize, estimatedTime, message }`，任务照常创建执行。
4. 落任务（status=processing，入参快照 JSON 全量保存）→ 返回 `{ taskId, status:"processing", warning? }` → 异步队列消费。

出处：S1 V4 L80-86（创建时序合并为一步）、L234-242（预估算法/配额双口径/warning 阈值）。

#### 3.1.3 执行流程

```
队列消费任务
  → 1. 按 filter 快照全量查询学生证书行（游标分页，无页大小上限）
  → 2. 生成 Excel（列规范见 3.1.4；数据 = 全量行）
  → 3. 遍历行：电子证书状态=已签发 且 有 cert_no → 从证书文件存储读 PDF
         - 读取失败/文件缺失 → 记入缺证书清单（原因枚举见 3.1.6），继续
         - 未签发/签发失败等 → 记入缺证书清单（状态原因），继续
  → 4. 流式打包 zip（结构见 3.1.5；PDF 每批 N=500 写入，假设值）；
         ★ 每批完成后刷新 updated_at（心跳）——合法大任务不被悬挂扫描误杀
  → 5. 上传/落盘 zip，更新任务记录：status=success、fileName、fileSize、统计、完成时间
  → 6. 消息中心导出记录 Tab 从任务表读取（S3 负责 UI 消费）
失败（Excel 生成失败 / zip 打包失败 / 存储写入失败 / 超时）
  → 任务置 failed + failReason，可重试
```

出处：S1 V4 L109-122。

#### 3.1.5 zip 包结构

```
学生证书包_20260805_共5682人_3200份.zip
├── 学生证书列表.xlsx          （全量行，必含）
├── 缺证书说明.txt             （★恒生成，三种内容形态）
└── 证书PDF/                   （打包 PDF 数为 0 时不生成此目录）
    └── 张小明_CERT202608050001.pdf   （仅已签发且读取成功；文件名=姓名_证书编号）
```

- **「缺证书说明.txt」恒生成三形态**：①全部打包成功（0 缺）注明「全部 N 行证书均已打包，无缺失」；②筛选结果为空注明「筛选条件下无数据」；③存在未打包行逐行列明明细（序号/姓名/证书编号/电子证书状态/原因）。
- **ZIP64**：Excel/zip 库选型硬性支持（单 zip 可超 4GB）。
- zip 文件名规范：`学生证书包_{yyyyMMdd}_{共{totalRows}人}_{{pdfCount}份}.zip`；UTF-8 字符集；姓名非法文件名字符（`/ \ : * ? " < > |`）替换为 `_`；单学生多证书行以 cert_no 唯一区分文件名。
- 命名先例：消息中心 mock 已有 `certs_batch_1002_final.zip`（19 页 L147）。

出处：S1 V4 L154-171、L375-377。

#### 3.1.6 缺证书原因枚举（7 类，机器可读 code + 文案，同时落库）

| code | 文案 | 触发条件 |
|---|---|---|
| NOT_ISSUED | 电子证书未签发 | 状态 ∈ pending 大类（含内部子状态：等待成绩/生成中/待签发，页面文案归 pending 大类） |
| ISSUE_FAILED | 电子证书签发失败 | 状态 = 签发失败（证书 PRD L73 保存失败原因） |

#### 3.1.7 下载与重试

- **下载** `GET /api/admin/export/tasks/{taskId}/download`：返回 `application/zip` 流 + `Content-Disposition: attachment; filename*=UTF-8''...`；鉴权（发起人本人或管理员）；支持 Range 断点续传；**错误码按状态**：processing → FILE_NOT_READY（生成中，S3 下载禁用态对齐）；failed → FILE_NOT_FOUND（无产物）；success 文件缺失/过期 → FILE_NOT_FOUND / FILE_EXPIRED。
- **重试** `POST /api/admin/export/tasks/{taskId}/retry`：仅 failed 可重试；attempt_count < 3 允许（自增 1），第 4 次重试请求返回 409；**409 仅为单任务重试上限提示，不限制新建任务**（频率限制列入 F14 Could）。

出处：S1 V4 L224-229、L357-358。
