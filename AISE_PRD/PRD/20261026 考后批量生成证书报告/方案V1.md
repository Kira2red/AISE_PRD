# 考后批量生成证书报告 方案V1

> 需求日期：2026-10-26 ｜ 状态：已拍板，进入 demo + PRD 交付

> 需求提出：张二红（2026-10-26 Slack 沟通拍板）

## 1. 背景

活动详情支持批量创建多场同构测评（如一个活动下 17 场）。现行证书/报告的生成与推送操作在单场维度（14/15 测评证书管理页，待复核环节逐场触发），活动下场次多时运营要逐场进详情页操作，等待与操作成本高。本需求在活动维度提供批量生成入口：一次圈选多场测评，批量生成证书与报告，统一查看进度并批量推送。

## 3. 方案要点

### 3.1 生成资格（逐场判断）

- 报告：批改完成、正式总分齐备即可生成；覆盖全部参测学员（含未通过），沿用 20260728 口径
- 证书：三个前置缺一不可——①批改完成 ②证书实例已配置（该测评全部考场格绑定证书模板）③分数线已设置；覆盖仅达标学员
- 资格不满足的场次锁住勾选并标注原因（批改中 / 证书实例缺配置 / 分数线未设置）
- 已生成过的场次默认跳过不重复生成；已流转公示中的场次自动排除

### 3.2 入口与交互

- 入口：33 活动详情页工具栏「生成证书 / 报告」按钮，打开近全屏三段式向导弹窗
- 第 1 段 资格检查与圈选：按分组树列出全部测评，每行展示名称、时间、参测/达标人数、资格状态、证书/报告双勾选；顶部「全选可生成 / 清空」快捷键；底部实时汇总（已选场次、证书覆盖 X 人、报告覆盖 Y 人）
- 第 2 段 进度视图：确认后异步执行，总进度条 + 按场次明细（证书/报告各自成功、失败、总数）；失败展开到学员级，单个重试 + 一键重试全部失败项；关闭弹窗任务不中断，重进恢复
- 第 3 段 推送：全部生成完成后出现「批量推送证书」「批量推送报告」按钮，各自独立进度；完成后汇总行显示「M/N 场已满足公示条件」

### 3.3 边界

- 同一活动同一时刻仅允许一个批量任务运行，入口置灰提示进行中
- 整场重新生成走既有单场流程（15 详情页），批量视图内只做失败重试
- 推送失败处理从简（标记失败可重推），沿用 Q4 口径不细分服务号绑定等原因
- 证书实例漏配的场次在资格列标注缺失格数，引导到 33 行内补配 / 28 证书实例管理
