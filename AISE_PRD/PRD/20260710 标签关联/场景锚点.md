# 场景锚点：标签跨属性关联

## 产品定位

AISE 标签配置管理（admin/13_标签配置.html）新增「跨属性标签关联」能力。现有标签体系中，属性之间是平级独立的——选了参测模块的某个标签后，参测等级的下拉仍然展示全部 11 个标签。通过建立标签间的父子关联，实现测评活动配置时的级联过滤。

## 现有系统基线

### 标签体系结构

```
属性（Attribute）
  ├── 名称
  ├── 状态（启用/停用）
  ├── 选择模式（单选/多选）
  ├── 描述
  └── 标签列表（Tag）
        ├── 名称
        ├── 颜色
        ├── 引用次数
        └── ...（无关联字段）
```

### 当前属性列表（线上实际数据）

| 属性 | 标签数 | 选择模式 |
|------|--------|---------|
| 所属模块 | 2 | - |
| 难度等级 | 0 | - |
| 年份 | 0 | - |
| 参测模块 | 4（创新实践评定/技术融合应用/智能工具实操/青年编程） | 单选 |
| 参测等级 | 11 | - |
| 编程语言 | 3 | - |
| 证书模板 | 3 | - |

### 当前标签表操作

- 每个标签行：编辑 / 删除
- 属性面板：新增属性 / 合并标签 / 新增标签

### 缺失能力

属性之间没有关联。选参测模块标签后，参测等级不能自动过滤。

## 目标模型

### 新增关联关系

```
参测模块「智能工具实操」
  └── 关联子标签（来自「参测等级」）：一级、二级、三级

参测模块「青年编程」
  └── 关联子标签（来自「参测等级」）：一级、二级、四级
```

### 核心约束

- 父标签和子标签必须属于**不同属性**（同一属性内不允许关联）
- 一个标签可以关联多个其他属性下的多个标签（不设限）
- 关联是**双向**的：父→子过滤，子→父也过滤
- 被关联的标签不允许删除（需先解除所有关联）

## 涉众

- **运营方（admin）**：在标签配置页配置标签间的关联关系
- **测评活动配置者**：在新建/编辑测评活动时体验级联过滤效果

## 涉及页面

- `13_标签配置.html`：标签行新增「关联子标签」按钮 + 关联弹窗

## 影响页面（级联过滤生效范围）

- `03_测评活动列表` / `04_测评活动详情` / `05_新建测评活动`：标签多选下拉的候选列表按关联关系过滤
- `06_测评组管理`：批量标签选择同样受影响
