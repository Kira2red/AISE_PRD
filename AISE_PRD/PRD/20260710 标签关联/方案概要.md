# 方案概要：标签跨属性关联

> 版本：V1.1 | 日期：2026-07-10 | 作者：产品大师（与 PRD V1.1 对齐）
>
> ⚠️ V1.1 变更：弹窗交互改为全量平铺式（按用户 Demo 确认）；标签删除逻辑统一；补充属性删除的父标签场景。

---

## 1. 概述

### 1.1 背景

AISE 标签体系当前属性之间完全独立。测评活动配置时，选了参测模块的某个标签（如「智能工具实操」），参测等级下拉仍然展示全部 11 个标签。运营需要在大量无关选项中翻找，且容易选错不匹配的等级组合。

### 1.2 目标

- 标签配置管理新增跨属性关联能力：一个标签可以关联另一个属性下的若干标签作为子标签
- 测评活动配置页面，标签选择实现级联过滤：选父后子属性候选列表自动缩减，反之亦然
- 关联关系在现有标签配置页内管理，不新增独立页面

---

## 2. 数据模型

### 2.1 新增：标签关联表（TagAssociation）

| 字段 | 类型 | 说明 |
|------|------|------|
| 关联 ID | - | 主键 |
| 父标签 ID | 外键 → 标签表 | 关联的发起方 |
| 子标签 ID | 外键 → 标签表 | 被关联的标签 |
| 创建时间 | datetime | 审计 |

**唯一约束**：(父标签 ID, 子标签 ID) 联合唯一，防止重复关联。

**跨属性约束**：创建关联时校验父标签和子标签的所属属性 ID 不同，相同时拒绝。

### 2.2 现有表修改

标签表无需新增字段。关联关系全部存在独立表中，不影响现有标签的 CRUD 操作。

---

## 3. 标签配置页改动（13_标签配置.html）

### 3.1 标签列表行操作

每行操作列新增「关联子标签」按钮：

```
编辑 | 删除 | 关联子标签
```

按钮样式与「编辑」「删除」同级，颜色使用 slate（中性色，与蓝/红区分）。

### 3.2 关联子标签弹窗

点击「关联子标签」→ 弹出「标签关联管理 —— {标签名称}」弹窗，宽度 800px。

**弹窗结构**（全量平铺式）：

弹窗主体按属性分组直接展示所有目标属性的标签，不需要先选择属性：
- **有标签的属性**：按属性名分组，每组标注标签总数和已关联数量。每个标签以复选框展示，已关联的默认勾选
- **无标签的属性**：灰色折叠，标注「0 个标签，无可用关联」
- **底部汇总区**：固定展示已关联的子标签（含属性名），实时更新。每个标签可点击直接取消关联

**保存逻辑**：整体提交弹窗中所有勾选的子标签集合。

### 3.3 协同时的冲突处理

两个管理员同时编辑同一标签的关联关系时，后保存的覆盖先保存的（以最后提交的勾选集合为准）。不做乐观锁，因为这个场景并发概率极低。

---

## 4. 级联过滤逻辑

**级联过滤本期不实现。** 关联关系仅作为数据存储，不改变已有页面的标签选择行为。测评活动配置页的标签下拉保持全部标签可选，不受关联关系影响。后续需要启用级联过滤时单独出需求。

---

## 5. 边界条件

### 5.1 删除标签

- 标签被其他标签关联为子标签 → **阻止删除**，提示「该标签已被 N 个标签关联为子标签，请先解除关联」
- 标签关联了其他标签（作为父标签）→ 允许删除，同时删除其所有关联记录（级联删除）
- 标签没有任何关联 → 正常删除（现有逻辑不变）

### 5.2 删除属性

- 属性下的标签如果有被其他属性的标签关联 → **阻止删除属性**，提示「该属性下有标签被其他属性的标签关联，请先解除」
- 属性下的标签如果关联了其他属性的标签 → 允许删除属性，关联记录级联删除
- 属性无标签或有标签但无跨属性关联 → 正常删除

### 5.3 合并标签

现有「合并标签」功能：将标签 A 合并到标签 B，标签 A 被删除。

合并时：
- 标签 A 的父关联 → 迁移到标签 B（以防丢失关联配置）
- 标签 A 的子关联 → 迁移到标签 B
- 出现重复关联（标签 B 已经关联了同一个子标签）→ 去重

### 5.4 属性选择模式

关联不影响属性的选择模式（单选/多选）。如果父属性是单选模式，父标签只能选一个，子属性候选列表基于唯一选中的父标签过滤。如果父属性是多选模式，父标签可以选多个，子属性候选列表基于所有选中父标签的子标签**合集**过滤。

---

## 6. 不做的场景

- 不提供「关联关系全景图」或「关联拓扑可视化」
- 不提供批量导入/导出关联关系
- 不支持跨属性关联的「层级深度限制」（当前就是一层：父→子，不会再有父→子→孙）
- 不校验「循环关联」——因为限定跨属性且单向存储（父→子），且同一属性内不允许关联，天然无循环

## 8. 接口设计

### 8.1 新增接口

| 接口 | 方法 | 说明 |
|------|------|------|
| 获取某标签的关联 | GET | 传入标签 ID，返回该标签关联的所有子标签（按目标属性分组） |
| 保存标签关联 | PUT | 传入标签 ID + 所有子标签 ID 列表（跨属性），整体替换该标签的全部关联 |

### 8.2 修改接口

| 接口 | 改动 |
|------|------|
| 获取某属性下的标签列表 | 新增可选参数 `filter_by_parent_tags`，传入已选中的其他属性标签 ID 列表，返回过滤后的标签列表 |
| 删除标签 | 增加关联检查，有子关联时拒绝 |
| 合并标签 | 增加关联迁移逻辑 |
