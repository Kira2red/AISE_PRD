# 个人报告与题库建设 — 业务需求梳理

> 依据：运营提供的《AISE考级报告需求说明v1.0》PRD
> 整理日期：20260728

---

## 需求总览

| 编号 | 模块 | 需求概述 | 优先级/备注 |
|------|------|---------|------------|
| 1 | 个人报告 | 生成 AISE 考级报告，含等级、成长区间、知识点、考级表现、下阶段建议 | 核心需求 |
| 2 | 题库建设 — 录题界面 | 新增 AISE 题库选择、级别下拉、编号规则 | 高 |
| 3 | 题库建设 — 题目维度 | 每个题干上方增加「题目」输入字段 | 高 |
| 4 | 题库建设 — 筛选 | 题目列表页增加 AISE 相关筛选 | 中 |
| 5 | 题库建设 — Python参考答案 | Python 编程题增加参考答案文件上传 | 中 |
| 6 | 题库建设 — Markdown批量上传 | 支持整套 Markdown 格式题目批量导入 | 低（复杂则暂缓） |
| 7 | 证书导出 | 后台导出证书表格、对应照片、证书图片 | 独立需求 |

## 一、个人报告

### 1.1 页面结构概览

报告从上到下分五个模块：

| 顺序 | 模块 | 说明 |
|------|------|------|
| 1 | 标题栏 | 级别、学生姓名、考试年月、通过/未通过状态 |
| 2 | 考级结果概览 | 报告等级 + 成长区间 + 一句话总结 + 小提琴图 |
| 3 | 知识点掌握情况 | 按一级二级标签展示掌握状态 |
| 4 | 考级具体表现 | 满分高光 / 非满分重点错题，两套展示逻辑 |
| 5 | 下一阶段建议 | 考级衔接 + 课程学习建议，按级别×状态交叉 |

### 1.3 考级结果概览

#### 1.3.1 等级总览映射表

报告直接使用考试系统正式发布总分，不取整、不四舍五入、不重新汇总。

| 正式总分 score | 通过状态 | 报告等级 | 所处成长区间 |
|---------------|---------|---------|------------|
| 0 ≤ score < 30 | 未通过 | 待提升 | 初步形成 |
| 30 ≤ score < 60 | 未通过 | 待提升 | 稳步接近 |
| 60 ≤ score < 70 | 通过 | 合格 | 目标达成 |
| 70 ≤ score < 80 | 通过 | 良好 | 熟练掌握 |
| 80 ≤ score ≤ 100 | 通过 | 优秀 | 高阶表现 |

#### 1.3.2 成长区间定位图（小提琴图）

| 规则项 | 内容 |
|--------|------|
| 五段图形宽度 | 30% / 30% / 20% / 10% / 10% |
| 五个阶段（从左到右） | 初步形成、稳步接近、目标达成、熟练掌握、高阶表现 |
| 图形含义 | 仅表示五个阶段，不表示人数或真实样本分布 |
| 轴线类型 | 类别轴，不是连续分数轴 |
| 标记位置 | 固定放在对应阶段中心，不随阶段内具体分数移动 |
| 五个中心位置 | 15% / 45% / 70% / 85% / 95%（满分取 100%） |

#### 1.3.3 一句话总结

| 报告等级 | 文案 |
|---------|------|
| 待提升 | 综合本次考级表现，本级基础正在逐步形成，建议继续巩固核心任务。 |
| 合格 | 综合本次考级表现，已达到本级基本要求，可继续巩固并拓展。 |
| 良好 | 综合本次考级表现，已较稳定达到本级要求，可进一步提升综合应用。 |
| 优秀 | 综合本次考级表现，已高质量完成本级主要任务，可继续挑战更复杂的综合任务。 |

### 1.4 知识点掌握情况

#### 1.4.1 知识标签体系

各级别有独立的知识树，结构为一级知识模块 → 二级知识点。报告知识点掌握情况及考级表现中的高光&错题，均依赖题目知识标签。

以四级（PL1）为例：

| 一级知识模块 | 二级知识点 | 题库映射三级标签（参考） |
|------------|-----------|---------------------|
| Python运算 | 比较运算 | >、<、== |
| Python运算 | 布尔值 | True、False |
| Python运算 | 算术运算 | +、- |
| 流程控制 | 条件分支 | 单分支if、双分支if...else... |
| 流程控制 | 循环 | while循环（while True） |
| 流程控制 | IPO编程 | IPO编程 |
| 常用标准库 | 模块导入 | random |
| 编程基础 | 变量 | 变量命名规则、变量赋值 |
| 编程基础 | 数据类型转换 | int() |
| 编程基础 | 数据类型 | 整数、字符串 |
| 编程基础 | input()语句 | input()语句 |
| 编程基础 | print()语句 | print()输出字符串、print()输出算式、print()输出数字 |

#### 1.4.2 掌握度判定

| 知识维度作答数据 | 掌握状态 |
|----------------|---------|
| < 60% | 重点提升 |
| ≥ 60% | 稳定掌握 |

掌握率公式：**该知识点关联题目的得分之和 ÷ 该知识点关联题目的满分值之和**。

#### 1.4.3 展示排序

一级结构下的二级标签按升序展示：先展示「重点提升」，再显示「稳定掌握」。同状态内按知识树顺序展示。

### 1.5 考级具体表现

#### 1.5.1 两套展示逻辑

| 规则项 | 满分画像（总分 = 100） | 非满分画像（总分 < 100） |
|--------|---------------------|----------------------|
| 触发条件 | 总分等于 100 | 总分小于 100 |
| 展示题目数 | 1 道 | 2 道 |
| 题目选取 | 首道满分的编程题 | 首道错误的客观题 + 首道扣分的编程题 |
| 排序 | / | 按题号展示，客观题先于编程题；如客观题全对，则仅展示编程题 |
| 展示答案 | 只展示学生作答，不展示正确答案 | 展示学生作答与正确答案 |
| 作答点评 | 本题目作答达到要求，完整完成任务。太棒了！ | 建议重点提升【题目二级标签知识点】。 |

#### 1.5.2 编程题截断规则

学生作答代码行数较多时，统一保留前 5 行后截断。

#### 1.5.3 关键澄清（对照运营口头规则）

| 维度 | PRD 原文 | 上次口头规则 | 采用 |
|------|---------|------------|------|
| 满分取题 | 首道满分的编程题 | 首道错题 | PRD 原文 |
| 非满分取题 | 首道错误的客观题 + 首道扣分的编程题 | 首道编程题 | PRD 原文 |
| 满分展示答案 | 只展示学生作答，不展示正确答案 | 展示正确答案 | PRD 原文 |
| 满分点评 | 固定文案「本题目作答达到要求，完整完成任务。太棒了！」 | 结合二级标签重点提升 | PRD 原文 |
| 非满分点评 | 「建议重点提升【题目二级标签知识点】。」 | 统一一句话文案 | PRD 原文 |

### 1.6 下一阶段学习

考级衔接区分级别（一级～八级）和通过/未通过状态，各出两套建议。学习建议也按级别区分。

#### 一级

| 状态 | 考级衔接 | 课程学习建议 |
|------|---------|------------|
| 通过 | 建议继续学习变量、循环和条件判断，尝试编写较复杂的逻辑程序，衔接二级。 | 建议提升程序逻辑设计与表达能力，逐步完成更完整的编程任务。 |
| 未通过 | 建议先巩固一级，继续学习变量、循环和条件判断，尝试编写较复杂的逻辑程序。 | |

#### 二级

| 状态 | 考级衔接 | 课程学习建议 |
|------|---------|------------|
| 通过 | 建议继续学习数据类型及顺序、分支和循环结构，逐步过渡到代码编程，衔接四级。 | 建议进阶学习代码编程，巩固基础编程语法。 |
| 未通过 | 建议先巩固二级，继续学习数据类型及顺序、分支和循环结构，尝试进行代码编程。 | |

#### 四级

| 状态 | 考级衔接 | 课程学习建议 |
|------|---------|------------|
| 通过 | 建议继续学习列表、字典及循环分支嵌套，构建更复杂的程序逻辑，衔接五级。 | 建议通过更完整的项目练习，提升复杂逻辑设计和问题解决能力。 |
| 未通过 | 建议先巩固四级，继续学习列表、字典及循环分支嵌套，练习构建复杂程序逻辑。 | |

#### 五级

| 状态 | 考级衔接 | 课程学习建议 |
|------|---------|------------|
| 通过 | 建议继续学习函数定义与整除取余，尝试用程序解决数学问题，衔接六级。 | 建议提升多文件编程能力，增强模块协作与项目组织能力。 |
| 未通过 | 建议先巩固五级，继续学习函数定义与整除取余，尝试用程序解决数学问题。 | |

#### 六级

| 状态 | 考级衔接 | 课程学习建议 |
|------|---------|------------|
| 通过 | 建议继续学习核心算法与数据分析，使用枚举、模拟等方法解决实际问题，衔接七级。 | 建议提升数据分析能力，增强数据处理与问题洞察能力。 |
| 未通过 | 建议先巩固六级，继续学习核心算法与数据分析，练习用枚举、模拟等方法解决实际问题。 | |

#### 七级

| 状态 | 考级衔接 | 课程学习建议 |

## 二、题库建设

### 2.1 录题界面增加 AISE 相关选择

| 改造项 | 说明 |
|--------|------|
| 题库下拉新增「AISE题库」 | 选择此题库录入的题目归属 AISE 题库，方便后期筛选组卷 |
| 新增「级别」下拉 | 可选一级～八级 |
| 新增编号规则 | AISE 题目编号体系（如 `AISE-{套}-{题号}`），具体规则待设计 |

### 2.2 题干上方增加「题目」输入字段

录题页面每个题干上方增加「题目」文本输入区，与报告呈现直接关联。

### 2.3 题目列表页筛选功能

增加 AISE 相关筛选条件（题库、级别、题型等）。

### 2.4 Python 编程题 — 参考答案文件上传

Python 编程 OJ 题型增加「上传示例代码」框体，示例代码代表本题标准答案。报告中提取前 5 行展示。

### 2.5 Markdown 批量导入（低优先级）

支持整套 Markdown 格式题目（含图片、代码）批量上传。复杂则暂缓。
