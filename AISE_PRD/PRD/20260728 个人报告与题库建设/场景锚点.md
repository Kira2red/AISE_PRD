# 场景锚点 — 个人考级报告与知识标签管理

## 1. 产品定位

AISE 考级平台新增两个能力：
- **用户端**：考生完成测评后，系统自动生成「考级报告」，展示等级结果、知识点掌握情况、错题分析、下阶段学习建议
- **admin端**：运营后台新增「知识标签管理」模块，维护三级知识标签体系（级别→一级模块→二级知识点→三级标签），用于题库标注和报告生成

## 2. 涉及页面

| 端 | 页面 | 类型 | 说明 |
|------|------|------|------|
| user | 考级报告页 | **新建** | 查看个人考级报告的完整页面 |
| admin | 知识标签管理 | **新建** | 维护三级知识标签体系的配置页 |

## 3. 核心规则（来源：AISE考级报告需求说明v1.0 PDF）

### 3.1 报告等级判定
- 所有模块均通过 → 获得对应等级
- 有任一模块未通过 → 显示最高通过模块对应等级
- 边界情况：无任何通过模块 → 不生成报告

### 3.2 报告页面基准
- 视口：390×844（手机端）
- 字号阶梯：主标题、副标题、正文、辅助文字

### 3.3 报告五章结构
1. **顶部信息**：姓名、测评名称、报考级别、获得级别（通过）/ 未通过说明
2. **结果预览**：五档成长区间小提琴图（中心点15%/45%/70%/85%/95%），标注"我的位置"
3. **知识点掌握**：一级知识模块×二级知识点矩阵，标注掌握率（正确数/总数），分"重点提升"(<60%)和"稳定掌握"(≥80%)
4. **考级具体表现**：满分→高光版（取首道满分编程题）；非满分→重点错题版（1道客观题+1道编程题）
5. **下阶段建议**：级别×通过/未通过 → 逐级文案

### 3.4 知识标签三级体系
- 一级（知识模块）→ 二级（知识点）→ 三级（题库映射标签，后台录入，前端不展示）
- 知识点掌握率 = 该知识点下做对题数 / 该知识点下总题数

## 4. 现有系统约束

- AISE admin 端所有页面遵循「列表表格 + 行内编辑按钮 + 弹窗表单」模式
- user 端页面以手机端为主（390-480px 宽）
- 当前 admin 标签系统（13_标签配置）为「属性→标签」两级结构，用于测评活动标记，与知识标签体系是不同领域
- admin 已最大编号 30，新建页从 31 开始
- user 已最大编号 28，新建页从 29 开始
