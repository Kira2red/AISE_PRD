## 一、产品定位

AISE 考级平台新增「个人报告」能力：考试批改完成、成绩发布后，为每位考生自动生成一份个人考级报告，包含等级评定、成长区间定位、知识点掌握情况、考级具体表现与下一阶段建议。用户在「我的活动」「成绩与证书」两个入口查看报告，支持 Web/移动端查看与 PDF 下载。

- 报告对象：所有已批改且有正式总分的考生（含未通过考生，未通过展示「待提升」等级）
- 报告性质：诊断 + 激励型学习反馈，非证书类证明文件
- 报告数据：全部来自考试系统正式数据，报告不做任何二次计算（总分不取整、不重算）

## 三、核心业务规则（来自原始需求，逐条锁定）

### 3.1 等级映射（正式总分直用，不取整不四舍五入不重算）

| 正式总分 | 通过状态 | 报告等级 | 成长区间 |
|---------|---------|---------|---------|
| 0 ≤ score < 30 | 未通过 | 待提升 | 初步形成 |
| 30 ≤ score < 60 | 未通过 | 待提升 | 稳步接近 |
| 60 ≤ score < 70 | 通过 | 合格 | 目标达成 |
| 70 ≤ score < 80 | 通过 | 良好 | 熟练掌握 |
| 80 ≤ score ≤ 100 | 通过 | 优秀 | 高阶表现 |

### 3.2 成长区间定位图（小提琴图）

- 五段宽度 30%/30%/20%/10%/10%，仅表示阶段不表示分布
- 类别轴，标记点固定于阶段中心（15%/45%/70%/85%/95%，满分 100%）

### 3.3 掌握度判定

- 掌握率 = 知识点关联题目得分之和 ÷ 关联题目满分值之和
- < 60% → 重点提升；≥ 60% → 稳定掌握
- 展示排序：一级模块按知识树顺序；模块内先「重点提升」后「稳定掌握」；同状态内按知识树顺序

### 3.4 考级具体表现（两套逻辑）

- 满分（=100）：展示 1 道首道满分编程题，只展示学生作答不展示正确答案，点评固定文案
- 非满分（<100）：展示首道错误客观题 + 首道扣分编程题，按题号排序、客观题在前；客观题全对则仅展示编程题；展示学生作答与正确答案；点评「建议重点提升【二级知识点】」
- 编程题作答保留前 5 行截断
- 口径冲突以 PRD 原文为准（满分取题/非满分取题/答案展示/点评文案四项）

### 3.5 下一阶段建议

- 级别 × 通过状态交叉出文案（一级/二级/四级/五级/六级/七级/八级共 7 个级别 × 2 状态）
- 未通过级别：课程学习建议列为空（原始需求表如此）
- 建议文案原文照录，不做演绎

### 3.6 知识标签体系

- 各级别独立知识树：一级知识模块 → 二级知识点（→ 三级标签入库不展示）
- 报告依赖题目「知识点」字段（非题目标签），题目录入侧由独立 PRD 覆盖

## 四、页面结构（五模块，自上而下）

1. 标题栏：级别 + 学生姓名 + 考试年月 + 通过/未通过状态
2. 考级结果概览：报告等级 + 成长区间 + 一句话总结 + 成长区间定位图
3. 知识点掌握情况：一级模块 → 二级知识点 + 掌握状态标签
4. 考级具体表现：满分高光 / 非满分重点错题
5. 下一阶段建议：考级衔接 + 课程学习建议

## 五、交互原则

1. 移动端优先响应式：基准视口 390×844，PC/移动端同一页面自适应
2. 可读性：正文/题目内容 ≥ 15px，辅助标签 ≥ 12px，核心标题 20-24px
3. 入口按钮规则：成绩发布且报告生成完成后才展示「查看报告」；生成中/未发布不展示
4. 打开方式：新页面打开报告（不弹窗）
5. 报告支持下载 PDF

## 六、设计基准（来自原始 PDF 样式提取）

- 主文字深藏青 #0f1835 / #0e1935，品牌紫 #8777d3 / #705fd2，浅紫 #aaa8e1
- 亮蓝（按钮/链接） #2555e7 / #2957e7，高亮粉红（错题/重点） #f0646b / #f1666d
- 页面背景白 #f7f7f8 / 浅灰 #e9e9ea，次要文字 #606471
- 代码块深底 #1d1d1e + 文字 #e9e9e9 + 语法高亮 #1d90fa
- 视觉基准图：images/page2_img1.jpeg、page2_img2.jpeg（长截图），page3-5 组件图
- 状态色（视觉核验近似值，Demo 阶段以长截图对照）：稳定绿 / 重点提升橙
- 注意：当前会话无视觉模型，Demo 阶段以样式参考文档的 PIL 色值 + 结构描述为准

## 七、系统依赖与生成时机

- 生成时机：与电子证书签发同一触发点（成绩发布后自动触发），异步任务生成
- 依赖数据：正式总分、题目知识点标签、学生作答（批改完成、成绩发布后齐备）
- 覆盖范围：所有已批改且有正式总分的考生（含未通过）；证书仅覆盖达标考生
- 生成完成前：入口不展示「查看报告」
