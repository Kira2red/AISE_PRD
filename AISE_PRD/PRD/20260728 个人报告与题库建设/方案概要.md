# 方案概要 — 个人考级报告与知识标签管理

## 1. 需求背景

AISE 考级平台当前缺少考试结果的可视化报告。考生完成测评后只能在「我的活动」看成绩公示、在「成绩与证书查询」查分数，没有一个完整的「考级报告」来展示等级评定、知识点掌握分析、错题回顾和下阶段学习建议。

同时，后台缺少知识标签体系。目前题库标注依赖活动级标签（参测模块、参测等级等），没有"一级知识模块→二级知识点→三级题库映射标签"的三级知识标签。报告中的"知识点掌握分析"需要这套标签体系做数据支撑。

## 2. 本期范围

| 模块 | 所属端 | 说明 |
|------|--------|------|
| 考级报告页 | user 端（新建 29） | 手机端页面，五章结构展示个人考级报告 |
| 知识标签管理 | admin 端（新建 31） | 三级知识标签体系的配置维护 |

### 本期不做的

- 题库批量标注/关联知识标签（后续单独需求）
- 报告中的小提琴图用 SVG 模拟数据实现（真实数据需后端）
- 报告分享/导出功能
- 已有的活动标签体系（13_标签配置）不做任何改动

## 3. 用户考级报告页

### 3.1 页面信息架构

```
┌──────────────────────────────┐
│  顶部导航：← 返回  │ AISE    │
├──────────────────────────────┤
│  §1 顶部信息                  │
│  姓名 / 测评名称 / 报考级别    │
│  获得级别（通过）OR 未通过说明  │
├──────────────────────────────┤
│  §2 结果预览                  │
│  五档成长区间小提琴图          │
│  标注"我的位置"               │
├──────────────────────────────┤
│  §3 知识点掌握                │
│  一级模块 × 二级知识点 矩阵    │
│  重点提升（<60%）/ 稳定掌握（≥80%）│
├──────────────────────────────┤
│  §4 考级具体表现              │
│  满分→高光版（首道满分编程题）  │
│  非满分→重点错题版（1客观+1编程）│
├──────────────────────────────┤
│  §5 下阶段建议                │
│  级别 × 通过/未通过 → 逐级文案 │
└──────────────────────────────┘
```

### 3.2 页面来源

新建 `user/29_考级报告.html`，文件路径：`/Users/didi/Documents/AISE/AISE_PRD/html/user/29_考级报告.html`

用户通过「我的活动」(15) 或「成绩与证书查询」(19) 进入报告页，入口为点击活动卡片上的「查看报告」按钮。

### 3.3 交互要点

- 纯展示页面，无用户输入控件
- 手机端设计，最大宽度 480px 居中
- §2 小提琴图使用 Canvas/SVG 可视化
- §3 知识点矩阵用卡片式分组，颜色标记掌握程度（绿色=稳定掌握，橙色=重点提升）
- §4 满分版与未通过版切换展示
- §5 按级别和通过状态展示对应建议文案

### 3.4 数据依赖（Demo 用 mock 数据）

mock 数据需覆盖两个典型场景：
- 场景 A：全部通过，获得编程四级（满分版报告）
- 场景 B：部分通过，最高通过为编程三级（非满分版报告）

## 4. 知识标签管理

### 4.1 页面信息架构

采用 admin 标准模式：**左侧树形导航 + 右侧表格/表单**

```
┌────────────┬──────────────────────────┐
│  左侧      │  右侧                     │
│            │                           │
│  ◉ 级别    │  [新增模块] [新增知识点]    │
│  ├─ 四级   │                           │
│  │ ├─ 算法 │  ┌─ 知识点表格 ──────────┐ │
│  │ │ ├─排序│  │ # │ 名称 │ 三级标签 │…│ │
│  │ │ ├─查找│  │ 1 │ 冒泡 │ 2个标签  │…│ │
│  │ │ └─递归│  │ 2 │ 二分 │ 1个标签  │…│ │
│  │ ├─ 数据 │  └─────────────────────┘ │
│  │ └─ …   │                           │
│  ├─ 三级   │  选中知识点→显示关联的三级 │
│  │ └─ …   │  标签列表                  │
│  └─ …     │                           │
└────────────┴──────────────────────────┘
```

### 4.2 页面编号与路径

新建 `admin/31_知识标签管理.html`，路径：`/Users/didi/Documents/AISE/AISE_PRD/html/admin/31_知识标签管理.html`

侧边栏新增菜单项：「知识标签」，位于「标签配置」下方。

### 4.3 数据模型

```
级别（Level）
  ├── 名称（如"编程四级"）
  ├── 一级模块列表（Module）
  │     ├── 名称（如"算法与数据结构"）
  │     ├── 二级知识点列表（KnowledgePoint）
  │     │     ├── 名称（如"排序算法"）
  │     │     ├── 三级标签列表（ThirdLabel）
  │     │     │     ├── 名称（如"冒泡排序"）
  │     │     │     └── 关联题目（后续需求，本期不展示）
```

### 4.4 交互模式

沿用 admin 标准模式：
- 左侧树形结构，可展开/折叠级别和模块
- 选中知识点后右侧显示该知识点下的三级标签
- 「新增模块」弹窗：选择级别、输入模块名
- 「新增知识点」弹窗：选择级别→模块，输入知识点名
- 「新增三级标签」弹窗：输入标签名（在知识点上下文中）
- 编辑/删除操作：行内按钮 → 确认弹窗
- 支持拖拽调整知识点排序（可选，优先级低）

### 4.5 与现有系统关系

- **不修改** 13_标签配置.html（活动标签体系是独立领域）
- 知识标签的三级标签命名需**全局唯一**（同一标签不能出现在两个不同知识点下）
- 知识标签体系未来会被题库管理（08_题目管理_详情）消费，届时在题目编辑弹窗中增加「关联知识标签」字段，本期不做
