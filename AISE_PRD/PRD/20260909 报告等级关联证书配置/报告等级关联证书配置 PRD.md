# 报告等级规则独立配置 PRD

## 1. 背景与收益

个人考级报告的等级原计划直接取用证书的分数线规则，评审讨论后确认两者业务形态不同：发证一般只配 2 档（合格发证 / 不合格不发证），报告需要 3 档（优秀 / 良好 / 合格）；部分考试（技术融合、创新实践）有证书无报告；未来还可能出现证书与报告同档名不同分数线的考试。本期改为报告等级规则独立配置：在「测评管理」新增「管理报告」入口，报告的等级档位、通过判定与报告文案在报告管理页单独配置，与证书等级规则完全解耦，互不影响。

- 讨论结论出处：微信群「爱测评需求组」评审讨论（2026-09-09，全拆方案由产品拍板）。
- 报告等级现行兜底口径：[个人考级报告与知识标签管理 PRD](<../20260728 个人报告与题库建设/PRD_个人考级报告与知识标签管理.md>) 5.1.3 固定映射表。

## 2. 业务流程

1. 运营在「测评管理」列表对目标考试点「管理报告」，进入报告管理页，配置本场报告的等级档位：分数下限、等级名称、是否计入通过，以及可选的成长区间与一句话总结；只按分数划线，配置独立保存。
2. 考试批改完成、成绩发布后，系统自动生成个人报告（时机与现状一致）；等级相关内容按查看时点的当前报告规则实时计算。
3. 考生从「我的活动」「成绩与证书」进入报告页，看到按报告规则展示的等级结论、成长区间与一句话总结，可下载 PDF（按下载时点规则实时生成，与在线一致）。

## 3. 详细功能说明

### 3.1 报告管理入口（admin/03 测评活动列表）

- 列表每行操作区在现有「编辑」等操作基础上新增「管理报告」，点击新页面打开该考试的报告管理页。

### 3.2 报告等级规则配置（admin/34 报告管理，新页面）

- 页面顶部为考试名称与报告开关；关闭开关后本场不再生成新报告。
- 档位配置区：每档一条规则行——分数下限（≥ N 分）、等级名称（自由文本）、「计入通过」勾选，行右侧删除；「添加等级档位」可增档。只按分数划线，不提供按比例划线，无「重新计算」动作。
- 每档下方可选填「成长区间」（≤10 字）与「一句话总结」（≤60 字），留空合法，留空档位在报告中按 3.4 默认规则展示。
- 保存独立于证书：保存后立即生效，本场已生成的在线报告与之后下载的 PDF 立即按新规则展示；不影响证书的任何配置与已签发证书。
- 右侧提供规则说明：未配置报告等级规则时，报告按固定映射表生成（60 合格 / 70 良好 / 80 优秀，60 以下未通过）。

### 3.3 报告等级判定与通过状态（user/29 考级报告）

| 场景 | 报告等级 | 通过状态 |
|------|---------|---------|
| 已配置规则，达到某档 | 显示命中的档位名（自由文本，如「优秀」） | 达到勾选「计入通过」的最低分数线 = 通过 |
| 命中的档位未勾「计入通过」 | 显示该档位名 | 未通过 |
| 未达到最低档位线 | 显示「未通过」 | 未通过 |
| 未配置报告规则 | 按固定映射表兜底（60 合格 / 70 良好 / 80 优秀，60 以下未通过） | 60 分及以上通过，与兜底表一致 |

- 等级名显示颜色按 3.4 默认对齐关系取默认四色；「未通过」与「待提升」同为橙色。
- 报告页保留通过状态展示（含未通过），考生无需回查证书规则。
- 报告其余模块（知识点掌握、考级具体表现、下一阶段建议、下载 PDF、入口）不改动。

### 3.4 未配置文案时的默认规则

档位与固定表四等级的对齐关系（用于等级颜色、成长区间段名、一句话总结三处默认取值）：

| 档位 | 对齐等级 | 默认成长区间 | 一句话总结 |
|------|---------|-------------|-----------|
| 勾选「计入通过」的档位，按分数线从高到低第 1 档 | 优秀 | 高阶表现 | 优秀固定文案 |
| 第 2 档 | 良好 | 熟练掌握 | 良好固定文案 |
| 第 3 档及以下 | 合格 | 目标达成 | 合格固定文案 |
| 未勾「计入通过」的档位、未达最低档 | 待提升 | 稳步接近 | 待提升固定文案 |

固定文案原文见 [个人考级报告与知识标签管理 PRD](<../20260728 个人报告与题库建设/PRD_个人考级报告与知识标签管理.md>) 5.1.3，逐字沿用不改写。

### 3.5 成长区间定位图（user/29）

| 规则状态 | 图形形态 | 段名 |
|---------|---------|------|
| 已配置报告规则 | 「未通过」段 + 规则档位按分数线升序排列，各段等宽 | 取该档「成长区间」配置；未配置按 3.4 默认规则取名 |
| 未配置报告规则 | 现行五段不等宽图（30% / 30% / 20% / 10% / 10%）不变 | 初步形成 / 稳步接近 / 目标达成 / 熟练掌握 / 高阶表现 |

- 考生标记点固定放在命中段正中心，不随段内具体分数移动（与现行规则一致）。
- 图下文字说明考生所处区间；「未通过」段说明文案为「尚未达到最低等级线」。

### 3.6 规则同步与证书边界

- 报告规则与证书规则完全独立：修改报告规则不影响证书配置、已签发证书与证书签发链路；修改证书规则（含「保存并重新计算」触发的重新复核与证书重生成）不影响报告等级。
- 报告等级相关内容（等级名、通过状态、成长区间、一句话总结）按考生查看时点的当前报告规则实时计算；报告其余内容仍为生成时的作答数据。
- PDF 下载按下载时点的当前规则实时生成，与在线展示一致；考生本地历史 PDF 不追溯，以在线版为准。

### 3.7 边界与异常

| 场景 | 处理 |
|------|------|
| 配置了规则但所有档位均未勾「计入通过」 | 所有考生通过状态均为未通过；等级名正常显示命中档位 |
| 档位分数线全部高于满分 | 全员「未通过」 |
| 档位「成长区间」/「一句话总结」超长 | 输入限制 10 / 60 字，无法超长提交 |
| 报告生成后规则被修改 | 在线报告立即按新规则展示；此后下载的 PDF 按新规则生成（见 3.6） |
| 考生成绩正好卡在档位线上 | 达到分数线即计入该档（≥ 判定） |
| 报告开关关闭后再开启 | 关闭期间的成绩发布不补生成报告；重新开启后仅对之后的成绩发布生效 |

## 附：与前期方案的关系（2026-09-09 评审改向）

本期原方案为「报告等级取证书分数线规则」（含按比例划线、发证勾选判定通过、证书档位上加报告文案字段），经群评审后废弃，改为本 PRD 的报告规则独立配置。证书管理页面（admin/15、17）恢复原状，仅保留证书自身能力。
