# 报告等级关联证书配置 PRD

## 1. 背景与收益

个人考级报告的等级目前按全局固定的分数线映射表计算，电子证书的等级按每场考试在证书管理中配置的分数线规则生成，两边各算各的：同一考生可能证书显示「良好」、报告却显示「优秀」。本期将二者打通：报告等级直接取本场考试的证书等级配置，成长区间与一句话总结支持按档位配置报告文案，考生在报告与证书上看到同一套等级结论。

- 报告等级现行口径：[个人考级报告与知识标签管理 PRD](<../20260728 个人报告与题库建设/PRD_个人考级报告与知识标签管理.md>) 5.1.3 固定映射表。
- 证书等级现行口径：[证书与导出 PRD](<../20260131 成绩与证书/20260131 证书与导出.md>) 分数线配置（分数与等级映射、每档可勾选发放证书）；[证书签发流程 PRD](<../20260512 5 月需求/20260512 证书签发流程 prd.md>) 电子证书等级字段即取自该规则。

## 2. 业务流程

1. 运营在活动证书管理中配置本场考试的分数线与等级（现状能力，支持按分数划线与按比例划线），本期起可为每个等级档补充「成长区间」「一句话总结」两项报告文案，均为可选。
2. 考试批改完成、成绩发布后，系统自动生成个人报告（时机与现状一致）；等级按生成时点的证书配置计算，按比例划线的考试在成绩发布后全员分数已定，同样可计算。
3. 考生从「我的活动」「成绩与证书」进入报告页，看到与电子证书同源的等级结论、按配置或默认规则展示的成长区间与一句话总结，可下载 PDF（PDF 内容与页面同源）。

## 3. 详细功能说明

### 3.1 报告等级判定（user/29 考级报告）

| 场景             | 报告等级                                                       | 通过判定                |
| -------------- | ---------------------------------------------------------- | ------------------- |
| 已配置分数线规则，达到某档  | 显示命中的档位名（含「一等奖」「参与奖」等自定义名）                                 | 达到勾选「发放证书」的最低档 = 通过 |
| 命中的档位未勾选「发放证书」 | 显示该档位名                                                     | 未通过                 |
| 未达到最低配置档       | 显示「未通过」                                                    | 未通过                 |
| 未配置分数线规则       | 按现行固定映射表兜底（0-30 待提升、30-60 待提升、60-70 合格、70-80 良好、80-100 优秀） | 60 分及以上通过，与现行一致     |

- 按比例划线：沿用「同分同权归上一档」规则，报告等级按成绩发布后的划线结果取档。
- 等级名的显示颜色按 3.5 兜底对齐关系取默认四色；「未通过」与「待提升」同为橙色。
- 报告其余模块（知识点掌握情况、考级具体表现、下一阶段建议、下载 PDF、入口与生成时机）不改动。

### 3.2 证书配置新增报告文案字段（admin/15 活动证书管理详情、admin/17 证书流程百分比分数线）

- 每个等级档位下方新增两个可选输入：「成长区间」「一句话总结」，按分数划线与按比例划线两种模式均提供；「添加新等级」新增的档位同样自带这两项输入。
- 成长区间不超过 10 个字（需放入成长区间图的段标签），一句话总结不超过 60 个字，输入时限制长度。
- 两项均留空合法：留空档位在报告中按 3.5 默认规则展示。
- 保存与「保存并重新计算」一并提交；文案不参与等级分布统计的计算。

### 3.3 成长区间定位图（user/29）

| 考试配置 | 图形形态 | 段名 |
|---------|---------|------|
| 已配置分数线规则 | 「未通过」段 + 配置档位按分数线升序排列，各段等宽 | 取该档「成长区间」配置；未配置按 3.5 默认规则取名 |
| 未配置分数线规则 | 现行五段不等宽图（30% / 30% / 20% / 10% / 10%）不变 | 初步形成 / 稳步接近 / 目标达成 / 熟练掌握 / 高阶表现 |

- 考生标记点固定放在命中段正中心，不随段内具体分数移动（与现行规则一致）。
- 图下文字说明考生所处区间；「未通过」段说明文案为「尚未达到最低等级线」，其余段为「处于××的成长区间」。

### 3.4 一句话总结（user/29）

- 命中档位配置了一句话总结：按配置文案展示。
- 未配置：按 3.5 默认规则取「合格 / 良好 / 优秀 / 待提升」四套固定文案之一（固定文案原文见 [个人考级报告与知识标签管理 PRD](<../20260728 个人报告与题库建设/PRD_个人考级报告与知识标签管理.md>) 5.1.3，逐字沿用不改写）。
- 未达最低配置档的考生无对应配置档，固定使用「待提升」文案，不提供配置入口。

### 3.5 未配置文案时的默认规则

档位与固定表四等级的对齐关系（用于等级颜色、成长区间段名、一句话总结三处的默认取值）：

| 档位 | 对齐等级 | 默认成长区间 | 一句话总结 |
|------|---------|-------------|-----------|
| 勾选「发放证书」的档位，按分数线从高到低第 1 档 | 优秀 | 高阶表现 | 优秀固定文案 |
| 第 2 档 | 良好 | 熟练掌握 | 良好固定文案 |
| 第 3 档及以下 | 合格 | 目标达成 | 合格固定文案 |
| 未勾选「发放证书」的档位、未达最低档 | 待提升 | 稳步接近 | 待提升固定文案 |

### 3.6 生成时机与存量报告

- 报告生成时机不变：成绩发布后自动触发生成，等级与文案在生成时点按当时的证书配置计算（配置快照）。
- 之后运营修改配置（含分数线与报告文案），已生成的报告不自动更新，仅影响之后新生成的报告——与证书侧「调整模板后需重新生成」的处理先例一致（[证书重新生成 PRD](<../20260816 证书重新生成/20260816 证书重新生成 PRD.md>)）；本期不提供报告重新生成入口。

### 3.7 边界与异常

| 场景 | 处理 |
|------|------|
| 配置了规则但所有档位均未勾选「发放证书」 | 所有考生通过状态均为未通过；等级名正常显示命中档位 |
| 等级档的分数线全部高于满分 | 全员「未通过」 |
| 档位「成长区间」配置超长 | 输入限制 10 字，无法超长提交 |
| 配置的档位名与固定表等级名相同（如自定义一档也叫「优秀」） | 按配置档位正常处理，不冲突 |
| 报告生成后配置被修改 | 已生成报告不变（见 3.7） |
| 考生成绩正好卡在档位线上 | 达到分数线即计入该档（≥ 判定）；按比例划线的同分同权规则沿用 |
