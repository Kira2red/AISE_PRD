# 方案概要 — 个人报告等级关联证书配置

## 一、需求概述

个人考级报告的「报告等级」从固定分数线映射表改为取该考试在证书管理中配置的等级规则，消除「证书显示良好、报告显示优秀」的口径分叉。等级相关的成长区间、一句话总结支持在证书配置中按档位填写报告文案，未配置时按兜底规则展示。

## 二、现状与依据

- 报告等级现行口径：固定映射表（0-30 待提升·初步形成 / 30-60 待提升·稳步接近 / 60-70 合格·目标达成 / 70-80 良好·熟练掌握 / 80-100 优秀·高阶表现），出处 `PRD/20260728 个人报告与题库建设/PRD_个人考级报告与知识标签管理.md` 5.1.3。
- 证书等级现行口径：每场考试在「活动证书管理」配置分数线规则，支持按分数划线（≥90 优秀）与按比例划线（TOP 15% 一等奖）两种模式，等级名称为自由文本（可配一等奖/二等奖等），每档可勾选「发放证书」；电子证书的等级字段即取自该规则（`html/admin/28_证书实例管理.html` 字段映射「等级 ← 证书分数线规则」）。出处 `PRD/20260131 成绩与证书/20260131 证书与导出.md`、`PRD/20260512 5 月需求/20260512 证书签发流程 prd.md`。

## 三、改动点

### 改动 1：报告等级判定改为取证书配置

- 配置了分数线规则的考试：报告等级 = 按该规则命中的档位名（含「一等奖」等自定义名称）。按比例划线的考试同样按比例档位计算等级——报告在成绩发布后生成，届时全员分数已定，可计算。
- 未配置分数线规则的考试：维持现行固定映射表兜底。
- 通过判定：达到勾选「发放证书」的最低档 = 通过；其余情况（含命中未勾选「发放证书」的档位）= 未通过。
- 未达任何配置档的考生：报告等级固定显示「未通过」。
- 生成时机不变：成绩发布后异步生成，等级按生成时点的配置计算；之后运营修改配置不影响已生成报告（与 20260816 证书重新生成的快照先例一致）。

### 改动 2：证书配置新增报告文案字段

- 分数线配置的每个等级档新增两个可选字段：「成长区间」「一句话总结」；按分数划线、按比例划线两种模式都加。
- 命中档配置了文案 → 报告按配置展示；未配置 → 按兜底规则展示。
- 兜底规则：勾选「发放证书」的档位按分数线从高到低依次对齐固定表通过档（优秀·高阶表现 → 良好·熟练掌握 → 合格·目标达成，第 4 档起沿用合格）；未勾选「发放证书」的档位与未达线考生统一用「待提升」等级文案（成长区间取「稳步接近」）。
- 未达线考生无对应配置档，一句话总结恒用「待提升」固定文案，不提供配置入口。

### 改动 3：成长区间定位图按配置渲染

- 配置了分数线规则的考试：定位图阶段 = 「未通过」段 + 配置档升序，段名取该档「成长区间」配置（未配置按兜底规则取名）；各段等宽分布；考生标记点固定在命中段正中心。
- 未配置的考试：维持现行五段不等宽图（30%/30%/20%/10%/10%）。
- 图下文字说明考生所处区间；未达线考生说明「尚未达到最低等级线」。

## 四、与现有系统的边界

- 电子证书等级字段本就取同一套分数线规则，本需求落地后证书与报告等级同源，口径分叉消除。
- 28_证书实例管理字段映射、电子证书签发链路、签发中心不改动。
- 20260728 报告 PRD 的 5.1.3 固定映射表降级为「未配置考试的兜底逻辑」，由本需求新 PRD 覆盖（不改写原文）。
- 报告的其余模块（知识点掌握、考级具体表现、下一阶段建议、PDF 下载、入口与生成时机）不改动。

## 七、验收标准草案

1. 配置了分数线规则的考试，报告等级 = 命中档位名，与电子证书等级同源一致。
2. 未配置的考试，报告按固定映射表展示，与现行版本一致。
3. 未达最低配置档的考生等级显示「未通过」，通过状态为未通过。
4. 达到勾选「发放证书」的最低档 = 通过；命中未勾选档位的考生等级显示该档名、通过状态为未通过。
5. 配置了成长区间/一句话总结的档位，报告按配置展示；未配置的按兜底规则展示。
6. 按比例划线的考试，报告等级按比例档位计算（含同分同权归上一档规则）。
7. 已生成报告不随后续配置修改变化。
8. 15/17 配置页每档可填写成长区间与一句话总结，留空合法（走兜底）。
