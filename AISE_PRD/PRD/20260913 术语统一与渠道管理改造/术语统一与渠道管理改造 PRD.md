# AISE 术语统一与渠道管理改造 PRD

> 需求文件夹：20260913 术语统一与渠道管理改造 ｜ 2026-09-13 V1.0
> 讨论稿拍板：渠道侧=方案 A（只读）+ 单场测评编辑增强；「考生」→「学员」；旧「活动」→「测评」；文件重命名本轮完成
> 范围：除「活动管理改版」（20260912 文件夹）之外的全部外部改动

## 1. 背景与收益

平台此前把「活动」「测评」「测评」混用：65 个 demo 文件出现 465 处「测评」、141 处「考生」，同一实体在不同端叫法不一。同时旧渠道管理是「渠道选测评 + 渠道自建分组」的写入模式，与新的「活动 › 分组 › 测评 + 运营在矩阵关联」模型冲突。

本次统一术语（一律「测评」/「学员」）并改造渠道管理为「只读 + 单场编辑」定位：数据入口收敛到渠道关联矩阵，渠道侧保留查看与单场测评渠道侧配置的编辑能力。

## 2. 术语替换规则

| 原词 | 新词 | 范围 |
|---|---|---|
| 测评（实体/动作） | 测评 | 全部 demo 页面文案 |
| 考生 | 学员 | 全部 demo 页面文案 |
| 旧体系「活动」（03/04/05/14/15、user15） | 测评 | 与新「活动」实体区分 |
| 保留不动 | — | 监考、考级报告、准考证（职能/专有词）；新活动体系（32/33/35）的「活动」；官网营销活动（user 首页「挑战活动」等） |

## 4. 渠道管理改造（admin/02）

### 4.1 定位变更

| 维度 | 旧 | 新 |
|---|---|---|
| 数据入口 | 渠道在 02 页「关联新测评」自行写入 | 运营在「活动管理 → 渠道关联」矩阵统一关联 |
| 渠道自建分组 | 渠道内分组管理（新建/排序/删除） | 取消；分组为活动下全局结构 |
| 渠道侧能力 | 添加关联 + 编辑 | **查看**（三级树）+ **编辑单场测评的渠道侧配置** |

### 4.2 「关联测评管理」弹窗改造

| 区块 | 处理 |
|---|---|
| 顶部按钮 | 删「分组管理」「关联新测评」；右上角为蓝色「活动管理」跳转按钮，点击直达 32 活动管理列表页（渠道可能关联多个活动，不直接跳某活动的矩阵） |
| 筛选器 | 手动触发式（不即选即滤）：①活动下拉（默认全部活动）②分组下拉（初始禁用提示「先选活动」；选定活动后解锁，只列该活动下分组）③测评名称模糊搜索框 + 「筛选」按钮——条件选好后点击才按并集过滤 |
| 行内编辑 | 保留「编辑」：可改该测评在本渠道的报名费、展示时间（含永久）、前端展示开关、报名可见性（正常/隐藏+定向链接） |
| 副标题 | 仅「当前渠道：X」，不加说明文字 |
| 编辑弹窗 | 编辑测评配置弹窗已加宽加大（尺寸以 HTML demo 为准）；小字号统一升至可读、分区间距加大，配置项不再拥挤 |
| 弹窗与列宽 | 弹窗已加宽（尺寸以 HTML demo 为准）；列表列见下 |

列表列：

- 测评名称（含展示状态标签）。
- **活动名称** / 分组。
- 时间信息 / 报名费 / 报名（正常·隐藏）。
- 前端展示 / 操作。
- 已报名统计列已删（本页不展示统计数据）。
