# 证书模板迁移与实例选择 PRD

> 需求编号：20260921 ｜ 版本：V1.0 ｜ 状态：评审中
> 需求提出：张二红 ＋ Micheal（考务反馈，2026-09-21）
> 方案依据：[方案V1.md](方案V1.md)（Q1-Q5 已拍板，见拍板记录）

## 1. 背景与收益

需求简介：把 3 套写死在代码里的正式测证书迁入「证书模板管理」，创建测评时直接选证书实例，考后自动生成电子证书，运营零重复操作。

背景：AISE 电子证书存在两套并存逻辑。旧逻辑按测评身上的「证书模板」标签出证，3 套证书写死在代码里，无法自助调整。新逻辑（20260512 上线的证书模板三层模型：模板 → 实例 → 用户证书）支持模板化配置与重新生成，但正式测从未使用——每场测评考后都要手动建一次实例，10 月测评 17 个考场意味着重复操作 17 次，实际无人执行，测试环境所有测评的电子证书均为「未配置」。

业务诉求与收益：考务在创建测评时一步选好证书实例，考后电子证书自动生成，消除逐考场重复配置；3 套证书内容可在后台自助维护，不再依赖开发改代码；「测评证书管理」的电子证书配置状态恢复真实可用，漏配可兜底补配。

## 2. 业务流程

正式测新流程：

1. 运营在证书模板管理维护证书模板（含迁移后的 3 套证书），在证书实例管理创建可复用实例（绑定模板 + 字段映射）
2. 创建测评（单个新建或批量创建）时选择证书实例——一个实例可同时用于多场测评，批量创建选一次全部继承
3. 测评结束进入「待复核」环节，系统按所选实例自动生成电子证书
4. 测评证书管理页该测评电子证书列显示「已配置」；未选实例的测评显示「未配置」，考务可随时点「配置电子证书」弹窗补配

预备测流程不变：仍按渠道维度在证书实例管理一次性配置。

配套迁移：已打「证书模板」标签的存量测评，按「标签值 → 新模板」对应关系自动生成实例绑定并补齐配置；旧标签观察一个考期后退役。

## 3. 详细功能说明

### 3.1 证书模板迁移（3 套证书入模板管理）

| 项 | 说明 |
|---|---|
| 位置 | admin/26 证书模板管理 |
| 迁移对象 | 技术融合应用和创新实践评定证书、生成式人工智能等级证书、程序设计等级证书（原「证书模板」标签对应的 3 套写死证书） |
| 迁移要求 | 以线上现行证书为样式基准制作底图，迁为 3 个正式证书模板（启用状态），完成后测试环境与线上证书比对验收 |
| 标识 | 卡片带迁移来源提示：由旧「证书模板」标签体系迁移，字段随测评数据自动填充 |

### 3.2 模板编辑器支持业务字段

| 项 | 说明 |
|---|---|
| 位置 | admin/27 证书模板编辑器 |
| 新增可配置字段 | 年份、难度等级、参测模块、参测等级、编程语言 |
| 字段口径 | 模板只配置「哪些字段出现在证书上及位置样式」；字段值在出证时随测评数据自动填充（取测评身上的标签/配置），不写死在模板里 |
| 兼容 | 现有 6 个模板不受影响，编辑器字段面板新增上述 5 个字段拖拽项 |

### 3.3 证书实例升级为一对多复用

| 项 | 说明 |
|---|---|
| 位置 | admin/28 证书实例管理 |
| 模型调整 | 实例从「绑定单场测评」升级为「可复用的证书配置」：实例 = 模板 + 字段映射；参测人数、已签发数等运行数据按各测评分别记录 |
| 列表展示 | 表头改「实例名称 / ID」「实例类型」；新增「引用测评」列（显示当前被多少场测评使用）；顶部说明条注明实例可复用 |
| 禁用保护 | 实例被测评引用时禁用，提示「正在被 N 场测评引用，禁用后这些测评不再自动生成新电子证书（已有证书不受影响）」，建议先批量换绑 |
| 模板修改影响 | 沿用既有原则：模板编辑只影响之后新生成的证书，已签发证书不变 |

### 3.4 创建测评时选择证书实例

| 项 | 说明 |
|---|---|
| 位置 | admin/05 新建测评弹窗，「证书落款时间配置」上方；admin/33 活动详情批量创建向导第二步正式考配置区（文字描述，demo 未改） |
| 字段形态 | 独立下拉选择项「证书实例 (选填)」，默认「暂不选择 — 考后可在测评证书管理补配电子证书」 |
| 选项内容 | 全部启用状态的 AISE 测评类实例，格式「实例名（模板：模板名）」 |
| 选择反馈 | 选中后显示提示条：本测评结束后将自动生成对应电子证书 |
| 固定说明 | 字段下方常驻说明：选择后测评结束进入「待复核」环节自动生成电子证书；一个实例可同时用于多场测评 |
| 保存反馈 | 已选实例保存提示「电子证书将按所选实例在考后自动生成」；未选提示「未配置电子证书，考后可补配」 |
| 批量创建 | 向导第二步选一次实例，批量生成的全部考场继承同一实例；个别考场需要不同实例的，生成后在 33 活动详情行内编辑改选 |

### 3.5 测评证书管理弹窗式补配

| 项 | 说明 |
|---|---|
| 位置 | admin/14 测评证书管理，未配置行的「配置电子证书」按钮 |
| 弹窗交互 | 点击弹出勾选弹窗（不跳列表页）：标题下显示当前测评名；列表列出可复用实例（名称、编号、模板、适用说明），勾选一个点保存即完成配置 |
| 校验 | 未勾选点保存提示「请先勾选一个证书实例」；勾选实例与测评数据不匹配（模板必填字段无对应数据）时保存提示具体不匹配字段，不阻断其他测评配置 |
| 保存后 | 行内状态「未配置」→「已配置」，按钮变为「电子证书」，顶部轻提示确认 |
| 新建入口 | 弹窗底部「都不合适？新建证书实例」跳 28 新建向导，Step1 自动带入当前测评且不可更改，保存后自动回填绑定该测评 |
| 筛选保留 | 「所有电子证书 / 已配置 / 未配置」筛选沿用 |
| 出证时机 | 已配置的测评在「待复核」环节自动生成电子证书（与既有证书流转时机一致，考务可先复核） |

### 3.6 存量测评补绑与旧标签退役

| 项 | 说明 |
|---|---|
| 存量补绑 | 上线时按「标签值 → 迁移后模板」对应关系（技术融合应用和创新实践评定 / 生成式人工智能 / 程序设计一一对应），为已打标签的存量测评自动生成实例绑定并补齐电子证书配置 |
| 已出证书 | 存量测评已签发的证书不动、不重新生成；仅补配置状态显示 |
| 同时有标签和实例 | 以实例为准，忽略标签 |
| 旧标签退役 | 「证书模板」标签属性保留一个考期（历史数据兼容、检索不受影响），标签描述改为「已由证书模板管理接管」；观察一个考期后下线出证关联 |

|---|---|---|---|---|---|
| 1 | 迁移模板展示 | 完成迁移 | 查看证书模板管理 | 3 套证书成为启用模板，带迁移标识，样式与线上现行证书一致 | 逐张比对 |
| 2 | 模板新字段 | 打开模板编辑器 | 查看字段面板 | 新增年份/难度等级/参测模块/参测等级/编程语言 5 个拖拽字段 | 可拖入画布配置 |

| 5 | 考后自动出证 | 测评已选实例 | 测评流转至「待复核」 | 自动按实例模板生成电子证书 | 学生端可查 |
| 6 | 批量创建继承 | 活动详情批量创建 | 第二步选一个实例，批量生成 17 场 | 17 场全部继承该实例 | 逐场核对 |
| 7 | 弹窗补配 | 测评证书管理未配置行 | 点「配置电子证书」勾选实例保存 | 行内变「已配置」，出轻提示 | 状态与提示正确 |
| 8 | 弹窗未勾选 | 配置弹窗 | 直接点保存 | 提示「请先勾选一个证书实例」 | 不关闭弹窗 |

| 15 | 回归：预备测配置 | 预备测渠道维度配置 | 走既有预备测实例配置 | 流程与功能不变 | 全流程正常 |
| 16 | 回归：重新生成 | 模板调整后 | 28 行内重新生成 | 按新模板重出，编号日期不变 | 既有能力不变 |
