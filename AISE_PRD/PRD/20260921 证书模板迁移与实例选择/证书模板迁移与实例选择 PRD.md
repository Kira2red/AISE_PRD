# 证书模板迁移与实例选择 PRD

> 需求编号：20260921 ｜ 版本：V1.2 ｜ 状态：评审中（V1.2 按运营 2026-10-06 需求修订）
> 需求提出：张二红 ＋ Micheal（考务反馈，2026-09-21）
> 方案依据：[方案V1.md](方案V1.md)（Q1-Q5 已拍板，见拍板记录）

## 1. 背景与收益

需求简介：把 3 套写死在代码里的正式测证书迁入「证书模板管理」，创建测评时直接选证书实例，考后自动生成电子证书，运营零重复操作。

背景：AISE 电子证书存在两套并存逻辑。旧逻辑按测评身上的「证书模板」标签出证，3 套证书写死在代码里，无法自助调整。新逻辑（20260512 上线的证书模板三层模型：模板 → 实例 → 用户证书）支持模板化配置与重新生成，但正式测从未使用——每场测评考后都要手动建一次实例，10 月测评 17 个考场意味着重复操作 17 次，实际无人执行，测试环境所有测评的电子证书均为「未配置」。

业务诉求与收益：考务在创建测评时一步选好证书实例，考后电子证书自动生成，消除逐考场重复配置；3 套证书内容可在后台自助维护，不再依赖开发改代码；「测评证书管理」的电子证书配置状态恢复真实可用，漏配可兜底补配。

## 2. 业务流程

正式测新流程：

1. 运营在证书模板管理维护证书模板（含迁移后的 3 套证书）
2. 创建测评（单个新建或批量创建）时选择证书模板——保存后系统自动为每场测评创建各自的证书实例，批量创建选一次全部继承
3. 测评结束进入「待复核」环节，系统按实例自动生成电子证书
4. 测评证书管理页该测评电子证书列显示「已配置」；未选模板的测评显示「未配置」，考务可随时点「配置电子证书」弹窗勾选模板补配（保存时自动生成实例）

预备测流程不变：仍按渠道维度在证书实例管理一次性配置。

配套迁移：已打「证书模板」标签的存量测评，按「标签值 → 新模板」对应关系自动生成实例绑定并补齐配置；旧标签观察一个考期后退役。

## 3. 详细功能说明

### 3.1 证书模板迁移（3 套证书入模板管理）

| 项 | 说明 |
|---|---|
| 位置 | admin/26 证书模板管理 |
| 迁移对象 | 技术融合应用和创新实践评定证书、生成式人工智能等级证书、程序设计等级证书（原「证书模板」标签对应的 3 套写死证书） |
| 迁移要求 | 以线上现行证书为样式基准制作底图，迁为 3 个正式证书模板（启用状态），完成后测试环境与线上证书比对验收 |
| 标识 | 卡片带迁移来源提示：由旧「证书模板」标签体系迁移，字段随测评数据自动填充 |

### 3.2 模板编辑器支持业务字段

| 项 | 说明 |
|---|---|
| 位置 | admin/27 证书模板编辑器 |
| 新增可配置字段 | 年份、难度等级、参测模块、参测等级、编程语言 |
| 字段口径 | 模板只配置「哪些字段出现在证书上及位置样式」；字段值在出证时随测评数据自动填充（取测评身上的标签/配置），不写死在模板里 |
| 兼容 | 现有 6 个模板不受影响，编辑器字段面板新增上述 5 个字段拖拽项 |

### 3.3 创建测评自动生成证书实例

| 项 | 说明 |
|---|---|
| 模型口径 | 证书实例 = 测评 × 证书模板的绑定记录（沿用 20260512 定义）；一场测评选择一个证书模板后，系统自动为该测评创建证书实例 |
| 变化点 | 实例创建时机从「考后在 28 手动新建」提前到「创建测评时选择模板后自动生成」；实例的模型本身不变，参测人数、已签发数等数据仍归属各测评自己的实例 |
| 列表展示 | 28 列表沿用「测评名称 / ID」维度，新增「创建来源」标识：创建测评时生成 / 手动新建 |
| 禁用 | 实例归属单一测评，禁用沿用既有确认流程：该测评不再生成新证书，已有证书不受影响 |
| 模板修改影响 | 沿用既有原则：模板编辑只影响之后新生成的证书，已签发证书不变 |

### 3.4 创建测评时选择证书模板

| 项 | 说明 |
|---|---|
| 位置 | admin/05 新建测评弹窗，「证书落款时间配置」上方；admin/33 活动详情批量创建向导第二步正式考配置区 **（demo 已同步，本行红字）** |
| 字段形态 | 独立下拉选择项「证书模板 **(必选，红字)**」，默认「请选择证书模板」；**未选时不可保存/进入下一步，提示「请先选择证书模板」（红字新增）** |
| 选项内容 | 全部启用状态的证书模板，含适用说明（如：程序设计等级证书 · 适用于程序设计/编程语言类测评） |
| 选择反馈 | 选中后显示提示条：保存测评时将自动创建证书实例，考后自动生成电子证书 |
| 保存反馈 | 已选模板保存提示「已按所选证书模板自动创建证书实例」**；原「未选提示考后补配」半句删除（必选后无未选场景）（红字删除说明）** |
| 批量创建 | 向导第二步选一次模板，批量生成的全部考场各自自动创建实例（均绑定该模板）；个别考场需要不同模板的，生成后在 33 活动详情行内编辑改选 **；第二步原「标签」多选字段删除，由本必选下拉替代（红字新增）** |

### 3.5 测评证书管理弹窗式补配

| 项 | 说明 |
|---|---|
| 位置 | admin/14 测评证书管理，未配置行的「配置电子证书」按钮 |
| 弹窗交互 | 点击弹出勾选弹窗（不跳列表页）：标题下显示当前测评名；列表列出启用状态的证书模板（名称 + 适用说明），勾选一个点保存即完成为该测评自动创建证书实例并完成电子证书配置 |
| 校验 | 未勾选点保存提示「请先勾选一个证书模板」；勾选模板与测评数据不匹配（模板必填字段无对应数据）时保存提示具体不匹配字段，不阻断其他测评配置 |
| 保存后 | 行内状态「未配置」→「已配置」，按钮变为「电子证书」，顶部轻提示确认 |
| 新建入口 | 弹窗底部「都不合适？新建证书模板」跳 26/27 创建模板，创建后回到弹窗可继续勾选 |
| 筛选保留 | 「所有电子证书 / 已配置 / 未配置」筛选沿用 |
| 出证时机 | 已配置的测评在「待复核」环节自动生成电子证书（与既有证书流转时机一致，考务可先复核） |

### 3.6 存量测评补绑与旧标签退役

| 项 | 说明 |
|---|---|
| 存量补绑 | 上线时按「标签值 → 迁移后模板」对应关系（技术融合应用和创新实践评定 / 生成式人工智能 / 程序设计一一对应），为已打标签的存量测评自动生成实例绑定并补齐电子证书配置 |
| 已出证书 | 存量测评已签发的证书不动、不重新生成；仅补配置状态显示 |
| 同时有标签和实例 | 以实例为准，忽略标签 |
| 旧标签退役 | 「证书模板」标签属性保留一个考期（历史数据兼容、检索不受影响），标签描述改为「已由证书模板管理接管」；观察一个考期后下线出证关联 |
| 批量创建标签字段删除 **（V1.2 新增）** | admin/33 批量创建向导第二步原「标签」多选字段整行删除，出证关联改由「证书模板」必选下拉承担；新流程不再产生新的「证书模板」标签数据，旧标签仅存在于存量测评 |

| 1 | 迁移模板展示 | 完成迁移 | 查看证书模板管理 | 3 套证书成为启用模板，带迁移标识，样式与线上现行证书一致 | 逐张比对 |
| 2 | 模板新字段 | 打开模板编辑器 | 查看字段面板 | 新增年份/难度等级/参测模块/参测等级/编程语言 5 个拖拽字段 | 可拖入画布配置 |

| 4 | 不选实例保存 | 新建测评弹窗 | 实例留空保存 | 保存成功，提示可考后补配 | 无阻断 |
| 5 | 考后自动出证 | 测评已选模板（实例已生成） | 测评流转至「待复核」 | 自动按实例生成电子证书 | 学生端可查 |
| 6 | 批量创建继承 | 活动详情批量创建 | 第二步选一个模板，批量生成 17 场 | 17 场各自生成实例且绑定同一模板 | 逐场核对 |
| 7 | 弹窗补配 | 测评证书管理未配置行 | 点「配置电子证书」勾选模板保存 | 行内变「已配置」且自动生成实例，出轻提示 | 状态与提示正确 |
| 8 | 弹窗未勾选 | 配置弹窗 | 直接点保存 | 提示「请先勾选一个证书模板」 | 不关闭弹窗 |

| 13 | 已出证书不动 | 存量测评已签发证书 | 迁移后查看 | 证书不变，仅配置状态更新 | 无重新生成 |
| 14 | 批量创建各自出证 | 批量 17 场共用同一模板 | 各场测评到「待复核」 | 各自实例独立出证，数据分场记录 | 数据不串 |
| 15 | 回归：预备测配置 | 预备测渠道维度配置 | 走既有预备测实例配置 | 流程与功能不变 | 全流程正常 |
| 16 | 回归：重新生成 | 模板调整后 | 28 行内重新生成 | 按新模板重出，编号日期不变 | 既有能力不变 |
