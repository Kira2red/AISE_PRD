# 需求一：试卷锁定 + 复制试卷

## 1. 背景与收益

需求简介：给「考场+试卷」增加两级锁定、题目防误删、考后版本追溯与试卷复制能力，正式考场绑定的试卷从锁定起不可变，考后可追溯到考生作答时的题目版本。

业务诉求：录题老师来自不同渠道，只能改自己录入的题目，无法掌握题目是否被他人改动。
题目编辑权限含删除权，题库误删一批题目会直接传导到试卷和考场。
试卷关联考场后，考后改题会影响成绩、报告和证书划线。

收益：
- 考生作答时刻的题目内容由系统强制固定，成绩、报告、证书划线可精确追溯到作答时的版本。
- 被引用的题目和试卷删除被拦截，误删不再传导到考场。
- 出分后修改强制二次确认并全程留痕。
- 下期组卷直接复制旧卷迭代，缩短配置时间。

## 2. 业务流程

管理员在考场管理与题目编辑入口操作：

1. 教研组卷完成后创建考场审校，期间题目正常修改不受限。
2. 正式开考前，管理员对考场执行锁定。
3. 锁定生效时系统冻结试卷引用的题目版本，作为本场作答的追溯基线。
4. 锁定期间：试卷整体只读，考场不能换卷，考中作答与数据推送不受影响。
5. 考试结束、证书公示后，管理员解除锁定。
6. 解锁后修改已出分试卷的题目需二次确认，修改全程留痕。
7. 复制旧卷生成独立副本，修改副本作为下期新卷。

## 3. 详细功能说明

### 3.1 锁定模型

锁定分两级，两级同时生效：

- 试卷内容级：锁定对象是试卷实体（含题目）。
  - 题目按版本保存，每次保存生成新版本，版本内容不可变。
  - 试卷引用的是题目版本，组卷时即确定。
  - 试卷被任一已锁定考场引用即整体只读：任何入口不可改题、不可删题。
  - 同组织或跨组织共用该卷的其他考场同样不可改。
- 考场配置级：锁定对象是考场的试卷绑定。
  - 被锁定的考场不能更换试卷、不能调整本场试卷配置。
  - 未锁定的考场不受影响，仍可换绑其他试卷。

锁定同时是追溯基线的冻结点：锁定动作发生时，系统记录该试卷引用的全部题目版本（冻结清单），本场考试的作答按此版本追溯。

### 3.2 锁定范围与前置校验

- 锁定入口：考场列表的操作列提供「锁定」「解锁」，仅管理员可见。
- 锁定仅对考试类型为「正式考试」的考场开放；「练习」类型考场不提供锁定入口。
- 锁定前置校验：试卷内题目须全部为「审核通过」状态，存在未审核通过题目时拦截并提示题目清单，审核通过后可重新执行锁定。
- 允许对已开考、已交卷的考场补锁：锁定仅约束其后的修改，锁定动作如实记录冻结时间，已产生的作答与推送数据不受影响。
- 锁定确认弹窗写明锁定影响：试卷整体只读、本考场不能换卷、已产生的作答不受影响。
- 提交中：按钮置灰防重复点击，超时阈值 8 秒，超时提示「操作超时，请重试」。
- 操作失败：轻提示说明失败原因，按钮恢复可点击，考场状态保持原值。

### 3.3 共卷提示与一键同锁

- 触发：锁定某考场时，若其试卷还被其他未锁定的正式考试考场引用，弹窗列出这些考场（含创建人）。
- 选项：「一键同锁」与「仅锁当前考场」。
- 选择「仅锁当前考场」时，其余考场仍可换绑试卷，但试卷内容因实体级锁定仍整体只读。
- 关闭弹窗：点击「取消」或右上角关闭视同选择「仅锁当前考场」；点击遮罩层不关闭。
- 一键同锁对该卷引用的全部未锁定正式考试考场执行锁定，完成后轻提示锁定数量。
- 弹窗优先级：同一时刻仅存在一个业务弹窗。

### 3.4 改题与删除拦截

- 改题拦截：任何入口修改被锁定试卷的题目时阻止保存，提示「该题目已被考场【考场名】锁定，如需修改请联系管理员解除锁定」。
- 多锁定考场：同一试卷被多个锁定考场引用时，提示列出全部锁定考场名。
- 题目防误删：已被试卷或考场引用的题目，删除入口做引用校验并拦截，提示引用位置（哪些试卷、考场在用）；未被引用的题目允许删除。
- 引用校验范围：不区分试卷锁定状态，题目仅被未锁定试卷引用时同样拦截。
- 试卷删除：被任一考场引用的试卷不可删除，校验规则同上。
- 题目版本保留：被任何试卷引用过的历史版本在引用存在期间不可物理删除。

### 3.5 解锁与恢复

- 管理员可随时解除考场锁定。
- 解锁后该考场恢复可换绑试卷。
- 试卷是否恢复可编辑取决于是否仍被其他锁定考场引用：仍被引用时保持只读，详情展示引用中的锁定考场列表。
- 全部引用考场解除后试卷恢复可编辑，此后修改已出分试卷的题目走二次确认（见 3.7）。

### 3.6 考后追溯

- 考场绑定的试卷和题目完整保留，含考后归档。
- 题库后续修改或停用题目不影响已绑定考场的试卷内容：试卷引用的是锁定时冻结的版本。
- 追溯入口：答卷与考场详情提供「作答时版本」查看。
- 追溯内容：逐题展示作答时版本与当前版本；两者不一致时提供差异查看。
- 追溯仅作查看，不把作答时版本写回题目；需要复用时走复制试卷（见 3.8）。

### 3.7 出分后修改与留痕

- 触发：试卷已生成成绩、报告或证书划线后，用户在题目编辑页点击保存。
- 交互：先弹窗提示影响范围（已出成绩、已生成报告），确认后允许保存；取消则不保存。
- 已出的成绩、报告按作答时版本保持不变；修改从下一次引用开始生效。
- 留痕：全部题目修改均记录修改人、修改时间、改动字段、修改前后值（含锁定前的日常修改与出分后修改；锁定期间不可改，无留痕产生）。
- 可见范围：仅管理员可查，按题目维度检索。

### 3.8 复制试卷

- 入口：试卷管理列表，仅管理员可见。
- 副本内容：试卷结构、题目、选项、答案、解析、分值全部复制。
- 独立性：副本题目为新建实例，与原卷完全独立；改副本不影响原卷。
- 命名：「原试卷名-副本」+ 复制时间；记录复制来源。
- 锁定交互：锁定不影响复制；被锁的卷可复制副本迭代为下期新卷；副本不带锁定状态、无引用继承。
- 粒度：第一期仅整卷复制。

### 3.9 操作日志

- 每次锁定、解锁记录操作人与时间，日志不可编辑、不可删除。

### 3.10 权限与角色

| 角色 | 权限 |
|------|------|
| 管理员 | 锁定、解锁考场，复制任意试卷，组卷，查看题目修改留痕，查看锁定与解锁操作日志 |
| 老师 | 组卷、建考场审校；审校期间正常修改题目；无锁定、解锁、复制入口 |
| 题目录入 | 仅可录题、修改或删除自己录入的题目（删除受引用校验限制）；无组卷、复制试卷、锁定、解锁入口 |

# 需求二：题库文件夹分类

## 1. 背景与收益

需求简介：题库增加多级自定义文件夹与文件夹树侧栏，替代现有「所属题库」字段的两个固定选项，管理员按考期、等级等维度目录化管理题目，早期题目按目录两步定位。

业务诉求：题目全部堆在公共池里靠标签分类，语种越来越多混在一起，早期上传的题目基本找不到；题目量、渠道量继续增长后按标签检索已失效。
现有「所属题库」字段只有「默认题库」「我的题库」两个选项，无法承载目录化管理。

收益：分类从「两个固定选项加一堆标签」变为可自定义的目录结构，管理员按「10月考期 → 一级考试题目」这类层级归置题目，预期找旧题从按标签翻页变为按目录两步定位。

## 2. 业务流程

管理员在题库列表页：

1. 创建文件夹（可多级、自定义命名，如「10月考期 → 一级考试题目」）。
2. 选中题目归入文件夹，一道题可同时归入多个文件夹；存量题目按考期分批归类。
3. 通过文件夹树侧栏浏览，或按文件夹名搜索定位题目；组卷时题目仍从公共池选取。
4. 过期文件夹删除后，其中题目仅移除该归属、回到未归类状态，题目本身不删除。

## 3. 详细功能说明

### 3.1 文件夹模型

- 「所属题库」字段在本需求上线后由文件夹替代，题目录入表单与列表筛选中的「所属题库」字段移除。
- 题目的可见范围字段保持现状，与文件夹归属互不影响。
- 文件夹是归置位置，标签是题目属性，两者并存：归入文件夹的题目仍在公共池，标签筛选保持现状。
- 文件夹与题目为多对多归属关系：一道题可同时归入多个文件夹。

### 3.2 入口与可见性

- 入口：题库列表页左侧新增文件夹树侧栏，顶部提供「＋ 新建」。
- 文件夹树与全部管理入口（新建、改名、删除、归类）仅管理员可见。
- 普通账号（含题目录入角色）不展示目录树、不展示列表归属列，仅在公共池按标签检索。

### 3.3 文件夹管理

- 层级：支持多级子文件夹，层级不设上限；侧栏默认展开到二级。
- 命名：自定义命名，不绑定固定枚举（如「10月考期」「一级考试题目」）。
- 重名校验：同一父级下不允许同名文件夹，输入即提示「该层级下已存在同名文件夹」；不同父级下允许同名。
- 空文件夹：允许存在，侧栏显示题目数为 0。
- 计数：文件夹行尾数字为该文件夹下题目数，不含子文件夹。
- 删除叶子文件夹：题目仅移除该归属，回到未归类状态，题目本身不删除。
- 删除父文件夹：弹二次确认，写明连带删除的子文件夹数量与受影响题目数（按题目去重计）；确认后整棵子树删除，子树内题目全部回未归类、不删除。
- 多归属题目：一道题同时归属多个文件夹时，删除其中一个仅摘除该归属，其他归属保留。
- 明细见下：
  - 文件夹行内操作按钮（＋新建子级、改名、删除）按 3.6 的按钮配色规范着色。
  - 侧栏展开层级在本次会话内保持，刷新后回到默认展开到二级。

### 3.4 题目归类与多归属

- 归类：管理员在列表勾选题目后批量归入文件夹（可多选目标文件夹），单题归类在题目详情操作。
- 批量入口：未勾选题目时「归入文件夹」按钮置灰；勾选后按钮亮起并显示数量。
- 公共池：归入文件夹的题目仍出现在公共题库池子，不影响组卷从池子选题。
- 引用题归类：被试卷或考场引用的题目，归类、移出不受限制（仅改归属，不改题面）。
- 移出：题目移出文件夹后回到未归类状态，仍在公共池。

### 3.5 检索与展示

- 按文件夹浏览：点击侧栏文件夹，展示该文件夹下的题目；侧栏末尾提供「未归类」节点。
- 按文件夹名搜索：搜索词命中文件夹名时定位到该文件夹及其下题目。
- 全局搜索：按题目关键词搜索时多归属题目按题目去重展示一条。
- 归属标签：浏览某文件夹时，该卷题目优先显示「归属：当前文件夹名」，其余归属合并为「+N」，鼠标悬停展示完整归属路径。
- 未归类题目：归属标签显示「未归类」。
- 无结果：搜索无命中时列表区显示「未找到相关题目」，不清空侧栏树。
- 加载失败：列表区显示「加载失败」与重试入口，不清空已有数据。

### 3.6 操作按钮配色规范

- 普通操作按钮（＋、改名、编辑）：蓝字、浅蓝底、蓝描边，悬停加深。
- 删除类按钮：红字、浅红底、红描边，悬停变为红色实边。
- 适用目录树行内按钮与题目列表行内按钮，与其他后台模块按钮风格保持一致。

### 3.7 存量迁移

- 上线时将现有「默认题库」「我的题库」两个选项值各转为一个同名顶层文件夹，存量题目按原值自动归入。
- 后续细分归类由管理员按考期分批执行，仅使用本功能的归类能力，不修改题目内容。
