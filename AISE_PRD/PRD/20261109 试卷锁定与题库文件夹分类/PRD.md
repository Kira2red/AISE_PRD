# 需求一：考试题目快照 + 复制试卷

## 1. 背景与收益

需求简介：考试开始时系统自动保存考场试卷的题目快照，本场考试的成绩、报告、证书划线全部关联快照；题库原题后续怎么修改都不影响已考数据；考中或考后确需修正时，从考场内入口修改本场题目；支持复制试卷作为下期新卷。

业务诉求：录题老师来自不同渠道，只能改自己录入的题目，无法掌握题目是否被他人改动。
题目编辑权限含删除权，题库误删一批题目会直接传导到试卷和考场。
试卷关联考场后，考后改题会影响成绩、报告和证书划线。

收益：
- 追溯基线由系统在开考时刻自动建立，不依赖人工操作，永不遗漏。
- 题库题目自由迭代，考试数据稳定可追溯。
- 考中、考后发现题目问题时有专属修改入口，修改全程留痕。
- 下期组卷直接复制旧卷迭代，缩短配置时间。

## 2. 业务流程

1. 教研组卷完成后创建考场审校，期间题目正常修改不受限。
2. 考试开始时间到达，系统自动保存该考场试卷引用的全部题目版本，生成题目快照。
3. 考生作答、成绩、报告、证书划线全部基于本场快照。
4. 题库侧随时正常修改题目，已绑定与已考考场不受影响。
5. 考中或考后发现本场题目需要修正时，管理员从考场详情进入「修改本场题目」，仅修改本场考试的题目快照，修改留痕。
6. 复制旧卷生成独立副本，修改副本作为下期新卷。

## 3. 详细功能说明

### 3.1 考试题目快照

- 触发：考试开始时间到达，系统自动保存该考场试卷引用的全部题目版本，生成题目快照，无需任何人工操作。
- 一个考场一份快照，快照记录引用的题目版本与内容。
- 本场考试的作答数据、成绩、报告、证书划线全部关联本场快照。
- 快照生成后，题库原题的修改、停用不影响本场考试。
- 开考前修改的题目，按开考时刻的最新版本进入快照。
- 爱测评侧所有考场统一处理，不区分考试类型。

### 3.2 题库改题与删除拦截

- 题库题目随时可正常修改，任何考场已产生的考试数据不受影响。
- 题目防误删：已被试卷或考场引用的题目，删除入口做引用校验并拦截，提示引用位置（哪些试卷、考场在用）；未被引用的题目允许删除。
- 试卷删除：被任一考场引用的试卷不可删除，校验规则同上。
- 引用校验与考试是否开考无关，被引用即拦截。

### 3.3 考中与考后的本场题目修改

- 入口：考场列表「题目快照」进入本场试卷详情页，题目卡片内提供「修改本场题目」，仅管理员可见；题目管理列表不提供本场题目修改入口。
- 范围：仅修改本场考试题目快照中的单个题目，不回写题库原题，不影响其他考场。
- 触发确认：修改前弹窗提示影响范围（本场考试、可能涉及已作答考生），确认后生效。
- 已提交的作答按提交时的快照保持不变；修改从其后的作答开始生效。
- 适用场景：考中或考后发现本场题目存在错误需要修正，属于极少数情况的兜底能力。

### 3.4 题目修改留痕

- 题库侧全部题目修改记录修改人、修改时间、改动字段、修改前后值。
- 本场题目修改的留痕并入同一记录，额外记录所属考场，支持按题目与考场两个维度检索。
- 仅管理员可查。

### 3.5 考后追溯

- 考场绑定的试卷和题目快照完整保留，含考后归档。
- 追溯入口：考场列表「题目快照」进入本场试卷详情页，按试卷详情形态展示快照题目完整内容（题干、选项、答案等）。
- 追溯内容：题目卡片标注快照版本与题库当前版本，两者不一致时提示「本场成绩按快照计算」并可查看差异；页面支持隐藏答案。
- 追溯仅作查看，不把快照写回题库；需要复用时走复制试卷（见 3.6）。

### 3.6 复制试卷

- 入口：试卷管理列表，仅管理员可见。
- 副本内容：试卷结构、题目、选项、答案、解析、分值全部复制。
- 独立性：副本题目为新建实例，与原卷完全独立；改副本不影响原卷。
- 命名：「原试卷名-副本」+ 复制时间；记录复制来源。
- 快照交互：快照不影响复制；已产生快照的卷可复制副本迭代为下期新卷；副本为全新试卷，无引用继承。
- 粒度：第一期仅整卷复制。

### 3.7 权限与角色

| 角色 | 权限 |
|------|------|
| 管理员 | 查看作答时版本追溯、修改本场题目、复制任意试卷、组卷、查看题目修改留痕 |
| 老师 | 组卷、建考场审校；审校期间正常修改题目；无修改本场题目、复制试卷入口 |
| 题目录入 | 仅可录题、修改或删除自己录入的题目（删除受引用校验限制）；无组卷、复制试卷、修改本场题目入口 |

# 需求二：题库文件夹分类

## 1. 背景与收益

需求简介：题库增加多级自定义文件夹与文件夹树侧栏，替代现有「所属题库」字段的两个固定选项，管理员按考期、等级等维度目录化管理题目，早期题目按目录两步定位。

业务诉求：题目全部堆在公共池里靠标签分类，语种越来越多混在一起，早期上传的题目基本找不到；题目量、渠道量继续增长后按标签检索已失效。
现有「所属题库」字段只有「默认题库」「我的题库」「AISE题库」三个固定选项，无法承载目录化管理。

收益：分类从「两个固定选项加一堆标签」变为可自定义的目录结构，管理员按「10月考期 → 一级考试题目」这类层级归置题目，预期找旧题从按标签翻页变为按目录两步定位。

## 2. 业务流程

管理员在题目管理页：

1. 创建文件夹（可多级、自定义命名，如「10月考期 → 一级考试题目」）。
2. 选中题目归入文件夹，一道题可同时归入多个文件夹；存量题目按考期分批归类。
3. 通过文件夹树侧栏浏览，或按文件夹名搜索定位题目；组卷时题目仍从公共池选取。
4. 过期文件夹删除后，其中题目仅移除该归属、回到未归类状态，题目本身不删除。

## 3. 详细功能说明

### 3.1 文件夹模型

- 「所属题库」字段在本需求上线后由文件夹替代，题目录入表单与列表筛选中的「所属题库」字段移除。
- 题目的可见范围字段保持现状，与文件夹归属互不影响。
- 文件夹是归置位置，标签是题目属性，两者并存：归入文件夹的题目仍在公共池，标签筛选保持现状。
- 文件夹与题目为多对多归属关系：一道题可同时归入多个文件夹。

### 3.2 入口与可见性

- 入口：题目管理页（题干预览列表形态，每题展示题干预览、题型、编程语言、知识标签、可见范围、出题人）左侧新增文件夹树侧栏，顶部提供「＋ 新建」。
- 文件夹树与全部管理入口（新建、改名、删除、归类）仅管理员可见。
- 普通账号（含题目录入角色）不展示目录树、不展示列表归属列，仅在公共池按标签检索。

### 3.3 文件夹管理

- 层级：支持多级子文件夹，层级不设上限；侧栏默认展开到二级。
- 命名：自定义命名，不绑定固定枚举（如「10月考期」「一级考试题目」）。
- 重名校验：同一父级下不允许同名文件夹，输入即提示「该层级下已存在同名文件夹」；不同父级下允许同名。
- 空文件夹：允许存在，侧栏显示题目数为 0。
- 计数：文件夹行尾数字为该文件夹下题目数，不含子文件夹。
- 删除叶子文件夹：题目仅移除该归属，回到未归类状态，题目本身不删除。
- 删除父文件夹：弹二次确认，写明连带删除的子文件夹数量与受影响题目数（按题目去重计）；确认后整棵子树删除，子树内题目全部回未归类、不删除。
- 多归属题目：一道题同时归属多个文件夹时，删除其中一个仅摘除该归属，其他归属保留。
- 明细见下：
  - 文件夹行内操作按钮（＋新建子级、改名、删除）按 3.6 的按钮配色规范着色。
  - 侧栏展开层级在本次会话内保持，刷新后回到默认展开到二级。

### 3.4 题目归类与多归属

- 归类：管理员在列表勾选题目后批量归入文件夹（可多选目标文件夹），单题归类在题目详情操作。
- 批量入口：未勾选题目时「归入文件夹」按钮置灰；勾选后按钮亮起并显示数量。
- 公共池：归入文件夹的题目仍出现在公共题库池子，不影响组卷从池子选题。
- 引用题归类：被试卷或考场引用的题目，归类、移出不受限制（仅改归属，不改题面）。
- 移出：题目移出文件夹后回到未归类状态，仍在公共池。

### 3.5 检索与展示

- 按文件夹浏览：点击侧栏文件夹，展示该文件夹下的题目；侧栏末尾提供「未归类」节点。
- 按文件夹名搜索：搜索词命中文件夹名时定位到该文件夹及其下题目。
- 全局搜索：按题目关键词搜索时多归属题目按题目去重展示一条。
- 归属标签：浏览某文件夹时，该卷题目优先显示「归属：当前文件夹名」，其余归属合并为「+N」，鼠标悬停展示完整归属路径。
- 未归类题目：归属标签显示「未归类」。
- 无结果：搜索无命中时列表区显示「未找到相关题目」，不清空侧栏树。
- 加载失败：列表区显示「加载失败」与重试入口，不清空已有数据。

### 3.6 操作按钮配色规范

- 普通操作按钮（＋、改名、编辑）：蓝字、浅蓝底、蓝描边，悬停加深。
- 删除类按钮：红字、浅红底、红描边，悬停变为红色实边。
- 适用目录树行内按钮与题目列表行内按钮，与其他后台模块按钮风格保持一致。

### 3.7 存量迁移

- 上线时将现有「默认题库」「我的题库」「AISE题库」三个选项值各转为一个同名顶层文件夹，存量题目按原值自动归入。
- 后续细分归类由管理员按考期分批执行，仅使用本功能的归类能力，不修改题目内容。
