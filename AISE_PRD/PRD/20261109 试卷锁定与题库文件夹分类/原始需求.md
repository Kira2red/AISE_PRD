需求一：试卷锁定 + 复制试卷
1. 背景与收益
需求简介：管理后台给「考场+试卷」增加两级锁定、题目防误删、考场试卷保留与试卷复制能力，正式考场绑定的试卷从锁定起不可变，考后可还原到作答时的题目版本。
业务诉求与收益：层级是活动 → 多个分组 → 每个分组下多个考场，同一分组下的多个考场可能共用一份试卷。录题老师来自不同渠道，只能改自己录入的题目，无法掌握题目是否被他人改动；题目编辑权限目前含删除权，题库一旦误删一批题目会直接传导到试卷和考场；试卷关联考场后，考后改题会影响成绩、报告甚至证书划线。本需求把「题目版本」从口头确认变为系统强制：锁定后考中改题事件为 0；考后可按作答时版本还原，成绩、报告、证书划线可追溯；被引用题目删除被拦截；出分后修改强制二次确认并留痕；下期组卷可直接复制旧卷迭代，缩短配置时间。
2. 业务流程
管理员在考场管理与题目编辑入口：
教研组卷完成后创建测试考场审校，期间题目正常修改不受限
正式开考前，管理员对「考场+试卷」执行锁定（单考场手动锁 / 按分组一键锁）；共卷的其他考场在锁定时获得同锁提示
锁定生效：该试卷（含题目）整体只读，该考场不能换卷；考中作答与数据推送不受影响
考试结束、证书公示后管理员解除锁定；修改已出分试卷的题目需二次确认并留痕
老师复制旧卷生成独立副本，修改副本作为下期新卷
3. 详细功能说明
3.1 权限与角色


角色

权限

管理员

锁定 / 解锁考场、按分组一键锁定、复制任意试卷、组卷、查看题目修改留痕、查看锁定与解锁操作日志

教研老师

组卷、建测试考场审校；审校期间正常修改题目

录题老师

仅可录题、修改 / 删除自己录入的题目（删除受引用校验限制）；无组卷、复制试卷、锁定 / 解锁入口
3.2 锁定模型


级别

锁定对象

生效范围

试卷内容级

试卷实体（含题目）

一份试卷被任一已锁定考场引用即整体只读：任何入口不可改题、不可删题；同分组或跨分组共用该卷的其他考场同样不可改

考场配置级

考场的试卷绑定

被锁定的考场不能更换试卷、不能调整本场试卷配置；未锁定的考场不受影响，仍可换绑其他试卷
3.3 锁定入口与分组一键锁定


变更项

说明

入口

考场列表与考场详情页提供「锁定本考场」「按分组一键锁定」「解除锁定」，仅管理员可见

单考场锁定

点击后该考场进入已锁定状态，触发 3.2 两级生效

分组一键锁定

对该分组下全部已绑定试卷的考场逐个执行锁定

组内未绑卷考场

弹窗列出未绑定试卷的考场，提供「去绑定」（跳转绑定页）与「跳过并锁定其余考场」两个选项，不默认拦截

锁定不回溯

对已开考、已交卷的考场执行锁定仅约束其后的修改，不影响已产生的作答与推送数据

操作日志

每次锁定 / 解锁记录操作人与时间，日志不可编辑、不可删除

提交中

按钮置灰防重复点击，超时阈值 8 秒，超时提示「操作超时，请重试」

操作失败

轻提示说明失败原因，按钮恢复可点击，考场状态保持原值
3.4 共卷提示与一键同锁


变更项

说明

触发

锁定某考场时，若其试卷还被其他未锁定考场引用，弹窗列出这些考场（含所属分组）

选项

支持「一键同锁」与「仅锁当前考场」；选择「仅锁当前考场」时，其余考场仍可换绑试卷，但试卷内容因实体级锁定仍整体只读

关闭弹窗

点击「取消」或右上角关闭视同选择「仅锁当前考场」；点击遮罩层不关闭

弹窗优先级

同一时刻仅存在一个业务弹窗
3.5 改题与删除拦截


变更项

说明

改题拦截

任何入口修改被锁定试卷的题目时阻止保存，提示「该题目已被考场【考场名】锁定，如需修改请联系管理员解除锁定」

多锁定考场

同一试卷被多个锁定考场引用时，提示列出全部锁定考场名

题目防误删

已被试卷或考场引用的题目，删除入口做引用校验并拦截，提示引用位置（哪些试卷 / 考场在用）；未被引用的题目允许删除

删除权口径

维持现状：编辑权限含删除权，不拆分、不做软删除，误删风险由引用校验兜底

试卷实体删除

被任一考场引用的试卷不可删除，校验规则同上

引用校验范围

不区分试卷锁定状态：题目仅被未锁定试卷引用时同样拦截删除
3.6 解锁与恢复


变更项

说明

触发

管理员可随时解除考场锁定

恢复范围

解锁后该考场恢复可换绑试卷；其试卷是否恢复可编辑取决于是否仍被其他锁定考场引用

保持只读

仍被引用时保持只读，详情展示引用中的锁定考场列表

全部解除

全部引用考场解除后试卷恢复可编辑，此后修改已出分试卷的题目走 3.7 二次确认
3.7 出分后修改二次确认


变更项

说明

触发

试卷已生成成绩、报告或证书划线后，用户在题目编辑页点击保存

交互

先弹窗提示影响范围（已出成绩 / 已生成报告），确认后允许保存；取消则不保存

留痕

每次出分后修改记录修改人、时间、改动字段，并入 3.10 题目修改留痕
3.8 考场试卷与题目保留


变更项

说明

保留范围

考场绑定的试卷和题目完整保留，含考后归档

题库侧变更

题库后续修改或停用题目，不影响已绑定考场的试卷内容

考后还原

按作答时的题目版本还原试卷，用于成绩、报告、证书划线追溯
3.9 复制试卷


变更项

说明

副本内容

试卷结构、题目、选项、答案、解析、分值、标签全部复制

独立性

副本题目为新建实例，与原卷完全独立；改副本不影响原卷

命名

「原试卷名-副本」+ 复制时间；记录复制来源

权限

管理员可复制全部试卷；教研 / 录题老师不可复制

锁定交互

锁定不影响复制；被锁的卷可复制副本迭代为下期新卷；副本不带锁定状态、无引用继承

副本再操作

副本的锁定、复制规则与原卷一致，来源链可追溯

粒度

第一期仅整卷复制；跨卷选题组卷列为二期候选
3.10 题目修改留痕


变更项

说明

记录内容

修改人、修改时间、改动的题目与字段、修改前后的值

覆盖范围

锁定前的修改与出分后修改均留痕；锁定期间不可改，无留痕产生

可见范围

仅管理员可查，按题目维度检索；录题老师不可见

4. 验收标准
验收项 ｜ 期望结果
验收项: 单考场锁定；期望结果: 考场显示已锁定，试卷整体只读，操作日志新增一条
验收项: 共卷实体级只读；期望结果: 考场A 已锁、考场B 未锁共用试卷A，录题老师改试卷A 任一题目被拦截并提示锁定考场名
验收项: 仅锁当前考场；期望结果: 其余引用考场仍可换绑试卷，但试卷题目不可改
验收项: 一键同锁；期望结果: 引用该卷的全部考场同时进入已锁定状态
验收项: 分组一键锁遇未绑卷考场；期望结果: 弹窗列出该考场，提供「去绑定」与「跳过并锁定其余考场」，其余考场正常锁定
验收项: 解锁后仍被引用；期望结果: 解锁考场可换绑，试卷保持只读并展示引用中的锁定考场列表
验收项: 引用题删除拦截；期望结果: 被试卷引用的题目删除被拦截并提示引用位置，未锁定试卷同样拦截
验收项: 未引用题删除；期望结果: 未被任何试卷引用的题目删除成功并轻提示
验收项: 出分后修改二次确认；期望结果: 先弹影响范围提示，确认后保存成功且留痕新增，取消不保存
验收项: 复制试卷；期望结果: 生成「原卷名-副本+时间」，题目为新建实例、不带锁定状态，来源记录正确
验收项: 录题老师权限边界；期望结果: 无复制试卷与锁定 / 解锁入口，仅可编辑 / 删除自己录入且未被引用的题目
验收项: 操作日志不可篡改；期望结果: 日志仅可查看，无编辑 / 删除入口
验收项: 回归考中作答；期望结果: 已锁定考场正常开考，作答与数据推送不受影响

需求二：题库文件夹分类
1. 背景与收益
需求简介：题库增加多级自定义文件夹与文件夹树侧栏，管理员按考期、等级等维度目录化管理题目，早期题目按目录两步定位。
业务诉求与收益：题目全部堆在题库池子里靠标签分类，语种越来越多混在一起，早期上传的题目基本找不到；题目量、渠道量继续增长后按标签检索已失效。文件夹把分类从「一堆标签」变为可自定义的目录结构，管理员按「10月考期 → 一级考试题目」这类层级归置题目，归入文件夹的题目仍在公共池，不影响组卷选题；预期管理员找旧题从按标签翻页变为按目录两步定位，存量题目可按考期分批归位。
2. 业务流程
管理员在题库列表页：
创建文件夹（可多级、自定义命名，如「10月考期 → 一级考试题目」）
选中题目归入文件夹，一道题可同时归入多个文件夹；存量题目按考期分批归类
通过文件夹树侧栏浏览，或按文件夹名搜索定位题目；组卷时题目仍从公共池选取
过期文件夹删除后，其中题目仅移除该文件夹属性、回到未归类状态，题目本身不删除

3.1 入口与可见性


变更项

说明

3.2 文件夹管理


变更项

说明

层级

支持多级子文件夹，层级不设上限；侧栏支持折叠，默认展开到二级

命名

自定义命名，不绑定固定渠道枚举（如「10月考期」「一级考试题目」）

重名校验

同一父级下不允许同名文件夹，输入即提示「该层级下已存在同名文件夹」；不同父级下允许同名

空文件夹

允许存在，侧栏显示题目数为 0

计数

文件夹行尾数字为该文件夹下题目数，不含子文件夹
明细见下：

3.3 文件夹删除


变更项

说明

删除叶子文件夹

题目仅移除该文件夹属性，回到未归类状态，题目本身不删除

删除父文件夹

弹二次确认，写明将连带删除的子文件夹数量与受影响题目数；确认后整棵子树删除，子树内题目全部回未归类、不删除

多归属题目

一道题同时归属多个文件夹时，删除其中一个仅摘除该归属，其他归属保留

取消

点击「取消」或右上角关闭不执行删除
3.4 题目归类与多归属


变更项

说明

归类

管理员选中题目后归入文件夹，一道题可同时归入多个文件夹

公共池

归入文件夹的题目仍出现在公共题库池子，不影响组卷从池子选题

引用题归类

被试卷或考场引用的题目，归类 / 移动不受限制（仅改分类属性，不改题面）

移出

题目移出文件夹后回到未归类状态，仍在公共池
3.5 检索与展示


变更项

说明

按文件夹浏览

按文件夹名搜索

支持按文件夹名称定位文件夹及其下题目

全局搜索多归属

按题目去重展示一条，总数按去重计，避免组卷重复计数

归属标签

优先展示当前正在浏览的文件夹名（如选中「一级考试题目」时显示「归属：一级考试题目」）；其余归属合并为「+N」，鼠标悬停展示完整归属路径

未归类题目

归属标签显示「未归类」

无结果

搜索无命中时列表区显示「未找到相关题目」，不清空侧栏树

加载失败

列表区显示「加载失败 + 重试」，不清空已有数据
3.6 存量题目迁移


变更项

说明

执行人

节奏
