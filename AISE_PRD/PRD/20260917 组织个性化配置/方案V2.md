## 1. 背景与目标

爱测评各组织（如人大）要求学生端按组织展示自己的品牌：登录页换 logo/插画/背景、首页"公告"栏目改名（如"证书查询"）并配二维码。这些配置全部集中到「运营位管理」，运营在一个页面维护一个组织的全部展示项。

## 2. 改动清单

### 改动一：运营位基础信息区新增「永久显示」开关

- 位置：新增/编辑弹窗「运营位基础信息」区，开启时间/结束时间上方
- 关（默认）：沿用现状，起止时间必填、到期失效
- 开：起止时间置灰、免填免校验，配置永久生效
- 列表「当前状态」列：永久显示 → 「永久有效」（不受时间影响）

控件规则：

- 内容列按类型切换：图片类型 → 文件上传（JPG/PNG ≤10M）；文本类型 → 输入框（≤10 字）
- 跳转链接列：皮肤类类型（插画/背景/组织图标/二维码/公告名称）不适用，隐藏；logo 类可选填（点 logo 跳转）
- 原有类型（右下豆腐块、顶栏横幅、banner、金刚位、弹窗、小红点）全部不动

### 改动三：列表新增「停止 / 启用」操作

- 位置：列表行操作列（编辑/更多 旁）
- 停止：该条配置立即失效，学生端回落平台默认；状态列显示「已停止」
- 再点「启用」：恢复按原规则（永久有效 / 按起止时间）生效
- 场景：组织换肤、临时活动下线，不用删配置

## 3. 生效与回落规则

1. 学生端按组织域名定位组织 → 取该组织各类型下**当前生效**的记录展示
2. 某类型无生效记录 → 该项回落平台默认（不强制全配）
3. 同类型多条生效记录冲突 → 取最近更新的（默认处理，见待确认 3）
4. 一条记录添加多个组织 → 这些组织共用同一套配置（沿用现有"添加组织"多选能力）

## 4. 核心流程

1. 运营进「运营位管理」→ 新增
2. 打开「永久显示」（品牌皮肤类均为常态配置）→ 添加组织（如人大）→ 逐行选类型传图/填名 → 确定
3. 该组织学生端登录页/首页按配置展示
4. 临时运营（节日活动二维码）：不开启永久显示，按起止时间自动上下线
5. 换肤/下线：列表行点「停止」，立即回落默认

## 5. 边界与异常

- 永久显示开启后关闭：起止时间恢复必填校验，原值带出可改
- 公告名称清空保存 → 视为未配置，回落「公告」
- 公告名称超 10 字 → 输入时拦截
- 停止的记录再编辑 → 保存后保持「已停止」，需手动启用（防误生效）
- 组织删除 → 其运营位记录保留，学生端无访问入口自然失效
- 存量 6 条已过期记录：不受影响，逻辑不变

## 6. 成功度量

- 后台可统计：完成个性化配置的组织数（预期初期 ≥3 个，假设值）
- 验收用例：按域名访问学生端，登录页 5 项 + 首页 3 项按配置展示；停止后回落默认；永久显示记录跨过结束时间仍展示

## 7. 风险与依赖

- 学生端（爱测评 user 端）渲染改造依赖前端排期，本需求后台侧只做配置存储与下发
- 皮肤类配置混入运营位列表后，列表会变长：靠「组织」筛选列（现有）+ 类型区分，可接受
- 历史类型「学生端-首页-公告」改名后，存量数据兼容（类型码不变，仅显示名变）
