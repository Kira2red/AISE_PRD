# 爱测评 运营位管理与组织个性化配置

> 需求文件夹：PRD/20260917 组织个性化配置
> 页面 demo：[29_运营位管理.html](<../../html/iceping_admin/29_运营位管理.html>)（爱测评运营管理端，样式与交互以 demo 为准）
> 决策依据：[方案V2.md](<方案V2.md>)（含逐项拍板记录，2026-09-17）+ 测试后台实测（test.iceping.org.cn:8888，2026-09-17）

## 1. 背景与收益

爱测评各组织（如人大附中）要求学生端展示自有品牌：登录页替换 logo、插画与背景图，首页"公告"栏目改名（如"证书查询"）并展示组织二维码。本需求将组织个性化配置与原有运营位能力统一收口到「运营位管理」，运营在一个页面即可维护一个组织的全部展示项，并为运营位补充永久显示、停止/启用两项长效管控能力。

## 2. 业务流程

1. 运营进入爱测评运营管理端「运营位管理」页面
2. 点击「新增」：开启「永久显示」开关（品牌皮肤类常态配置）→ 添加组织 → 逐行选择运营位类型、上传图片或填写名称 → 确定
3. 学生端按组织域名读取当前生效配置，展示对应品牌皮肤
4. 临时活动类配置（节日二维码等）：保持永久显示关闭，按起止时间自动上下线
5. 换肤或下线：在列表行点击「停止」，配置立即失效、学生端回落平台默认；点击「启用」按原规则恢复

## 3. 详细功能说明

### 3.1 运营位列表

| 项目 | 说明 |
|------|------|
| 筛选区 | 运营位ID、组织名称两个输入框 + 查询/重置按钮 |
| 表格列 | 序号、运营位ID、组织名称、开启时间、结束时间、当前状态、操作人、操作 |
| 操作列 | 编辑、停止/启用（直接露出，按当前状态切换文案）、更多 |
| 分页 | 默认 10 条/页 |

当前状态取值与判定规则：

| 状态 | 标签色 | 判定规则（按优先级从高到低） |
|------|--------|------|
| 已停止 | 红色 | 运营手动点了「停止」 |
| 永久有效 | 蓝色 | 永久显示开关开启，且未被停止 |
| 未开始 | 橙色 | 当前时间早于开启时间 |
| 已过期 | 灰色 | 当前时间晚于结束时间 |
| 生效中 | 绿色 | 当前时间在起止时间内 |

时间列展示规则：

- 永久显示开启的记录，开启/结束时间列显示"—（永久显示）"
- 其余记录显示实际起止时间

### 3.2 新增/编辑弹窗

弹窗分三个分节（分节标题带蓝色下划线，样式同 demo）。

**分节一：运营位基础信息**

| 字段 | 控件 | 规则 |
|------|------|------|
| 运营位ID | 只读文本 | 新增时显示"系统自动生成"，编辑时显示实际ID |
| 永久显示 | 开关（默认关闭） | 开启后：起止时间输入框置灰、免填免校验，配置长期生效；关闭后：起止时间恢复必填校验，编辑时原值带出可改 |
| 开启时间 | 日期时间选择 | 永久显示开启时免填；关闭时必填，未填提交时报"请选择开启时间！" |
| 结束时间 | 日期时间选择 | 同上 |

**分节二：组织管理**

| 字段 | 控件 | 规则 |
|------|------|------|
| 添加组织 | 按钮 + 组织下拉列表 | 必填；可添加多个组织（一条记录被多个组织共用）；已添加组织显示为带「×」的小标签，可逐个移除；未添加提交时报"请添加组织！" |

**分节三：运营位配置**

表格行结构：序号、运营位类型、运营位内容、跳转链接、运营位说明、操作（删除）。

- 点击「添加运营位配置」追加一行
- 内容控件随类型联动（见 3.3）
- 至少配置一行并选择类型后才可提交，否则报"请至少添加一条运营位配置并选择类型！"

### 3.3 运营位类型与内容控件

新增学生端个性化类型 8 个，原有类型保持不变，类型下拉共 21 项。

**新增类型（本需求核心）：**

| 运营位类型 | 内容控件 | 跳转链接 | 说明 |
|------|------|------|------|
| 学生端 - 登录页 - logo | 图片上传 | 选填 | 登录页左上角品牌标识，可配置点击跳转 |
| 学生端 - 登录页 - 小图1 | 图片上传 | 隐藏 | 登录卡片顶部插画 |
| 学生端 - 登录页 - 小图2 | 图片上传 | 隐藏 | 登录卡片右侧插画 |
| 学生端 - 登录页 - 背景图 | 图片上传 | 隐藏 | 登录页整页背景 |
| 学生端 - 首页 - logo | 图片上传 | 选填 | 登录后首页导航栏品牌标识 |
| 学生端 - 首页 - 公告名称 | 文本输入（限10字） | 隐藏 | 首页"公告"栏目标题，如"证书查询"；清空保存按未配置处理，回落显示"公告" |
| 学生端 - 首页 - 二维码 | 图片上传 | 隐藏 | 首页公告卡片内的二维码图（原「学生端 - 首页 - 公告」类型更名，存量配置自动沿用） |
| 学生端 - 组织图标 | 图片上传 | 隐藏 | 组织品牌图标 |

**原有类型（保持不变）：**

学生端 - 首页 - 右下豆腐块、顶栏横幅、banner；教师端 - 首页 - 左金刚位、右金刚位、弹窗；高级组织 - 首页 - 右金刚位；教师端 - 小红点 - 题目管理/试卷管理/考试管理/班级管理/学生管理/日常作业。

**内容控件联动规则：**

| 类型内容形态 | 控件表现 |
|------|------|
| 图片类 | 虚线框上传控件，点击选择文件；上传限制 JPG/PNG，不超过 10M；各类型的具体尺寸要求显示在"运营位说明"列（如豆腐块 16:9、banner 宽1400像素、顶栏横幅高34像素等，沿用现有口径） |
| 文本类（公告名称） | 文本输入框，实时显示已输入字数（0/10），最多 10 字 |
| 富文本类（教师端弹窗） | "编辑内容"按钮 |
| 小红点类 | 长期显示/单次显示单选 |

**跳转链接列规则：**

- 皮肤类（小图/背景/组织图标/二维码/公告名称）：该列显示"—"，该类内容为纯展示图，无需配置跳转
- logo 类与运营内容类（豆腐块/横幅/banner/金刚位）：显示输入框，选填

### 3.4 生效与回落规则

1. 学生端按组织域名定位组织，取该组织各类型下当前生效的记录展示
2. 某类型无生效记录时，该项回落平台默认（不强制组织全量配置）
3. 同一组织同一类型存在多条生效记录时，取最近更新的一条优先展示
4. 一条记录添加多个组织时，这些组织共用同一套配置
5. 「停止」立即生效：学生端读取时点起回落平台默认；「启用」后按原规则（永久有效或按起止时间）恢复

### 3.5 组织管理弹窗

组织管理的编辑弹窗字段：组织名、域名、组织状态、组织类型、子组织、所属地区。

组织图标统一在运营位管理中按「学生端 - 组织图标」类型配置（见 3.3）。
