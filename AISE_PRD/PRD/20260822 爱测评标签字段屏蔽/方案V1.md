# 产品方案 V1 — 爱测评平台 AISE 组织后台「标签」字段屏蔽

> 涉及仓库：~/Documents/AISE_PRD/AISE_PRD

## 一、背景与目标

**一句话**：在爱测评平台中，针对 AISE 组织后台（爱测评视角下 AISE 为特殊学校组织），屏蔽爱测评原生的「标签」字段展示，AISE 运营在录入/编辑题目时只看到 AISE 知识标签体系的「知识标签」。

**为什么**：AISE 知识标签体系（一级模块 → 二级知识点 → 三级标签）已建设并落地于题目录入（admin/09「知识点标签」、admin/31 知识标签管理树）。但 AISE 复用的爱测评平台（iceping 端）出题界面同时存在爱测评原生「标签」字段（自由标签，如"高频""2024秋招"）。两个「标签」并存，AISE 运营录题时容易混淆、误填爱测评标签，导致 AISE 题库题目挂上非知识体系的标签，污染报告知识点掌握度统计口径。

**期望效果**：AISE 组织后台录题时只呈现「知识标签」，杜绝双标签并存；非 AISE 组织不受影响。

|---|---------|---------|

| 2 | 作为 AISE 运营，我在爱测评题目列表页筛选/查看题目时，看不到「标签」筛选和「标签」列，列表维度与录题维度一致 | D（用户直接反馈） |
| 3 | 作为爱测评其他组织（非 AISE 学校/机构）的运营，我的录题界面保持原样，「标签」字段照常可用 | D（用户直接反馈） |

## 三、功能清单

| # | 功能 | 优先级 | 价值依据 | 说明 |
|---|------|--------|---------|------|
| 1 | 录入/编辑题目表单屏蔽「标签」输入 | P0 | D | 仅 AISE 组织生效；「知识标签」字段保留展示 |
| 2 | 题目列表页屏蔽「标签」筛选控件 | P0 | D | 仅 AISE 组织生效 |
| 3 | 题目列表页屏蔽表格「标签」列 | P0 | D | 仅 AISE 组织生效 |
| 4 | 「知识标签」字段在爱测评录题界面呈现 | P0 | D | 形态以阶段二 demo 确认（chips 输入 or 知识树选择） |
| 5 | 组织维度控制（仅 AISE 生效） | P0 | D | 后端按组织身份控制字段可见性，非纯前端隐藏 |

**不做**：
- 不清除、不迁移已录题目的「标签」历史数据（数据保留，仅界面屏蔽）
- 不改「所属知识点」字段（爱测评原生字段，非本次范围）
- 不影响非 AISE 组织的任何界面

## 四、核心流程

```
AISE 运营登录爱测评平台（AISE 组织身份）
        │
        ▼
进入题目管理（iceping/01）── 列表页：无「标签」筛选、无「标签」列，仅「知识标签」相关维度
        │
        ▼
点击 新增/编辑题目（iceping/02）── 录题表单：显示「知识标签」字段，不显示「标签」输入
        │
        ▼
保存题目 ── 题目仅挂「知识标签」，不产生爱测评「标签」值
```

## 五、边界与异常场景

| # | 场景 | 行为 |
|---|------|------|
| 1 | 历史题目已挂爱测评「标签」 | 数据保留，界面不展示；不迁移、不删除 |
| 2 | AISE 运营通过其他入口（如 API）维护题目 | 本次只定义界面屏蔽；API 层是否限制「标签」写入待确认 |
| 3 | 非 AISE 组织 | 完全不受影响 |
| 4 | 「知识标签」字段在爱测评尚未落地 | 需确认该字段现状（demo 中 iceping/02 当前无此字段） |
