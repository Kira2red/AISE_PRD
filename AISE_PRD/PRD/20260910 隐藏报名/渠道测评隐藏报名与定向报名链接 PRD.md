# 渠道测评隐藏报名与定向报名链接 PRD

## 1. 背景与收益

渠道（合作方）在正式环境测试报名流程、或需要给小部分人单独开放报名时，这类测评不能被普通用户看到。现有「前端展示开关」只有对所有人开/关两态：关掉则老师也无法走真实报名链路测试，开着则用户能看到甚至误报名（如近期「回归测试」考场被用户报入）。本期在渠道管理的关联测评配置中新增「隐藏报名」能力：被设为隐藏的测评在前端任何入口都不可见、不可报名，仅持有定向报名链接的用户可见可报。

- 需求出处：微信群聊（2026-09-10，Micheal/刘玮_未来基因 提出考场 A 场景，三诉求原文：老师通过「考场A专属链接」能报名；用户通过「渠道链接」看不到；优先级放在批量创建之前）。
- 功能命名与口径：与张二红 2026-09-10 拍板一致——功能名「隐藏报名」，链接名「定向报名链接」，粒度「渠道×测评」独立，第一版一条固定链接，不设有效期，随隐藏开关切换自动失效。
- 基线版本：基于测评管理版本渠道管理页实现；活动管理需求上线后此能力需同步迁移到考试×渠道矩阵（迁移要求见 3.6）。

## 2. 业务流程

1. 教务在「渠道管理」打开渠道的「关联考试管理」，对该渠道下的某场测评点「编辑」，将报名可见性设为「隐藏报名」，系统生成一条定向报名链接，复制链接或二维码发给目标人群（如授课老师）。
2. 老师打开定向链接，直接进入该测评的报名流程，正常填写信息、缴费，与普通报名体验一致。
3. 普通用户通过渠道码、渠道推广链接或任何直达方式进入报名页，均看不到该测评；无法通过拼接近似链接进入报名。

## 3. 详细功能说明

### 3.1 报名可见性配置（admin/02 渠道管理 → 关联考试管理 → 编辑弹窗）

- 弹窗在「配置报名费」「前端展示」等现有配置基础上，新增「报名可见性」单选组：
  - **正常报名**（默认）：现状行为不变，前端按展示规则正常展示，渠道链接均可报名。
  - **隐藏报名**：前端任何入口不可见、不可报名，仅持定向链接可报名。
- 选择「隐藏报名」后，弹窗内出现定向报名链接区块：链接输入框（只读）+「复制」+「二维码」；切换选项时语义提示文案同步更新。
- 一条「渠道×测评」关联关系对应一条固定定向链接：首次设为隐藏时生成，此后重新编辑保留不变；由隐藏改回正常报名再重新隐藏时生成新链接（旧链接随之失效）。
- 新建关联时默认「正常报名」。

### 3.2 定向报名链接

- 链接带随机标识，不可伪造；伪造或篡改的链接按「测评不存在或未开放」处理，不提示「隐藏」相关信息。
- 第一版不设有效期、不提供多条链接与单独作废；唯一失效途径是该关联关系改回「正常报名」。
- 链接即凭证，不做身份绑定；链接被转发给非目标人群时其同样可见可报，扩散风险由渠道管理员自行控制。
- 随机标识在整个报名流程中保持在地址栏（见 3.3「标识全程保留」），报名完成前不转换为明文测评 ID 地址。

### 3.3 前端可见性控制（user/08 考试报名）

三个入口按「系统判定依据」区分，判定依据不同、放行结果不同：

| 入口 | 形态 | 系统判定依据 | 正常报名测评 | 隐藏报名测评 |
|------|------|------------|------------|------------|
| 渠道码 / 渠道推广链接 | 从渠道聚合页进入报名列表 | 公开渠道身份 | 按现有展示规则展示 | 不展示 |
| 直达报名页 URL | `…/reg?exam=测评ID`（明文 ID，可被构造、传播） | 公开入口语义（按 ID 查测评状态） | 可报名 | 拒绝：按「测评不存在或未开放」处理，不可报名 |
| 定向报名链接 | `…/reg/d/随机标识`（标识不在任何公开页面出现，无法构造） | 定向关系凭证（按标识反查渠道×测评） | ——（不适用） | 放行：直接进入该测评报名流程，正常报名缴费 |

- **直达 URL 与定向链接的本质区别**：直达 URL 谁都能构造（测评 ID 在地址栏明文可见），因此对隐藏测评必须拒绝，否则任何人拿到 ID 即可绕过隐藏；定向链接的随机标识是唯一放行凭证。
- **标识全程保留**：持定向链接进入报名流程后，各步骤页面地址保持 `/reg/d/随机标识` 形态，不得降级为明文测评 ID URL——否则用户刷新或复制地址后即变成「直达 URL」，再次访问会被误拒。
- 隐藏控制必须在列表层与详情层同时生效：列表不展示且直达 URL 不可报名，不得只做列表过滤。
- 隐藏测评与「前端展示开关」相互独立、叠加生效：任一关闭，前端即不可见。
- 展示时间仅约束公开入口的展示节奏，对定向报名链接不生效（时间外定向链接仍可报名）；测评本身的报名截止对所有入口正常生效。
- 选择「隐藏报名」后，弹窗内「前端展示开关」「前端展示时间」区块整体收起不再显示（隐藏报名下两者不参与控制），改回「正常报名」时恢复显示。

### 3.4 管理侧呈现（admin）

- 关联考试管理列表、活动详情的考试×渠道矩阵中，隐藏测评显示「隐藏报名」标签，管理员可识别配置状态。
- 筛选器增加「报名可见性」筛选项。

### 3.5 边界与异常

| 场景 | 处理 |
|------|------|
| 测评报名已结束后打开定向链接 | 提示「报名已结束」，与正常测评口径一致 |
| 已有报名记录的测评被设为隐藏 | 已报名用户不受影响（正常参考试）；仅新报名入口按隐藏逻辑控制 |
| 隐藏测评被取消关联 | 定向链接随之失效，打开按「测评不存在或未开放」处理 |
| 渠道被禁用 | 该渠道所有链接（含定向链接）均不可用，与正常测评同口径 |
| 用户通过定向链接报名成功后，测评改回正常报名 | 已产生的报名记录与订单不受影响 |

### 3.6 与活动管理需求的迁移约定

本能力基于测评管理版本的「渠道×测评」关联关系实现。活动管理需求上线后，渠道与测评的关联关系迁移为活动下的考试×渠道矩阵，隐藏报名配置与定向链接须同步迁移，保持渠道×考试粒度独立配置与既有链接有效性，迁移方案在活动管理 PRD 中明确。

## 4. 验收标准

| # | 测试场景 | 前置条件 | 操作 | 期望结果 | 判定 |
|---|---------|---------|------|---------|------|
| 1 | 设置隐藏报名 | 渠道已关联测评 A | 编辑关联，选「隐藏报名」，保存 | 生成定向链接；前端报名列表不展示 A | 列表无 A，链接可复制 |
| 2 | 定向链接报名 | 测评 A 已隐藏 | 打开定向链接 | 直接进入 A 的报名流程，可正常缴费 | 报名成功，产生订单 |
| 3 | 渠道链接不可见 | 测评 A 已隐藏 | 通过渠道推广链接进入报名列表 | 列表无 A | 列表无 A |
| 4 | 直达 URL 不可报 | 测评 A 已隐藏 | 无链直接访问 A 的报名页 URL | 提示「测评不存在或未开放」，无法报名 | 不可报名，无隐藏字样 |
| 5 | 伪造链接 | 测评 A 已隐藏，定向链接标识为 X | 把标识 X 改为其他值访问 | 按「测评不存在或未开放」处理 | 不可报名 |
| 5a | 明文直达 URL 不可报 | 测评 A 已隐藏，其测评 ID 为 123 | 持定向链接进入后，复制/构造明文地址 `…/reg?exam=123` 重新访问 | 按「测评不存在或未开放」处理；确认各步骤地址始终保持 `/reg/d/` 标识形态 | 不可报名，标识未降级 |
| 6 | 链接失效 | 测评 A 已隐藏 | 编辑改回「正常报名」，保存后访问原定向链接 | 原链接失效；A 恢复公开展示 | 原链接不可用，A 在列表可见 |
| 7 | 已报名用户不受影响 | 测评 A 隐藏前已有用户报名 | 该用户查看已报名记录并参考试 | 报名记录、参考试流程正常 | 不受隐藏影响 |
| 8 | 弹窗联动 | 测评 A 关联配置弹窗打开 | 切换「隐藏报名」/「正常报名」 | 选隐藏时展示开关与展示时间区块收起；改回正常恢复显示 | 区块随选项显隐 |
| 9 | 回归：正常报名不受影响 | 未做隐藏配置的测评 | 走一遍现有报名流程 | 与本期上线前行为完全一致 | 现有功能无回归 |
