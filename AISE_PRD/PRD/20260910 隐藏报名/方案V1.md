# AISE 隐藏报名 · 产品方案 V1（方案级）

> 基于**测评管理版本**（渠道管理可关联多个测评，一个测评 = 一场考试）设计。
> 项目空间：`PRD/20260910 隐藏报名/`；流程：产品大师三阶段（方案 → demo → PRD）。

## 1. 背景与目标

**一句话**：在渠道管理的「关联考试管理」弹窗中新增「隐藏报名」能力——被设为隐藏的测评在前端任何入口都不可见、不可报名，仅持有定向报名链接的用户可见可报。

**业务动因**：渠道（合作方）在正式环境频繁测试报名流程、或需要给小部分人单独开放报名时，这类测评不能被普通用户看到。现有「前端展示开关」只有对所有人开/关两态，无法做到「对公开隐藏、对指定人开放」。

**期望效果**：
- 老师通过定向链接正常走完 C 端报名流程（含支付）
- 普通用户通过渠道码/推广链接/任何直达方式均看不到该测评

## 3. 功能清单

| # | 功能 | 优先级 | 说明 |
|---|------|--------|------|
| 1 | 报名可见性配置 | P0 | 「编辑关联测评」弹窗新增：正常报名（默认）/ 隐藏报名 二选一 |
| 2 | 定向报名链接生成 | P0 | 设置隐藏后可生成一条定向链接（带随机标识），支持复制、二维码预览 |
| 3 | 前端可见性控制 | P0 | 隐藏测评在渠道报名列表不展示；直达 URL 不可报名；仅定向链接可进报名流程 |
| 4 | 隐藏状态标识 | P1 | 关联考试列表、活动详情矩阵中该测评行显示「隐藏报名」标签（admin 侧可见，便于管理） |

## 4. 核心流程

**配置侧（admin）**：
渠道管理 → 关联考试管理 → 编辑关联测评弹窗 → 报名可见性选「隐藏报名」→ 保存 → 生成定向报名链接 → 复制链接/二维码发给老师

**用户侧（C 端）**：
- 持定向链接 → 打开即进入该测评报名流程（正常报名/缴费）
- 渠道码/推广链接进入 → 报名列表不展示隐藏测评
- 无链直达 URL → 不可报名（按「测评不存在或未开放」处理，不提示「隐藏」字样）

## 5. 边界与异常场景

| # | 场景 | 处理口径（待拍板项见 §7） |
|---|------|------|
| 1 | 隐藏测评 + 展示开关同时配置 | 隐藏报名优先：前端一律不可见 |
| 2 | 定向链接在测评结束后被打开 | 提示「报名已结束」（与正常测评口径一致） |
| 3 | 定向链接被二次转发（非目标人群持有） | 第一版不做身份绑定，链接即凭证；泄露风险由渠道管理员自行控制（可改回正常报名使链接失效） |
| 4 | 隐藏测评在 admin 各列表的呈现 | 正常展示 + 「隐藏报名」标签；筛选器增加「报名可见性」筛选项 |
| 5 | 已有报名记录的测评被设为隐藏 | 已报名用户不受影响（正常参考试）；仅新报名入口按隐藏逻辑控制 |
| 6 | 由隐藏改回正常报名 | 定向链接立即失效，测评恢复公开可见 |
| 7 | 渠道被禁用 | 隐藏测评与正常测评同口径：该渠道所有链接均不可用 |
| 8 | 定向链接格式被篡改/伪造 | 校验失败按「测评不存在或未开放」处理 |

| 类型 | 内容 |
|------|------|
| 依赖 | 基于测评管理版本的渠道管理页（admin/02）实现；活动管理上线后需迁移（见待确认 #6） |
