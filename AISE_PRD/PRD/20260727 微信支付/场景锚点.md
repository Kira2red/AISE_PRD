# AISE 微信支付集成 — 场景锚点

## 产品定位

为 AISE 考试报名流程引入微信支付闭环，替换现有的「扫静态码+手动确认」乐观支付模式，同步建立用户微信账号绑定和模板消息触达能力。

## 当前系统状态

### 报名流程（4步）
1. 报名须知 → 2. 填写信息 → 3. 确认信息 → 4. 支付费用
- Step4 当前：展示金额 → 选微信/支付宝 → 展示静态二维码 → 用户扫码 → 手动点击「我已完成支付」
- 问题：支付状态不可验证、无回调闭环、用户端无通知触达、账号未绑定

- 报名成功页：已存在，需增加公众号关注引导

## 交互原则

1. **不改变报名前三步**：报名须知、填写信息、确认信息保持不变
2. **支付环节最小改动**：Step4 只在支付方式部分改动，不移除整个步骤结构
3. **强引导关注公众号**：支付成功不是终点，关注公众号才能收到后续通知。引导不可跳过、不可一闪而过
4. **PC端 + 微信端双端覆盖**：PC端扫码支付 + 微信端内H5支付，两端都展示公众号关注引导
5. **现有页面增量修改**：基于已有的 `08_考试报名_主页.html` 做增量 patch，不改原页面整体结构

## 约束条件

- 服务号已认证，JSAPI 支付是否开通待确认
- 需微信商户号 + 支付目录配置 + JS 接口安全域名
- 排期待评审后确定
- 不做全流程微信端报名（报名表单仍在PC端）
- 模板消息「审核结果通知」本期不做
