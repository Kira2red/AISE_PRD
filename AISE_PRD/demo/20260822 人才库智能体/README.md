# 人才库智能体（AI人才大脑 1.0）本地 Demo

一个**本地完整可跑**的全链路演示：用户上传作品 → 智能体自动预审归档 → 后台人工检查确认修改 → 前台看到结果（人才卡标签/能力雷达更新 + 画像分析报告）。

## 运行要求

- 仅需 **Python3**（标准库即可，**零依赖、无需 pip install 任何包**）
- 可选：DeepSeek API key（不配也能跑，见下方「两种模式」）

## 启动

```bash
python3 server.py
```

然后浏览器打开：

| 页面 | 地址 | 说明 |
|------|------|------|
| 作品上传（学员端） | http://localhost:8080/ | 上传作品、查看「审核中 / 审核完成 / 未通过」 |
| 人才卡 | http://localhost:8080/card.html | 特长领域动态标签 + 综合分析能力雷达 |
| 画像分析报告 | http://localhost:8080/report.html | 标题栏「画像分析」tab 的独立报告页 |
| 审核工作台（后台） | http://localhost:8080/admin.html | 预审队列、AI 结论、人工终审、材料审核、留痕记录 |

## 两种模式

| 模式 | 条件 | 行为 |
|------|------|------|
| **真实模式** | 项目目录 `.env` 配置了 `DEEPSEEK_API_KEY` | 智能体预审真实调用 DeepSeek V4 Flash（图片作品走视觉模型） |
| **Mock 模拟模式** | 未配置 key | 返回**显式标注「模拟结果」**的预设结论，全链路照常演示 |

启动后顶栏徽章会显示当前模式；Mock 结论一律带「模拟结果」标识。

## ⚠️ 分享给别人（token 安全，重要）

**把 demo 发给别人时，不要附带 `.env` 文件**——里面是 API key，带了等于把 token 送给对方。

- `.env` 已被 `.gitignore` 忽略，git 提交/推送不会包含它
- 分享时打包整个目录（删除 `.env` 和 `data.json`）即可
- 收件人：直接跑 = Mock 模式，全链路可演示；想用真实大模型，自己把 key 填入 `.env`（参考 `.env.example`）后重启

## 配置说明（.env，可选）

```bash
DEEPSEEK_API_KEY=你的key          # 不填 = Mock 模式
DEEPSEEK_MODEL=deepseek-v4-flash  # 文本类作品（代码/PDF）审核模型
DEEPSEEK_VISION_MODEL=deepseek-v4-flash-vision-exp  # 图片作品审核模型（不可用则自动降级文字分析）
PORT=8080                          # 端口
```

## 演示链路

1. 学员端 `index.html` 上传作品（代码/图片/PDF ≤10MB，连续上传不受限，提交即「审核中」）
2. 服务端异步调用大模型预审（真实/模拟），结论仅在后台可见：准入结论、理由、标签、得分（100 分制）、评语、理解结果
3. 后台 `admin.html` 查看预审结论 → 人工终审：确认通过 / 修改（标签/得分/评语）后通过 / 驳回（填原因，不限重提次数）；全部留痕
4. 通过后：人才卡特长领域出现动态标签、能力雷达更新；画像分析报告（报告页点「重新生成」）综合测评与作品评价生成
5. 简历材料审核：人才卡/后台提交三模块材料条目 → 按条目 AI 预审（规范性/一致性/敏感信息）→ 人工通过/驳回
