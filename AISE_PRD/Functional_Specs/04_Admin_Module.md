# 管理员模块功能规范 (Admin Module)

## 1. 概述
管理员模块 (Admin) 提供后台管理能力，主要包括考务管理（报名/考生/测评）和教务管理（题库/试卷）。

## 2. 考务管理

### 2.1. 报名管理 (Enrollment)
- **列表视图**:
    - 展示报名记录，字段包括：报名信息（项目/订单号）、考生信息（头像/姓名/电话）、渠道来源（标识/标签）、支付金额、支付状态（已支付/待支付/后台录入）、报名时间。
    - **筛选查询**: 支持按订单号/姓名/手机号搜索，按测评项目、支付状态、渠道来源筛选。
- **详情抽屉 (Drawer)**:
    - 点击列表行唤起右侧抽屉。
    - **支付凭证**: 展示支付方式、时间、金额。
    - **详细信息**: 报考信息、考生信息（含身份证/监护人）、操作日志（时间轴展示“创建订单->支付成功->生成准考证”）。
    - **操作**: 取消/退款、下载凭证。
- **后台代报名 (Proxy Enrollment)**:
    - 弹窗形式，管理员可代用户操作报名。
    - **用户选择**: 搜索现有用户（姓名/手机/身份证），下拉选择并确认。
    - **报考设置**: 选择测评场次，填写渠道识别码。
    - **支付处理**: 可标记为“直接已支付”、“免单”或“仅生成订单”。

## 3. 教务管理

### 3.1. 题库录入 (Question Entry)
- **基础属性**:
    - **类型**: 单选、多选、判断、实操编程。
    - **难度**: 简单、中等、困难（单选组）。
    - **标签**: 知识点标签管理（输入回车添加、点击删除）。
- **题干编辑**:
    - 富文本编辑器：支持加粗、斜体、代码块、图片、公式。
    - 支持 Markdown 语法输入。
- **选项设置 (选择题)**:
    - 拖拽排序 (Drag & Drop)。
    - 标记正确答案（单选 Radio / 多选 Checkbox）。
    - 选项内容支持文本和图片。
    - 动态添加/删除选项。
- **答案解析**:
    - 富文本编辑器，录入详细解析。

## 4. 系统交互
- **导航栏**: 左侧固定导航，支持折叠/展开子菜单。
- **面包屑/返回**: 详情页支持返回上一级。
- **反馈**: 操作成功/失败的 Toast 提示。
