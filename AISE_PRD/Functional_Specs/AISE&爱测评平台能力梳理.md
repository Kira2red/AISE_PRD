# AISE & 爱测评平台能力梳理

## 平台说明

AISE 考试平台会开放三种考试能力：
1. 在 AISE 平台的网页端直接测评
2. AISE 开放 api，由合作方在自己的平台嵌入考试能力，对应的管理功能在 AISE-组织后台模块。
3. 合作方自己组织内部测评（现在叫预备测），不用 AISE 的测评能力，但是可以把部分测评结果返回给AISE

另外还有个爱测评平台，是个基于学校部署的考试平台，其中考试相关的能力被我摘出来复用到 AISE 了，AISE 是 C 端和 B 端用户自主报名、接入的平台，考试、试卷管理等功能都是复用爱测评的，对于爱测评来说，AISE 平台就是一个特殊的学校组织。

## 第一部分：AISE 各端能力概述

### 1. admin 端（AISE 运营后台）

平台运营团队使用的管理后台，是整个 AISE 平台的"中控室"。核心能力包括：

- **教务中心**：管理题库（CRUD + 批量导入）、组卷、测评活动的创建/同步/配置、标签体系管理、测评分组
- **考务与用户**：考生信息管理、报名记录管理（含代报名）、批量导入、用户信息审核、实体证书生命周期管理（分数线配置→公示→制作→寄送）
- **电子证书管理**：证书模板配置（拖拽式可视化编辑器）、证书实例管理（测评绑定+模板+字段映射）、电子签发状态追踪
- **运营中心**：渠道/合作方管理（含 API 凭证配置）、官网内容管理（Banner、专家团队、合作单位、导航栏、新闻资讯）
- **系统支撑**：消息中心（异步任务/导出文件管理 + 签发启停通知）

共 28 个页面（原 25 + 新增 3 个电子证书管理页）。

### 2. exam 端（考试答题端）

面向青少年考生的在线答题界面，采用"趣味编程大冒险"童趣风格设计。核心能力包括：

- **考试框架**：统一的侧边栏（题号导航 + 摄像头监控）+ 顶栏（倒计时 + 交卷）+ 答题区布局
- **丰富题型支持**：选择/填空/判断、划线题、编程题（内嵌 IDE）、实践题（多步骤实操）、图形化编程（Scratch 类积木）、AIGC 文生文、AIGC 文生图、AI 工作流（拖拽节点）
- **考试保障**：切屏检测与阻断弹窗、答案自动保存、导航离开拦截、摄像头异常提示
- **教师出题**：复用爱测评系统的题目编辑器，支持全题型配置

共 17 个页面（含字体变体版本），覆盖从考试等待到提交交卷的全流程。

### 3. iceping 端（爱测评平台）

基于学校部署的底层考试能力平台，AISE 复用其核心考试引擎。核心能力包括：

- **题目管理**：题库列表管理 + 单题录入/编辑（富文本、选项、答案解析）
- **试卷管理**：试卷列表 + 试卷内容编辑（题目排序、分值设置、实践题按步骤赋分）
- **测评管理**：测评详情查看（考生成绩列表、统计数据）、考试过程视频回放
- **批改能力**：教师在线批改实践题（查看代码/运行结果、评分）

共 8 个页面，提供 AISE 所依赖的底层考试和阅卷能力。

### 4. org_admin 端（组织后台）

合作方管理员使用的后台，对应第 2 种能力开放模式（API 嵌入）。核心能力包括：

- **组织管理**：学生列表管理（搜索、CRUD、批量导入）
- **考务管理**：报名记录管理（筛选、导出）、项目管理（测评项目列表 + 场次/报名详情）
- **API 接入**：密钥管理（AppKey/Secret）、Webhook URL 配置、签名验证说明
- **联调支撑**：API 调用日志查看（请求/响应详情、状态码、时间线）

共 8 个页面，为合作方提供完整的自助接入和管理能力。

### 5. issuance 端（签发中心）

面向中国软件行业协会（软协）的独立电子证书签发管控平台。采用飞书风格深蓝/灰白配色。核心能力包括：

- **签发仪表盘**：全量用户证书列表（所有考试混排）、签发状态统计（总计/待签发/签发中/已签发/失败）、全局签发启停开关
- **证书管理**：查看/下载已签发电子证书、重签失败证书、批量重签
- **筛选查询**：按姓名/证书编号搜索、按签发状态/测评名称/测评类型多维度筛选、测评多选标签输入

共 2 个页面（登录+仪表盘），与 AISE admin 账号体系独立。

### 6. user 端（C 端用户端）

面向考生及其家长的前端应用，是 AISE 的用户触达入口。核心能力包括：

- **官网展示**：首页（Banner、测评活动、专家团队、合作单位）、新闻中心
- **报名流程**：测评报名（活动信息/费用）→ 身份选择 → 填写信息（考生/监护人）→ 照片上传
- **考生管理**：家庭考生管理、多学生个人中心
- **考试流程**：我的考试列表 → 设备调试（摄像头/麦克风/网络）→ 答题页
- **成果查询**：准考证查看/下载、成绩与证书查询、成绩公示

共 23 个页面，覆盖从了解平台到报名、考试、查成绩的完整用户旅程。
