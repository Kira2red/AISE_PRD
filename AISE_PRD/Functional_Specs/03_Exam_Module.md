# 考试模块功能规范 (Exam Module)

## 1. 概述
考试模块是系统的核心，提供稳定、防作弊的在线测评环境。支持标准题型（选择/判断/填空）和编程题型（图形化/Python IDE）。

## 2. 考试界面框架

### 2.1. 全局布局
- **侧边栏 (Sidebar)**:
    - **考生信息**: 实时显示摄像头画面（监考）、姓名、设备状态（摄像头/录屏/检录状态）。
    - **答题卡 (Question Map)**: 按章节/题型分组展示题号。
        - 颜色状态：🔵 当前、🟢 已做、⚪️ 未做。
    - **折叠功能**: 支持收起侧边栏以扩大答题区域。
- **顶部栏 (Top Bar)**:
    - **考试信息**: 考试名称、剩余时间倒计时（红色醒目/警告样式）。
    - **导航控制**: 上一题/下一题按钮。
    - **工具栏**: 全屏切换、**交卷**按钮。

### 2.2. 题型交互

#### 通用题型
- **单选/多选/判断**: 点击选项即选中，支持取消（多选）。
- **填空题**: 下划线式输入框，支持中文/英文输入。
- **阅读理解**: 左侧阅读材料（支持滚动），右侧作答区（分栏布局）。

#### 编程题型
- **图形化编程 (Scratch-like)**:
    - 描述与任务在左侧。
    - 右侧提供“启动独立编程环境”入口。
    - **状态同步**: 模拟检测外部工具的保存/完成状态，界面显示“已保存/已完成”。
- **Python 编程 (IDE)**:
    - **布局**: 左侧题目描述，右侧在线编辑器。
    - **编辑器特性**:
        - 语法高亮、行号显示。
        - **专注模式**: 隐藏侧边栏和顶部栏，仅保留编辑器和题目。
        - **控制台**: 运行代码，底栏弹出终端(Terminal)显示输入/输出结果。
        - **重置**: 恢复初始代码模板。

## 3. 核心逻辑

### 3.1. 监考与防作弊
- **实时监控**: 侧边栏持续显示摄像头画面，模拟“红点”录制状态。
- **全屏强制**: 建议或强制全屏模式，退出全屏可能触发警告。
- **焦点检测**: (从HTML逻辑推断) 具备专注模式切换。

### 3.2. 保存与提交
- **自动保存**: 编程题模拟了“代码已保存到云端”的反馈。
- **离页拦截**:
    - 当用户试图切换题目或交卷时，如果检测到未保存的修改，弹出 **Modal** 警告。
    - 选项：保存并继续、不保存、取消。
- **交卷流程**:
    - 点击交卷 -> 二次确认弹窗 -> 提交成功 -> 跳转至结果页或锁定状态。

### 3.3. 导航逻辑
- 支持通过侧边栏题号直接跳转。
- 支持“上一题/下一题”顺序切换。
- 最后一题时，“下一题”按钮变更为“交卷”或禁用。
