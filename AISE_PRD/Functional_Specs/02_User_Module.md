# 用户模块功能规范 (User Module)

## 1. 概述
用户模块面向学生/考生，提供从注册登录、个人信息维护到考试报名、准考证查看及成绩查询的全流程服务。

## 2. 核心功能

### 2.1. 首页与导航
- **动态导航栏**:
    - 未登录态显示登录/注册入口。
    - 登录态显示用户头像、姓名及下拉菜单。
    - 滚动时背景呈现毛玻璃效果 (Glassmorphism)。
- **英雄区 (Hero Section)**:
    - 核心行动点：立即报名、设备检测。
    - 动态展示即将开始的考试倒计时。
- **新闻/公告**:
    - 展示最新赛事动态、通知及备考指南。

### 2.2. 个人中心 (Profile)
- **基本信息管理**:
    - **头像**: 支持上传与预览。
    - **身份信息**: 真实姓名、性别、身份证号（作为唯一标识及初始密码）。
    - **联系方式**: 邮箱、监护人姓名及电话。
    - **地址信息**: 省市区选择及详细地址输入。
- **交互体验**:
    - 保存按钮具有“保存中 -> 成功”的状态反馈动画。

### 2.3. 我的考试 (My Exams) / 准考证
- **考试列表**:
    - 展示已报名的考试卡片。
    - **状态标签**: 如 `2025春季一级`，区分不同等级和批次。
    - **时间信息**: 报名时间、考试时间。
    - **实时状态**: “进行中”状态会有呼吸灯动画提示。
- **操作行动**:
    - **查看准考证**: 弹窗展示。
    - **模拟测评**: 进入模拟考试环境。
    - **正式测评**: 在规定时间内激活，点击进入正式考试。
    - **已交卷**: 考试结束后或主动提交后，按钮置灰不可点击。

### 2.4. 准考证详情 (Ticket Modal)
- **展示信息**:
    - 报考项目、测评名称。
    - 考生姓名、身份证号（脱敏显示）、照片（带认证水印）。
    - 测评时间、准考证号 (Barcode/Text)。
- **操作**:
    - **下载 PDF**: 生成并下载准考证文件。
    - **打印**: 调用浏览器打印功能。

## 3. 业务流程
1.  **登录/注册**: 用户通过手机号或身份证号登录。
2.  **完善资料**: 首次登录强制或引导完善个人资料。
3.  **报名/查看**: 在首页或活动页报名，在“我的准考证”页查看已报名项目。
4.  **考前准备**: 点击“设备检测”或“模拟测评”。
5.  **参加考试**: 到达考试时间，点击“正式测评”进入考试模块（详见考试模块规范）。
